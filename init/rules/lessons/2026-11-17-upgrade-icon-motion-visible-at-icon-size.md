# 아이콘 연출은 실제 표시 크기에서 몇 픽셀 움직이는지로 판단한다
- 날짜: 2026-11-17
- 태그: ui, animation, upgrade, hover, visual
- 실수: 산소 소모 감소 노드의 '숨 쉬는 광부'가 호버해도 가만히 서 있는 것처럼 보였다. 테스트는 통과한 상태였다. 전신 그림을 허리에서 잘라 상체만 부풀린 1차 수정도 "숨 쉬는 느낌이 부족하다"는 피드백을 받았다.
- 원인: 60px 아이콘 전체를 발끝 기준으로 3.5~7%만 키워 변화가 2~4px였다. 그림 한 장을 늘이는 것만으로는 표정·어깨·입 모양이 바뀌지 않아 호흡으로 읽히지 않는다. 테스트는 배율 차이만 확인했다.
- 다음부터 할 일: 작은 아이콘 연출은 표시 크기에서의 이동 픽셀로 진폭을 정한다. 캐릭터의 동작은 자세가 다른 그림 여러 장(가스 저항 썸네일과 같은 상반신 구도)을 이어 섞고, 섞는 동안 두 그림의 높이를 맞춰 겹쳐 보이지 않게 한다. 대기·정점·복귀 프레임을 묶어 캡처해 직접 확인한다.
- 관련: prompt-B 200-1, UpgradeNodeHoverFx(OxygenEfficiency), UpgradeIconFx.MinerBreathFrame/MinerFrameRise, upgrade-icon-miner-breath-01~04.png.
