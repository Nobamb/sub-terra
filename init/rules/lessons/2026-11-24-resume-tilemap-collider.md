# 이어하기 위치 검사 전에 타일 충돌체를 갱신한다

- 날짜: 2026-11-24
- 태그: save, continue, tilemap, physics, windows
- 실수: Windows 플레이어의 재실행 후 저장을 읽고 광산을 불러왔지만 플레이어 위치 복원에서 실패했다.
- 원인: 저장된 채굴 결과를 타일맵에 적용한 프레임에 위치를 검사했다. 타일맵 충돌체가 아직 갱신되기 전이라 비어 있는 칸이 물리 검사에서 막힌 것으로 판정됐다.
- 다음부터 할 일: 즉시 위치를 검사해야 할 때는 변경 대기 중인 타일맵 충돌체를 먼저 갱신한다. 에디터에서 씬을 다시 여는 검사와 별도로 플레이어 프로세스를 끝낸 뒤 같은 슬롯으로 이어하기를 확인한다.
- 관련: PR #385, PR #386
