# 고립 지형은 연결 단위로 판정하고 복원 중에는 조용히 제거한다
- 날짜: 2026-11-11
- 태그: structural, collapse, snapshot
- 실수: 바로 옆에 다른 블록이 남은 덩어리는 받침과 끊겨도 낙하하지 않았고, 기존 저장을 불러오면 떠 있는 상태가 유지됐다.
- 원인: 단일 블록의 사방만 검사했고, 이어하기에서는 위험 점수만 복원했다.
- 다음부터 할 일: 타일 제거 지점에서 이어진 덩어리를 탐색해 경계 암석·보호 셀·버팀목과의 연결을 확인한다. 이어하기에서는 시설 복원 뒤에 검사하고, 제거한 셀을 기존 붕괴 기록에 넣어 재저장 시 보존한다.
- 관련: #281, PR #314, StructuralIntegritySystem, WorldSnapshotSystem.
