# 씬 연결 기능은 가짜 람다가 아니라 실제 광산 씬 경로로 검증한다
- 날짜: 2026-11-11
- 태그: structural, collapse, gas, playmode, integration
- 실수: 낙석 피해 배율과 착지 가스 PR(#312)이 테스트는 통과했지만 실제 광산 씬에서는 동작하지 않는다는 보고가 나왔다.
- 원인: 테스트가 손으로 만든 DTO·가짜 람다·미리 넣은 필드로만 검증해, 오버레이가 늦게 준비되는 경우와 같은 붕괴 묶음의 착지 바닥 재탐색 같은 실제 경로를 놓쳤다. 착지 바닥도 낙하 시작 시점에만 저장해 아래 칸이 같이 떨어지면 가스가 생략됐다.
- 다음부터 할 일: Bootstrap → 광산 씬 PlayMode로 실제 배선(콜백, 구독)을 확인하는 검사를 함께 둔다. 이벤트 구독·콜백은 대상이 늦게 준비돼도 버리지 않고 보관했다가 연결한다. 착지·충돌 같은 결과는 시작이 아니라 끝나는 시점의 상태로 판정한다. 가스 도트처럼 이전 검사가 남긴 상태가 다음 검사의 피해·무적을 바꿀 수 있으니 검사 사이에 비운다.
- 관련: #289, PR #312, B-193, StructuralIntegritySystem, StructuralCrackOverlay.
