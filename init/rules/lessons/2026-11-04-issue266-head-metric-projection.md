# 색상 영역 폭을 실제 머리 크기로 간주하지 않기
- 날짜: 2026-11-04
- 태그: character, animation, alignment, imagegen
- 실수: 앞·뒤 모션의 주황색 연결 영역 폭을 같은 값으로 맞추자 사다리 캐릭터가 작아졌다. 새 그림의 헬멧 이음선이 달라졌을 때에도 같은 측정만으로는 정렬 크기가 잘못됐다.
- 원인: 색상 연결 영역은 이음선·광원·시점에 따라 갈라지며 머리 전체 윤곽이 아니다.
- 다음부터 할 일: 앞·뒤 보기별 교정값과 중립 자세 키를 사용하고 전신 비교로 확인한다. 모션 안에서는 같은 확대율을 유지한다. 측정값만으로 외형 일치나 게임 접점 확인을 주장하지 않는다. 바닥을 맞춘 상태에서 진입·정지의 머리 높이도 비교한다.
