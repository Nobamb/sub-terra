# HUD의 한·영 전환은 표시 중인 수치를 다시 그린다

- 날짜: 2026-11-26
- 태그: localization, hud, ui, shortcuts
- 실수: 영어 설정에서도 깊이·골드·미정산과 오른쪽 메뉴의 일부 한국어가 남았다.
- 원인: HUD 수치 일부만 언어 갱신 대상이었고 메뉴의 설정 라벨을 별도 컨트롤러가 한국어로 덮었다.
- 다음부터 할 일: 값이 바뀌지 않아도 적용 언어가 변경되면 모든 대상 라벨을 갱신한다. 메뉴 라벨과 입력 단축키는 같은 표시 경로에서 확인한다.
