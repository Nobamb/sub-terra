# 스크롤 UI의 입력 중심과 구획 높이를 함께 확인
- 날짜: 2026-11-03
- 태그: UI, uGUI, ScrollRect, 건설창, 테스트
- 실수: 건설창 설명/비용 열이 겹치거나 잘릴 수 있었다. 새 검사에서는 pivot을 클릭해 마스크 경계에 걸렸고 저장된 driven 좌표를 실제 배치로 오해했다. 이동된 자식 경로와 main의 오래된 문구 기대도 놓쳤다.
- 원인: 고정 높이/중복 열과 실제 렌더·레이아웃·입력 계약을 함께 검토하지 않았다.
- 다음부터 할 일: 설명 선호 높이로 비용을 밀어내고 상태/결과는 고정한다. 실제 RectTransform 중앙을 화면 좌표로 변환해 클릭하고 LayoutGroup의 행 크기/순서 및 실행 화면을 검증한다. 변경 경로 전체와 기존 main의 실패를 대조한다.
