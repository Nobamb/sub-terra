# 인벤토리 배치 변경 뒤 다른 프롬프트 테스트가 옛 요소 좌표를 계속 검사함
- 날짜: 2026-11-09
- 태그: UI, uGUI, 인벤토리, 테스트, issue268
- 실수: B-190에서 무게 `?`를 적재 현황 제목 옆으로 옮겼는데, B-68 테스트(`PromptB68CargoWeightTests`)가 숨김 계약용 `CargoSummaryText`와 `?`의 가로 겹침을 검사해 실패했다. 프롬프트 안내의 기존 테스트 3개만 고치고 같은 프리팹을 보는 다른 테스트를 놓쳤다.
- 원인: 수정 대상 테스트를 프롬프트 목록에서만 골랐고, 프리팹 경로·요소 이름(`WeightHelpIcon`, `CargoSummaryText`)으로 테스트 전체를 검색하지 않았다.
- 다음부터 할 일: 프리팹 배치를 바꾸면 `Tests/` 전체에서 프리팹 경로와 옮긴 요소 이름을 grep 해 검사 대상을 먼저 모으고, 화면에 보이는 요소 기준으로 기대값을 고친다. 그 뒤 해당 묶음 EditMode를 실행한다.
