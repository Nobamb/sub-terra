# 플레이 중 스크립트를 고치면 코드로 만든 UI 상태가 조용히 지워져 버그처럼 보인다

- 날짜: 2026-11-23
- 태그: playmode, compilation, mcp, ui, issue266
- 실수: B-209 광부 선택 화면을 플레이로 확인하다가 레이아웃 숫자만 고치려고 `.cs`를 저장했다. 다음 MCP 호출에서 `Flow`가 null인 NullReferenceException이 나고, 안내 글자는 숨김·카드 또렷함은 0으로 읽혀 선택 로직 버그로 오해할 뻔했다.
- 원인: 에디터 자동 새로 고침이 플레이 중에 재컴파일·도메인 리로드를 했다. `[SerializeField]`가 아닌 런타임 필드(세션·카드 배열·CanvasGroup 참조)가 모두 초기화돼 패널이 "열린 채 비어 있는" 상태가 됐다. Console에는 오류가 없었다.
- 다음부터 할 일: 플레이 확인 중에는 코드를 고치지 않는다. 고칠 것이 보이면 메모만 하고 플레이를 끝낸 뒤 고치고, `Library/ScriptAssemblies/*.dll` 시각이 소스보다 새것인지 본 다음 다시 플레이한다. 플레이 중 이상한 null이 나면 먼저 DLL 시각과 플레이 시작 시각을 비교한다.
- 관련: #266, B-209, `2026-10-25-playmode-script-reload.md`
