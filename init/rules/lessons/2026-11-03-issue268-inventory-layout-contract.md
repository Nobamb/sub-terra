# 인벤토리 표시의 직렬화와 닫힘 기준 확인
- 날짜: 2026-11-03
- 태그: UI, TMP, 인벤토리, 테스트
- 실수: 행 이름과 수량 영역이 겹칠 수 있었고 도움말이 숫자 위를 덮었다. 검사에서는 TMP 최대 줄 수가 저장되는 것으로 가정했고 지상 창의 부모 숨김을 놓쳤다.
- 원인: 열 간격·두 줄 높이·도움말 영역을 함께 검토하지 않았고 런타임 전용 TMP 속성과 부모/자식 가시성 계약을 대조하지 않았다. 보조 Python 스크립트에서 UTF-8도 명시하지 않았다.
- 다음부터 할 일: 고정 수량 열과 2줄 높이를 확보하고 실제 큰 숫자/도움말 화면을 비교한다. TMP 줄 수는 런타임 적용하고 가시성은 activeInHierarchy로 검사한다. 파일 읽기/쓰기는 UTF-8을 명시한다.
