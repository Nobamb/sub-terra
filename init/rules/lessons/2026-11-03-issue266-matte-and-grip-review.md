# 투명 배경과 그립 보정은 실제 합성으로 검수
- 날짜: 2026-11-03
- 태그: character, imagegen, alpha, animation
- 실수: 투명 배경 지시로 편집한 결과에 외부 얼룩이 반복됐고, 그립 보정 중 손이 세 개 생겼다.
- 원인: 이미지 도구가 배경 흔적과 가려진 신체 부위를 잘못 보존/추가했다. 생성 지시나 파일 알파 존재만으로 합격 판정을 할 수 없다.
- 다음부터 할 일: 양손과 연결된 팔 수를 자세별로 확인한다. 흰색/검정 합성으로 외곽을 검수하고, 도구가 실패하면 같은 편집을 무작정 반복하지 않는다. 코드 배경 정리는 사용자 허용 후 외곽만 처리하며 내부 RGB 보존을 확인한다.
