# Unity 실행 전후 보존할 검증 파일은 Temp 밖에 저장
- 날짜: 2026-11-07
- 태그: Unity, 테스트, Git, Temp
- 실수: 테스트 결과 XML과 병합 검증용 임시 인덱스를 Unity 프로젝트의 Temp에 두어 Editor 실행·종료 시 사라졌다.
