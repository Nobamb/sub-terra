# 실제 광산 소리 검사 전에 현재 음소거 상태를 확인한다
- 날짜: 2026-11-04
- 태그: audio, playmode, integration, settings, issue158
- 실수: B-184 실제 광산 통합 검사에서 가스 소스가 생성되지 않은 것을 곧바로 재생 실패로 단언했다.
- 원인: 현재 SFX 음소거가 켜져 있었고, 새 반복음은 음소거 때 소스를 만들지 않는 정상 경로를 따랐다. 격리 검사에서는 음소거 판정을 주입하므로 이 차이가 드러나지 않았다.
- 다음부터 할 일: 실제 환경 검사의 실패 메시지에 음소거·정지·가스 진행·배선 상태를 포함한다. 사용자 설정을 변경하지 말고, 필요하면 해당 검사 컴포넌트의 음소거 판정만 주입하여 배선·재생을 확인한다. 실제 설정과 테스트 대체 범위를 보고서에 구분한다.
