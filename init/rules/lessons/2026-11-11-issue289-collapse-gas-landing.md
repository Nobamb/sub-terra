# 낙석 착지 효과는 낙하 시작 때 찾은 바닥 셀을 사용한다
- 날짜: 2026-11-11
- 태그: collapse, gas, tilemap
- 실수: 바닥이 있는 가스 낙석에서 착지 가스 생성 검사가 실패했다.
- 원인: 초기 구현은 낙하 시작 때 찾은 셀을 버리고 착지 좌표에서 바닥을 역산했다. 검사 타일맵의 셀 범위도 명시적으로 갱신하지 않았다.
- 다음부터 할 일: 바닥 셀을 낙석에 보관하고 착지 때 그 셀이 남아 있는지 확인한다. 테스트 타일을 넣은 뒤 타일맵 범위를 정리하고, 착지 전과 착지 후를 나눠 검사한다.
- 관련: #289, PR #312.
