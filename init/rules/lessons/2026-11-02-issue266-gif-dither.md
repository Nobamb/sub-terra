# GIF 점무늬와 원화 결함 구분
- 날짜: 2026-11-02
- 태그: animation, gif, palette, visual-qa
- 실수: 색상 변환의 오차 확산 디더링 때문에 좋은 PNG 원화가 GIF에서 얼룩져 보였다.
- 원인: 변환 전후의 디코딩 프레임을 비교하지 않고 기본 디더링으로 검토 GIF를 공유했다.
- 다음부터 할 일: 공통 팔레트·무디더링 GIF와 무손실 미리보기를 비교하고, PNG 원화는 그대로 보존한다. 변환 얼룩 때문에 캐릭터를 다시 생성하지 않는다.
- 관련: #266, PR #270 여자 사다리 모션.
