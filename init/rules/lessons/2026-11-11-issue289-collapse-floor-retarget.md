# 낙석 착지점은 붕괴 중 바닥이 사라지면 다시 찾는다
- 날짜: 2026-11-11
- 태그: collapse, gas, tilemap, playmode
- 실수: 최초에 찾은 바닥이 같은 붕괴에서 사라지면, 아래에 다른 바닥이 있어도 착지 이벤트를 버렸다.
- 원인: 낙하 경로가 최초 바닥까지만 계산됐고 착지 시 그 셀이 없으면 종료했다.
- 다음부터 할 일: 처음 바닥이 유지되는 경우, 사라진 뒤 아래 바닥이 있는 경우, 끝까지 바닥이 없는 경우를 나눠 확인한다. 낙석별 피해 배율은 생성 시 보관하고 실제 Bootstrap 광산의 채굴·충돌·가스 경로도 검증한다.
- 관련: #289, PR #312. 수정 전 리튬의 고정 바닥 착지와 피해 20은 재현 환경에서 정상 작동했다.
