# 절차 생성 빛 그림의 옅은 꼬리가 리니어 색 공간에서 네모 상자로 보인다

- 날짜: 2026-11-23
- 태그: ui, glow, sprite, color-space, b209
- 실수: 광부 선택 카드 바깥 빛을 깎인 모서리 모양 9분할 그림으로 바꿨는데, 바깥 꼬리를 `exp(-d/4.5)`로만 줄여 그림 가장자리 알파가 약 0.02로 남았다. 오프스크린 렌더로 보니 고른 카드 둘레에 모서리가 각진 옅은 네모 상자가 보였다(가장자리 픽셀이 배경 (3,5,16)에서 (17,48,55)로 바로 뛰었다).
- 원인: 프로젝트가 리니어 색 공간이라 2% 알파 청록도 sRGB로 바꾸면 눈에 띄는 밝기가 된다. 꼬리가 0이 되기 전에 그림이 끝나 Image 사각형 경계가 그대로 드러났다.
- 다음부터 할 일: 빛·그림자 그림을 절차로 만들 때는 바깥 꼬리에 `(1 - d/pad)^2` 같은 감쇠를 곱해 그림 가장자리에서 알파가 정확히 0이 되게 한다. 숫자 테스트만 믿지 말고 오프스크린 렌더로 빛 경계 바깥 픽셀이 배경과 같은지 확인한다.
- 관련: B-209 광부 선택 화면 디자인 수정, `MinerSelectArt.CardGlow`
