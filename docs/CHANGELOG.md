# Changelog

## 1.0.0-mvp2

- Completed the MVP2 demo route through Surface Base, mine traversal, hazards, facilities, return, save, and progression.
- Added accessibility controls for reduced motion and safe-area aware menu layouts.
- Added repeatable Windows x64 Development, QA, and Release packaging gates.
- Reworked the start briefing (Prompt-B 120): terminal-signal entrance, low-intensity edge interference while open, 0.4s close, confirmed briefing text, and a pause gate that stops the mine reset timer and background input while it is open.
- Reworked the Clinic and Charger popups into compact cyan service panels with a heart + ECG (Clinic) or bolt + electric arc (Charger) entrance, a real HP/energy gauge showing the before/after values, and a short exit. Healing and charging still apply immediately; the animation is display-only and runs on unscaled time.
- Reworked the Outpost Core popup (Prompt-B 133) into a connected-facility list plus a live CCTV view rendered by one reusable preview camera. TV power-on / power-off animation (~1.3s in, ~0.26s out), fast eased camera moves with a CCTV-only afterimage, vertical scroll with keyboard selection follow, and live list updates while open. Facility connection, power, interaction range and save data are unchanged; selecting a facility only changes what the CCTV observes.
- Replaced the black facility name bubbles with small cyan hologram name tags (Prompt-B 134): corner-spark / frame-spread / scan-reveal entrance (~0.26s), steady soft border glow, fold-away exit (~0.17s). Display conditions and name data are unchanged. The Outpost Core CCTV shows one tag for the selected facility only, in its own overlay clipped to the CCTV screen: the old tag folds in place on selection, the new one opens once the camera arrives. Main-screen tags are on a layer the CCTV camera does not render, so the two never mix.
- Reworked the power-depleted rescue popup and the over-the-head rescue button (Prompt-B 135). The popup uses the cyan frame / navy panel look with a red warning title, a column-aligned cost table (resource icon + name / deducted / owned → remaining after rescue), a ~0.5s broken-frame glitch entrance, light edge glitches while open, and a ~0.3s strong glitch exit. After the exit finishes, a small hologram appears over the player (title, rescue pictogram, R keycap): hover lifts the figure and the arrow, and the keycap pulses every 3–5s as a visual hint only. Clicking the hologram or pressing R reopens the same popup with refreshed costs; only the popup's rescue button runs the existing rescue. Rescue cost, destination, resource deduction and save rules are unchanged.
- Unified the Surface Base resource sale window and the Settlement Console into one shared sell popup (Prompt-B 136). Each row (resource / owned / unit price / quantity / gold to receive) has −, +, +5, +10 (cumulative) and Max controls clamped to the sellable amount; "Select max" and "Reset selection" only change the planned quantities, and the Sell button sells every selected resource in one atomic transaction (one inventory reduction, one gold grant, one autosave request). The header shows current gold and a cargo gauge of current vs. after-sale weight (real unit weights). Entrance (~0.72s): coins stack into the gold icon, a five-strip compressed panel approaches from the distance and unfolds like an accordion from the center, then settles flat while content fades in and the icon moves to the gold display; exit (~0.34s) fades content, re-folds the strips and recedes. A successful sale sends short streaks from the sold rows to the gold summary and counts the gold display up. Each screen keeps its own rules: Surface Base can sell the rare engine fuel by explicit quantity but excludes it from Select max and applies the gold bonus per line; the Settlement Console still refuses rare items and applies the bonus to the total, and it still closes when the player leaves range.

## Save compatibility

- Current save schema: v2.
- Game version is recorded in each save. Back up user saves before testing migrations or a new release build.
