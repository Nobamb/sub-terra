# 여자 모션 표면 흰 반점 후속 정리

## 범위와 결과

- 승인된 `female-ladder-matte-surface-pose03-v1-20261104.png`의 무광 주황·회색 명암을 기준으로 사다리 나머지 4자세를 보정. 전체 5자세의 표면 표현을 같은 시트에서 맞춘 새 검토본이다. 승인된 단독 pose03 원본은 보존했다.
- 같은 기준을 채굴 11자세와 걷기 8자세에 적용했다. 기존 게임용 에셋·시험 창 연결 경로는 교체하지 않았다.
- 수정 대상은 캐릭터 내부 헬멧·장비·장갑·신발의 흰 광택 반점이다. 눈의 흰자·청록색 장비 화면·피부는 구분해 유지했다. 헤드램프는 확산광 없는 연한 노란 렌즈로 표현했다.
- 기존 자세를 이미지 편집 도구로 표면 재도색한 결과이며, 원본 픽셀·윤곽·비율이 완전히 동일하다는 뜻은 아니다. 새 부위 리깅·관절 늘리기·겹쳐 섞기 없이 전신 셀로 처리했다.

## 파일

- 원화: `work_process/images/issue266/female-{ladder,mining,walk}-matte-sheet-v1-20261104.png`
- 검토 폴더: `work_process/images/issue266/female-matte-surface-review-20261104/`
- 폴더 내 `ladder/`, `mining/`, `walk/`: 원시 셀·외부 잔점 정리 셀·1024 정렬 PNG. 소스와 렌더용 셀을 구분한다.
- `ladder.gif`, `walk.gif`, `mining.gif`, `mining-finish.gif`: 공통 팔레트·디더링 없는 GIF. 채굴 마무리는 한 번 재생한다.
- 각 `*-lossless.png`: 색 손실 없는 APNG 비교본.
- `*-contact-white.png`, `*-contact-black.png`: 전체 자세 외곽·표면 확인용.
- `*-source-map.json`, `*-sequence.json`, `*-verification.txt`, `encoding-comparison.txt`: 출처 해시·순서·검사 기록.
- 재생성 도구: `work_process/tools/female-matte-surface-review-20261104.ps1`. 기존 로컬 `LandingRecoveryReview-20261103.cs`, `SpriteMotionAlignment-20261103.cs`와 로컬 ffmpeg를 사용한다. 도구 자체는 이미지 서비스 호출 없이 제공된 생성 시트의 추출·외부 알파 정리·미리보기 출력을 담당한다.

## 확인한 내용

- 24자세의 흰/검정 배경 접촉 시트를 육안 비교: 헬멧의 크림색 덩어리, 주황 손목·팔·다리의 작은 흰 점, 신발의 강한 흰 선이 제거·완화됨. 두 손과 두 다리, 드릴 양손 그립 및 불투명 치마의 가림 상태를 확인했다.
- 모든 셀이 경계 여백을 확보하고 잘림 검사 통과. 캐릭터 표면 수정은 이미지 도구에서 수행했고, 후처리는 외부 잔점/극미량 알파 정리와 전신 단위의 균일 확대·이동만 수행했다.
- GIF 4개·APNG 4개 모두 디코딩 통과. 디더링 사용 안 함. 동일 프레임끼리 GIF와 APNG를 비교한 SSIM은 약 0.9979~0.9989로, 큰 변환 차이는 검출되지 않았다. 이 수치는 자연스러운 동작이나 깜빡임 부재를 증명하지 않는다.
- 사다리 5fps, 걷기 8fps, 채굴 반복 8fps·마무리 6fps는 검토용 속도다. 실제 게임 타이밍으로 확정하지 않았다.

## 미검증 / 다음 검토

1. GIF 또는 APNG 반복 재생에서 색·명암과 얼굴/장비 윤곽 변화가 거슬리지 않는지 팀원 리뷰.
2. 생성 편집으로 조금 달라진 얼굴·장비·치마 윤곽을 채택해도 되는지 검토. 최종 원화 확정으로 간주하지 않는다.
3. 채택 후 실제 게임에서 손·발·드릴 접점 및 걷기 속도 확인. 이번에는 Unity 실행·Console·빌드 검사를 하지 않았으며 게임 적용도 하지 않았다.

작성 당시에는 로컬 검토본이었으며, 이후 사용자가 이 보정 결과의 커밋·푸시를 요청했다. 게시 범위는 표면 보정 원화·최종 정렬 PNG·미리보기·기록·필수 후처리 도구다. 재생성 가능한 raw/clean/clip/finish 중간 PNG는 제외한다. 앞서 남아 있던 걷기/접점 시험의 Editor 코드와 별도 작업 문서는 포함하지 않는다.

다음 작업 순서: 대기·진입·정지 자세도 같은 표면으로 맞춰 전환 시 광택 차이를 줄이기 → 채택된 모션의 크기·손발 접점 조율 → 게임 적용·캐릭터 선택·저장 연결. 정식 적용 전까지 게임 동작은 미검증으로 유지한다.
