# 여자 사다리 캐릭터 표면 흰 반점 정정

사용자가 지적한 것은 배경 투명화 잔점만이 아니라 캐릭터 내부의 흰 광택 반점이다. 앞선 배경·외곽 정리로 이 문제가 해결됐다고 판단하면 안 된다.

- 대상: 헬멧의 크림색 덩어리와 흰 선, 주황 손목·팔·다리 장비의 작은 흰 점, 장갑·신발의 과한 흰 반사.
- 방법: pose-03 원화를 이미지 도구로 편집해 흰 광택을 줄이고 주황/노랑·회색의 넓은 명암으로 교체. 배경만 정리하는 작업과 구분한다.
- 결과: images/issue266/female-ladder-matte-surface-pose03-v1-20261104.png
- 비교: images/issue266/female-ladder-surface-comparison-20261104.png
- 육안 확인: 한 장에서 헬멧 흰 덩어리와 장비의 흰 점이 제거되고 신발의 강한 흰 선이 완화됨. 생성 편집이므로 원본 픽셀·윤곽의 완전 동일성은 보장하지 않는다.
- 남은 작업: 나머지 네 자세에 같은 표면 기준 적용, 프레임 간 색·윤곽 일관성과 반복 재생 검수. 전체 GIF 해결은 미검증.
- 사용자 승인: 같은 자세의 무광 표면 수정 시안을 채택하고 커밋·푸시 요청. 게임 적용은 하지 않으며 기존 모션 원본은 보존.
