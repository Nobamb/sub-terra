## 재현 계약·가설
- 신고: 메인 메뉴 네 버튼 위에 마우스를 올려도 소리가 안 남.
- 기대: 클릭 가능한 각 버튼 진입마다 UiHover 1번, 머무름 동안 반복 없음, 재진입/설정창 종료 뒤 복구. 비활성/음소거/효과음0은 무음.
- 가설 A: 연결 누락/중복 또는 레이캐스트 차단. 정상 메뉴 입력에서 실제 EventSystem 상위 hit와 네 버튼의 요청 횟수를 비교했다.
- 가설 B: 설정창 재열기 후 입력/구독이 끊김. 실제 합성 마우스로 설정창을 열고 Esc로 닫은 다음 재진입을 검사했다.
- 가설 C: 재생기/라이브러리/음량 게이트. 요청과 StartedCount를 따로 세고 마스터/효과음 음소거 및 효과음0을 구분했다.
- 가설 D: 부팅 중 입력 차단, Windows 장치/믹서/과거 빌드 차이. 이번 작업에서는 미검증이며 원인 확정하지 않는다.
