# #266 대기 → 걷기 진입 원화 검토

- 선행 착지 회복 작업은 사용자 승인으로 **47b3469e** 커밋·푸시. 기존 PR #270 브랜치 `codex/issue-266-character-selection`에 반영했다.
- 이후 이번 진입 보완은 검토용으로 제작했고, 후속 요청에서 커밋·푸시 승인을 받아 같은 브랜치에 게시한다. 게임 적용·캐릭터 선택·슬롯 저장은 아직 진행하지 않았다.

## 제작 범위

- 기존 정렬본의 `damage/pose-01.png`(대기 참고)와 `walk/key-01.png`(첫 걸음)를 참고해 전신 중간 자세 2장을 built-in imagegen으로 새로 그렸다.
- 진입 1: 가까운 다리의 짧은 전진과 약한 무릎 굽힘, 반대 팔의 낮은 전진. 진입 2: 보폭과 팔 흔들림을 더 키워 첫 걸음으로 연결한다.
- 여자 외형의 짧은 치마·갈색 다리 덮개·허벅지 청록 장비·포니테일을 유지했다. 기존 원화를 부위별로 잘라 붙이거나 신체를 늘리지는 않았다.
- `female-walk-entry-v1-alpha-20261103.png` 원본 시트와 `female-walk-entry-prompt-20261103.txt` 프롬프트를 보존했다.
- 승인된 배경 정리 범위에서 셀별 외부의 분리 알파 픽셀만 제거했다(1675/1153px). 전신 연결 영역 내부 RGB/알파는 보존했다. 기존 사다리 흰 잔점 문제와는 별개다.
- 두 자세에 동일 전신 배율 적용. 기준 헬멧 주황 영역 폭161px, 허리 버클 가로 중심512, 바닥 y800에 정렬했다. 몸통·얼굴 자체의 원화 차이까지 해결됐다는 뜻은 아니다.
