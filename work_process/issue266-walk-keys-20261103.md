- 여자 원본의 얼굴·헬멧·포니테일·치마·갈색 다리 덮개·허벅지 장비를 기준으로 전신 4자세를 제작했다. 기존 남자 Walk 1/11/21/31은 동작 참고, 여자 채굴 마스터는 의상/명암 참고다.

- 초기 결과의 마지막 통과 자세에서 허벅지 장비가 지지 다리에 남는 오류를 발견해, 들어 올린 가까운 다리를 따라가도록 보정했다.

## 순서와 검토 목적

1. 가까운 다리 앞쪽 착지, 반대 다리 뒤쪽.
2. 가까운 다리 지지, 반대 다리가 앞으로 통과.
3. 반대 다리 앞쪽 착지, 가까운 다리 뒤쪽.
4. 반대 다리 지지, 가까운 다리가 앞으로 통과.

1→2→3→4→1, 2.5fps/1.6초 주기의 **느린 핵심 자세 비교용**이다. 중간 자세가 없으므로 부드러운 전체 걷기 완성본이 아니다. 기존40장 런타임 속도를 수정하지 않았다. GIF는 무디더링 공통 팔레트이며 실제 게임용 원본은 알파 PNG다.

## 확인한 항목

- 흰색/검정 배경에서 외부 잔점·얼룩, 치마 밑단, 신발 외곽과 허벅지 장비 위치를 비교했다.
- 배경 정리 과정의 불투명 내부 RGB 변경0, 셀 외부4px 여백 비투명 픽셀0. 서로 다른 원화4장/GIF4프레임, GIF/APNG 디코딩 정상.
- 배경 도구를 사각형2×2 시트에도 사용할 수 있게 확장했다. 기존 채굴 마스터를 다시 처리해 이전 채굴 출력과 SHA-256이 동일함을 확인했다.
- 원화에서 보이는 하단 왼쪽 어깨 원근·팔 가림 순서와 자세별 머리 높이의 미세 차이는 리뷰 대상으로 남겼다. 모든 외형이 완전히 같다고 보고하지 않는다.

## 다음 순서 / 미검증

- 사용자가 이4자세를 기준으로 커밋·푸시 후 중간 자세와 점프·피격·쓰러짐 제작을 이어가도록 지시했다. 단순 복제나 왕복 재생으로40장을 채우지 않는다.
- **미검증:** 실제 반복 재생 인상, 지지 발 미끄러짐/게임 속도 일치, 인게임 크기·충돌·전환, 전체40장 연결.
- 그다음 점프 → 피격·쓰러짐 원화를 제작하고, 전체 모션의 크기/접점이 맞은 후 캐릭터 선택·저장을 연결한다. 아직 이 단계들은 시작하지 않았다.
- 채굴 후속 리뷰와 기존 사다리 흰 잔점은 별도 미해결 항목이다.
- Unity/게임 Assets/씬/프리팹/저장 코드 변경 없음. 게임 적용은 하지 않는다. 후속 요청으로 이 핵심4자세 단계의 커밋·푸시 승인을 받았다.
