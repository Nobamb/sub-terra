# B-211 점프 손맛 (가변 점프 + 늘어남·찌그러짐 + 착지 먼지 + 착지 흔들림)

## 목표
지금 점프는 누르는 순간 항상 같은 높이로 뛰고, 착지할 때 소리 말고는 반응이 없다. 손맛을 살리는 4가지를 넣는다.
1. **가변 점프:** 짧게 누르면 낮게, 길게 누르면 지금처럼 높게.
2. **늘어남·찌그러짐(squash & stretch):** 뛸 때 위로 살짝 늘어나고, 착지할 때 옆으로 살짝 찌그러졌다가 돌아온다.
3. **착지 먼지:** 착지한 발밑에서 흙먼지가 조금 일어난다.
4. **착지 화면 흔들림:** 높은 곳에서 떨어져 착지할 때만 아주 짧고 약하게.
관련: #265(이 작업), #167(점프 선입력·코요테 타임, 완료), #264(점프 4단계 그림, B-175), #392(B-210 피격 경직), #359(B-207 피해 글리치), 완충판(`CushionPad`).

## 현재 상태 (main `a694aca`)

  - `TryApplyJump()`은 땅에서 뛸 때와 사다리에서 뛸 때(`ExitLadderMode` 후) 모두 `ApplyJumpImpulse()`를 부른다.
  - `ApplyJumpImpulse()`는 `LastJumpLaunchSpeed`를 기록하고, `JumpCount++` 한 뒤 Impulse를 가한다.
  - 경직 중에는 `AcceptsControl`이 false라서 점프가 막힌다.
- 입력: `PlayerController`가 `Player/Jump`의 `started`에서만 `RequestJump()`를 부른다. **떼는 입력은 아직 받지 않는다.**
- 화물: `CargoLoadEffectPolicy.EvaluateJumpMultiplier`는 가득 찼을 때 `FullLoadJumpMultiplier 0.75`다. 이때 최대 높이는 약 1.16칸이다.
- 착지: `PlayerSurvivalController.TrackFall()`가 최고점과 착지 높이의 차이(`distance`), 사다리 사용 여부(`ladderExempt`), 완충판 여부(`IsOnStableLandingPlatform`)를 구해 `ResolveLanding()`을 부른다.
  - 착지음 기준은 `PlayerMoveSfxGate.MinLandHeight 0.3`이다.
  - 낙하 피해의 최소 높이 기본값은 `minimumFallDamageHeight 10`이다.
  - 디버그 `falling`은 `SimulateFall` → `RunWithoutDamageCameraShake`로 처리한다.
- 흔들림: `PlayerCameraFollow.RequestShake(amplitude, duration)`. 기본값은 0.28초이고, 피해 흔들림은 0.22다. 줄인 움직임(`AccessibilityPreferences.ReduceMotion`)이면 무시한다. 겹쳐 부르면 큰 값(Max)을 쓴다.
- 그림: Player 아래 `VisualRoot`(localScale 0.95)가 있다.
  - `PlayerFacing`은 `VisualRoot.localScale.x`의 부호만 바꿔 좌우를 뒤집는다(`Abs*방향`).
  - `PlayerAnimationController.ApplyJumpBob`은 SpriteRenderer 쪽 localPosition.y를 움직인다.
  - 점프 그림 단계는 `PlayerJumpAnimationSequence`(준비·상승·꼭대기·낙하·착지 역재생)가 맡는다.
- 완충판: 높이 0.8~1.8칸, 0.25 간격. 완충판 위 착지는 피해가 줄어든다(`CushionLandingDamageRatio`).

## 할 일
### 1. 가변 점프
1. `PlayerController`에서 `Player/Jump`의 `canceled`를 받아 `PlayerMovement.ReleaseJump()`(새 함수)를 부른다. 설정 창이 열려 있을 때의 처리는 `started`와 같게 한다. 키를 바꿨을 때(`ControlTerminalBindings`)도 같은 액션을 쓰는지 확인한다.
2. `PlayerMovement`는 점프 버튼을 누르고 있는지(`jumpHeld`)를 기억한다. 땅 점프(선입력·코요테 포함)로 뜬 뒤 **상승 중에** 버튼이 떨어져 있으면 위 속도에 `jumpReleaseVelocityMultiplier = 0.5`를 **한 번만** 곱한다.
3. **최소 높이 보장:** 지금 위치 + 자른 속도로 더 올라갈 높이(`v²/2g`)가 `minJumpApexHeight = 1.1`칸보다 낮으면 아직 자르지 않는다. 기준을 넘는 순간 자른다.
   - 계산해 보면 빈 몸은 뜬 뒤 약 0.1초, 화물 85%는 약 0.16초, 가득 찬 화물(0.75)은 약 0.28초가 지나야 자를 수 있다. 가득 찬 화물은 사실상 거의 가변이 없다.
   - 1칸 턱은 짧게 톡 눌러도 항상 올라가야 한다.
   - 최대 높이가 1.1보다 낮은 배율이면 자르지 않는다.
4. 떨어지는 중에 떼면 아무 일도 없다. 자르기는 점프 한 번에 한 번만 한다. 착지하거나 다음 점프를 하면 상태를 초기화한다.
5. 선입력으로 뛴 점프가 이미 손을 뗀 상태라면, 뜨자마자 3번 규칙으로 낮게 뛴다(톡 친 낮은 점프).
6. **사다리에서 뛰기는 자르지 않는다**(지금 높이 그대로). 사다리를 벗어나는 높이가 바뀌면 안 되기 때문이다. 보고서에 적는다.
7. 경직(B-210) 중에는 점프가 시작되지 않는다. 공중에서 경직이 걸려도 자르기 규칙은 물리값이라 그대로 둔다.
8. 완충판 높이(0.8~1.8)는 길게 눌렀을 때 지금과 똑같이 닿아야 한다. 가득 찬 화물로 0.8 완충판에 올라설 수 있어야 한다.
9. `PlayerJumpAnimationSequence`가 잘린 점프에서도 꼭대기→낙하로 자연스럽게 넘어가는지 확인한다. `LastJumpLaunchSpeed`만 믿고 상승 그림에 멈춰 있으면 실제 세로 속도를 기준으로 고친다.
10. 값은 인스펙터 필드로 둔다(`jumpReleaseVelocityMultiplier 0.5`, `minJumpApexHeight 1.1`, `variableJumpEnabled true`).

### 2. 늘어남·찌그러짐
1. Gameplay에 새 컴포넌트 `PlayerSquashStretch`를 만든다. 프리팹은 손으로 고치지 않고, 빌더나 `AddComponent`로 붙인다. 이 컴포넌트는 `VisualRoot`의 **크기만** 바꾼다. 충돌체와 물리는 바꾸지 않는다.
2. 기본 크기(0.95)에 곱하는 방식이다. x는 **크기만** 바꾸고 부호(좌우)는 `PlayerFacing`이 정한 그대로 둔다. 같은 프레임에 둘이 싸우지 않게 실행 순서를 정한다.
3. **발 기준:** 크기가 바뀌어도 발바닥 위치(그림 바닥, 대략 GroundCheck y -0.37 근처)가 땅에서 뜨거나 파묻히지 않게 `VisualRoot`의 localPosition.y를 보정한다. `ApplyJumpBob`(SpriteRenderer 쪽 위치)와 더해져도 어긋나지 않게 한다.
4. 기본값(그림에 이미 웅크림·늘어남이 있어서 이슈 예시 0.7/1.3보다 약하게 시작한다):
   - 점프 순간 늘어남: 가로 0.88 / 세로 1.12.
   - 착지 찌그러짐: 낙하 0.3칸에서 가로 1.05 / 세로 0.95, 3칸 이상이면 최대 가로 1.18 / 세로 0.82. 그 사이는 선형이다.
   - 돌아오는 시간은 `squashRecoverSeconds = 0.12`. 부드럽게 1로 돌아오고 튕김(오버슈트)은 없다.
5. 세기 배율 `squashStrength`(0~1.5, 기본 1)를 하나 둔다. 0이면 효과가 꺼진다. 줄인 움직임에서도 이 효과는 유지한다(작은 캐릭터 동작이기 때문).
6. 0.3칸 미만 착지, 사다리를 타고 내려온 착지(`ladderExempt`), 사다리 위, 경직 그림, 기절이나 실패 상태에서는 찌그러짐을 주지 않는다. 진행 중인 찌그러짐은 즉시 1로 되돌린다.
   - 피해 착지도 찌그러짐은 준다. 피격 그림 위에서 0.12초 동안 짧게 보인다.

### 3. 착지 먼지
1. 착지 판정은 `TrackFall()`의 `ResolveLanding`과 같은 곳에서 이벤트 하나로 나간다. 예: `Landed(distance, ladderExempt, stable, damaged)`. 효과들은 이 이벤트를 구독한다. 디버그 `falling`도 같은 이벤트를 쓴다.
2. 먼지는 코드로 만든다. 작은 원이나 사각 스프라이트를 생성하거나 풀링하고, 새 그림은 없다.
   - 색: 광산 흙 톤(예: `#6B5644` 근처, 불투명도 0.5~0.6)으로 은은하게.
   - 모양: 발 양옆으로 퍼지고, 살짝 떠올랐다가 0.35초 안에 사라진다.
   - 정렬: 캐릭터 뒤나 같은 층에서 땅 바로 위에 그린다. 타일 위에 가려지지 않게 한다.
3. 높이에 따른 크기:
   - 0.3칸 미만: 없음.
   - 0.3~1칸: 작게, 2~3알.
   - 1~3칸: 중간.
   - 3칸 이상: 최대, 6~8알.
   - 피해 착지는 최대 크기로 한다.
4. 사다리를 타고 내려온 착지(`ladderExempt`)에는 먼지가 없다. 완충판 위에서는 한 단계 작게 낸다.
5. 줄인 움직임에서도 유지한다. 개수 상한과 풀링으로 연속 착지에서도 쌓이지 않게 한다.

### 4. 착지 화면 흔들림
1. **3칸 이상** 낙하해서 착지했고 **피해가 없을 때만** `RequestShake`를 부른다.
   - 세기는 3칸에서 0.05, 8칸 이상에서 0.10(피해 흔들림 0.22보다 훨씬 약하게). 시간은 0.1초.
2. 피해 착지는 기존 피해 흔들림만 쓴다(겹치지 않음). 완충판 착지와 사다리 착지는 흔들지 않는다. 디버그 `falling`(흔들림 없이 실행)에서도 흔들지 않는다.
3. 줄인 움직임에서는 흔들지 않는다(`RequestShake`가 이미 막지만, 착지 쪽에서도 부르지 않는다).
4. Gameplay→App 참조 규칙을 지킨다. 지금 피해 흔들림이 카메라에 닿는 경로를 그대로 쓴다.

## 테스트 (플레이어 시점)
1. 평지에서 Space를 아주 짧게 톡 친다 → 낮게 뛰지만 **1칸 턱 위에는 올라선다.** 길게 누른다 → 지금처럼 약 2칸까지 뜬다.
2. 누르는 시간을 다르게 해서 여러 번 뛴다 → 높이가 자연스럽게 달라지고, 공중에서 툭 끊기는 느낌이 거슬리지 않는다.
3. 떨어지는 중에 Space를 떼거나 다시 누른다 → 아무 변화 없음. 공중 연타도 안 된다.
4. 착지 직전에 톡 누른다(선입력), 그리고 턱 끝에서 살짝 벗어난 뒤 누른다(코요테) → 둘 다 뛴다.
5. 화물을 가득 채운다 → 짧게 눌러도 1칸 턱에 오르고, 0.8 높이 완충판에 오른다. 길게 누르면 지금과 같은 높이.
6. 사다리에서 점프해 뛰어내린다 → 지금과 같은 높이로 벗어난다.
7. 뛸 때 캐릭터가 위로 살짝 늘어나고, 착지할 때 옆으로 찌그러졌다가 0.1초쯤에 돌아온다. 좌우를 바꿔도 방향이 유지되고, 발이 땅에서 뜨거나 묻히지 않는다.
8. 0.3칸 미만의 작은 턱에서 내려선다 → 먼지와 찌그러짐이 없거나 아주 작다. 2칸에서 떨어진다 → 작은 흙먼지. 5칸에서 떨어진다 → 더 큰 먼지와 아주 짧고 약한 흔들림.
9. 사다리를 타고 내려와 바닥에 닿는다 → 먼지, 찌그러짐, 흔들림이 모두 없다(소리도 지금처럼 없음).
10. 디버그 `falling 30m` → 피해 흔들림 하나만 보인다(착지 흔들림은 겹치지 않음). 먼지는 크게. `falling 30m cushion` → 흔들림 없음, 먼지는 작게.
11. 설정에서 줄인 움직임을 켠다 → 착지 흔들림이 없다. 먼지와 찌그러짐은 그대로 있다.
12. 가스 지대에서 `hitgas 3` → 경직 0.4초 동안 점프가 안 되고, 풀리면 바로 뛸 수 있다. 공중에서 낙하 피해로 경직되어도 착지 효과가 정상이다.
13. `gender female`로 바꿔도 1~8이 똑같다.
14. 새 효과음이 없는지, Unity Console에 새 빨간 오류가 없는지, EditMode 테스트에 새 실패가 없는지 본다. 가변 점프의 최소 높이 계산은 EditMode 테스트로 남긴다(배율 1 / 0.85 / 0.75).
