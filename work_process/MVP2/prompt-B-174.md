# B-174 사다리 위 채굴 동작 추가 (이슈 #264)

## 목표
- 사다리에 매달린 채 한 팔로 사다리를 잡고 다른 팔로 드릴을 쓰는 새 동작(24장)을 넣는다. 지금은 사다리 위에서 캐면 바닥 채굴 그림이 나온다.
- 베이스: 최신 `MVP2-fix117`(PM 확인 `3d0bc4bf`, 2026-10-29 11:12 KST, B-172·채굴 딜레이 수정 포함). 새 브랜치 **`MVP2-fix118`**. main에는 아직 fix116·117이 머지되지 않았다.

## 절대 규칙
1. 바닥 채굴 규칙은 그대로: 한 번 누르면 블록이 깨질 때까지 캔다. 버튼을 떼도 취소하지 않는다. fix117의 채굴 딜레이 수정(깨지는 즉시 드릴 회수 60fps, `PlayerMiningAnimationSequence`)과 바닥 채굴·쓰러지기·걷기·대기·점프·사다리 그림과 속도는 바꾸지 않는다.
2. 채굴 판정·시간·에너지·효과음은 바꾸지 않는다. 막는 것은 "사다리 위에서 위·아래 블록 시작"과 아래 취소 조건뿐이다.
3. 사다리 등 그림 비반전(B-172)은 유지한다. 예외는 이번 사다리 채굴 동작으로 **왼쪽 블록을 팔 때만** 좌우 반전.
4. 그림은 다시 그리거나 부위별로 고치지 않는다. 한 배율·한 위치 이동만. 드릴 끝 잘림은 사용자가 감수하기로 했다(원본 그대로).
5. 줄 번호는 fix117 기준 근사(~). 못 찾으면 "못 찾음"으로 보고한다.

  - 발 아래 끝 y 914~923, 가로 중심 440~454, 키 901~923px.

  - 드릴 끝이 오른쪽 경계에서 잘림: 13~16, 21~24번(15~25px). 1번은 헬멧 꼭대기가 위 경계에 닿음. 그대로 쓴다.

## 2. 방향
1. 사다리 위(사다리 그림이 보이는 상태, `IsClimbing` 또는 사다리 접촉 중 사다리 그림 표시)에서는 **같은 줄의 왼쪽·오른쪽 블록만** 채굴을 시작한다.
2. 위·아래 방향키, 마우스로 위·아래(또는 대각선 다른 줄) 블록을 고르면 시작하지 않는다(실패 표시·소리 없이 무시. 지금 코드에 "잘못된 목표" 표시가 있으면 그것을 따른다). 바닥에서는 지금처럼 위·아래 채굴 가능.
3. 오른쪽 블록이면 그림 그대로, 왼쪽 블록이면 이 동작만 좌우 반전(`PlayerFacing`이 사다리 채굴 중에는 목표 블록 쪽 방향을 따름). 채굴이 끝나거나 취소되면 다시 사다리 비반전.
4. 반전 기준은 `MiningSystem.ActiveCell`과 플레이어 칸의 가로 차이. `FacingDirection`만으로 정하지 않는다.

## 3. 재생 (그림 번호 1부터)
1. 시작: 1→12 한 번, **24fps**(0.5초).
2. 파는 중: 13→16→13 왕복, **12fps**. 블록이 안 깨지면 계속.
3. 블록이 깨지는 순간(`Completed`): 남은 프레임 없이 바로 17→24 **60fps**(약 0.13초) → 사다리 자세(사다리 그림 0번 또는 이동 중이면 해당 사다리 그림)로 복귀.
4. 즉시 취소(모션 바로 끊고 채굴도 `CancelMining`): 위·아래 입력, 사다리를 벗어남(사다리 범위 밖, `IsClimbing`·접촉 해제), 점프. 역재생 없이 바로 사다리/점프/낙하 그림.
5. 그 밖의 진짜 취소(`Cancelled` 이벤트: 설정 창 열기, 방향 변경 등): 현재 프레임에서 1번까지 빠르게 역재생(최대 약 0.3초) 후 사다리 자세. 버튼을 떼는 것만으로는 취소하지 않는다(규칙 1).
6. 피격·쓰러지기는 지금 우선순위 그대로(쓰러지면 즉시 쓰러지기). 피격 뒤에도 채굴 중이고 사다리 위면 13번부터 이어 간다.
7. 연속 채굴: 마무리(17~24) 중에 새 채굴이 시작되면 1번부터. 취소 직후 0.15초 안에 같은 쪽으로 다시 시작되면 시작 구간 없이 13번부터.
- 순서 계산은 Unity와 분리한 클래스(예: `PlayerLadderMiningAnimationSequence` 또는 기존 클래스에 설정 묶음 추가)로 만들어 시간·이벤트만으로 테스트한다. fps·구간 번호는 프리팹 설정값.
- 바닥 채굴과 사다리 채굴이 서로 넘어갈 때(사다리에서 바닥에 닿는 순간 등)는 취소 규칙 4번을 따른다.

## 사용자 테스트 가이드 (보고서에 그대로 넣기)
디버그 터미널: 플레이 중 **Ctrl + `**(1 왼쪽 키). `spawn copper`(또는 iron·gas)는 바라보는 쪽 옆 칸에 블록을 놓는다. 사다리 위에서 왼쪽을 보고 쓰면 왼쪽에 놓인다.
1. 사다리를 설치하고 중간쯤 올라가 멈춘다. 오른쪽에 블록이 있으면 오른쪽을 판다 → 한 팔로 사다리를 잡고 다른 팔로 드릴을 꺼내 오른쪽을 판다.
2. 같은 자리에서 왼쪽 블록을 판다 → 같은 동작이 좌우만 뒤집혀 나온다.
3. 단단한 블록(`spawn iron`)을 판다 → 드릴을 대고 있는 동작이 끊김 없이 반복된다.
4. 블록이 깨지는 순간 → 바로 드릴을 거두고 사다리 자세로 돌아온다(멈칫하는 시간 없음).
5. 파는 중 위·아래 키를 누른다 → 동작과 채굴이 바로 멈추고 사다리를 오르내린다.
6. 파는 중 점프하거나 사다리 밖으로 나간다 → 동작과 채굴이 바로 취소된다.
7. 파는 중 마우스 버튼을 뗀다 → 블록이 깨질 때까지 계속 판다(바닥과 같음).
8. 사다리 위에서 위·아래 블록을 파려고 한다 → 시작되지 않는다. 바닥에서는 위·아래 채굴이 그대로 된다.
9. 사다리 위에서 블록 여러 개를 연달아 판다 → 매번 자연스럽게 시작하고 크기·위치가 튀지 않는다.
10. 사다리 그림 ↔ 사다리 채굴 그림이 바뀔 때 크기와 발 위치가 같다. 드릴 끝이 잘린 프레임(원본 그대로)이 얼마나 눈에 띄는지 적는다.
11. `hp 1` 뒤 사다리 위에서 가스 블록(`spawn gas`)을 판다 → 가스로 쓰러지면 쓰러지기 동작이 바로 나온다(가스가 터지지 않으면 건너뜀).
12. 바닥 채굴(시작 → 파기 → 깨지면 바로 회수)이 fix117과 똑같다.
13. Unity Console에 새 빨간 오류·노란 경고가 없다(기존 URP stereoTargetEye, obsolete, 라이선스 로그 제외).
