## 할 일
### 1. 공통 주기 장치 `FacilityIdleAnimation` (Gameplay/Building)
1. 시설이 생길 때 런타임에서 붙인다. 붙이는 곳은 `BuildingInstance.Initialize`/`Awake` 근처나 설치·복원 경로다. 프리팹에 손으로 넣지 않는다. 시설별 동작은 BuildingId로 고른다(조명, 충전기, 보건소, 보관함, 자원 정산기, 전진기지, 포탈).
2. 인스펙터에서 조절할 수 있는 값(PM 조정용 상수는 한곳에 모은다): `periodSeconds = 30`, `periodJitterSeconds = 3`(매 주기 ±3초 무작위), 처음 시작은 설치·복원 뒤 `3~30초` 사이 무작위, 연출 길이는 아래 표.
3. **엇갈림:** 무작위 값은 인스턴스마다 따로 뽑는다. 같은 종류끼리 시작 시각이 0.5초 이내로 겹치면 한쪽을 1~2초 밀어 준다.
4. **건너뛰는 경우**(그 주기만 건너뛰고 다음 주기를 다시 기다린다): 전력 없음, 건설·켜짐 연출 재생 중, 시설 비활성·이동·철거 중, 게임 정지(`Time.deltaTime`이라 timeScale 0이면 멈춤). 포탈은 주기 연출이 없고 회전만 한다(3번).
5. 연출 도중에 전력이 끊기거나 시설을 옮기거나 철거하면 0.15초 안에 사라지게 하고 원래 그림으로 되돌린다. 남은 조각이 없어야 하고, 잘라 만든 Sprite는 Destroy한다.
6. 덧그림은 시설 그림 바로 위 순서에 그린다. 플레이어나 UI 위로 올라오지 않는다. 시설 크기(lossyScale)를 따라간다.
7. **줄인 움직임에서도 주기 연출과 포탈 회전은 그대로 둔다.** 화면 전체가 움직이는 연출이 아니기 때문이다.
8. 저장할 상태는 없다. 이어하기 뒤에는 3번 규칙으로 처음부터 다시 시작한다.

### 3. 포탈 내부 홀 회전 (주기 아님)
1. **켜짐(웜홀 그림)에서만** 돈다. 원형 `SpriteMask`(홀보다 살짝 작게) 안에서 웜홀 그림 복사본과 코드로 그린 소용돌이 줄기(2~3갈래, 청록, 알파 0.25)가 천천히 돈다. 웜홀만 돌리면 거의 보이지 않는다. 링 테두리는 가리지 않는다. 속도는 8초에 한 바퀴, 시작 각도는 시설마다 무작위.
2. **꺼짐(`PortalInactive`, 빈 링)에서는 소용돌이를 그리지 않고 링을 그대로 둔다.** 빈 링 안에 홀이나 소용돌이를 넣지 않는다. 다시 켜지면 같은 각도에서 회전을 이어 간다.
3. 포탈 이동, 판정, 탈출 연출, 그림 전환 코드는 바꾸지 않는다. 탈출 연출 중에도, 켜져 있으면 회전은 이어진다. 건설 연출 중에는 완성본이 가려지므로 회전도 숨긴다.

### 4. 디버그 명령 `idlefx`
`DeveloperDebugFacilityIdleCommands.cs`(App)를 새로 만들고, 사용법을 help에 표시한다.
- `idlefx now`: 화면에 있는 켜진 시설이 연출을 바로 한 번 재생한다. 엇갈림은 무시한다.
- `idlefx now <light|charger|clinic|storage|settlement|outpost>`: 그 종류만 재생한다.
- `idlefx period <초>`: 이번 실행 동안만 주기를 바꾼다(최소 2초, 저장 안 함). `idlefx period reset`은 기본값으로 되돌린다.
- `idlefx`만 입력하면 시설별로 남은 시간 목록을 보인다.

## 테스트 (플레이어 시점)
1. 조명, 충전기, 보건소, 보관함, 자원 정산기를 전력 범위 안에 하나씩 짓고 약 1분 지켜본다. 각 연출이 표대로 30초 안팎마다 나온다. 효과음은 없다.
2. `idlefx now`로 6종(+ 포탈 회전)을 보고 위치를 확인한다. 하트는 보건소 탑 위, 금화는 정산기 화면 안, 정전기는 충전기 차양과 번개 화면, 깜빡임은 조명 등불, 와이파이와 바깥으로 퍼지는 파형은 전진기지, 보관함은 뚜껑만 열리고 닫힌다(두 겹·남은 틈 없음).
3. `idlefx period 4`로 바꾸고 같은 시설을 3개씩 지어 1분 지켜본다. 같은 시설끼리 동시에 시작하지 않고 엇갈린다. `idlefx period reset`으로 되돌린다.
4. 전력 범위 밖에 지은 시설은 연출하지 않는다. 연출 중에 코어를 옮기거나 케이블을 끊어 전력을 끊으면 곧바로 사라지고 원래 그림으로 돌아온다.
5. 막 지은 시설은 0.5초 건설 연출과 켜짐 연출이 끝난 뒤에야 주기 연출을 시작한다(겹침 없음). 옮기기나 철거 중에도 조각이 남지 않는다.
6. 포탈은 켜짐에서 내부 홀이 천천히 돈다. 전력을 끊으면 빈 링만 남고 소용돌이는 바로 사라지며 링은 멈춘다. 다시 연결하면 웜홀과 함께 회전이 이어진다. 포탈 이동과 탈출 연출은 지금과 같다.
7. 조명이 깜빡이는 동안 가스 시야 범위는 바뀌지 않는다.
8. Esc로 일시정지하면 연출과 회전이 멈추고, 풀면 이어진다.
9. 설정에서 줄인 움직임을 켜도 주기 연출과 포탈 회전(켜짐)은 나온다. 건설 연출은 지금처럼 나오지 않는다.
10. 시설 20개 이상을 지은 상태로 1분 동안 프레임 저하나 오류가 없고, 저장하고 이어하기 뒤에도 정상 동작한다. 남는 GameObject나 Sprite도 늘어나지 않는다.
11. 설치 가능한 칸, 전력 범위, 상호작용(E), 건설창 아이콘이 이 작업 전과 같다.
12. Unity Console에 새 빨간 오류가 없고, EditMode에 새 실패가 없다. 주기, 엇갈림, 전력 건너뜀, 포탈 켜짐 회전·꺼짐 정지는 EditMode 테스트로 남긴다(`Tick`을 직접 호출).
