# B-209 새 게임 전 광부 선택 화면 (#266)

## 목표
메인 메뉴에서 「새 게임」을 누르면 바로 시작하지 않고 **광부 선택 화면**이 뜬다. 남자/여자 두 광부가 청록 홀로그램 실루엣으로 서 있고, 하나를 고르면 그 광부의 얼굴 윤곽·색이 더 또렷해진다. 「탐사 시작」을 누르면 고른 광부에 원래 색이 차오르고, 글리치 전환 뒤 인트로 영상이 바로 시작된다. 고른 성별은 B-208 진입점으로 새 게임에 넘긴다.
기준: https://github.com/Nobamb/sub-terra/issues/266 (「새 게임 시작 전에 남/여를 고르는 화면」). 그림·저장·가이드는 B-208에서 했다.
#266은 Nobamb 담당이다(mink 작업 금지 댓글 있음). 이번 작업은 PM 요청으로 진행한다.
시안: PM이 `work_process/MVP2/UI-fix-markdown-document/concept-image/main-screen/miner-select-mockup.png`에 넣어 둔다. 배치·분위기는 시안을 따른다.

## 화면 (시안 기준)
- 위: 작은 글씨 `SUB-TERRA OPS`, 큰 제목 `광부 선택`, 그 아래 `MINER REGISTRATION`.
- 가운데: 청록 홀로그램 카드 두 장(왼쪽 `남자`, 오른쪽 `여자`). 각 카드 아래 빛나는 받침대(투사기). 카드 안에 광부 서 있는 그림.
- 아래: 안내 `광부를 선택해 주세요`, 버튼 `탐사 시작`(고르기 전에는 꺼진 회색, 누를 수 없음), `돌아가기`.
- 글자는 `LocalizationService`에 한국어/영어 키로 추가한다(영어 예: `Select Miner`, `Male`, `Female`, `Start Expedition`, `Back`, `Select a miner`).

## 카드 상태 (애니메이션은 코드로 직접 만들어도 된다)
1. **기본.** 두 카드 모두 청록 실루엣(그림 모양만 보이는 단색 청록 + 옅은 스캔라인·약한 깜빡임). 얼굴·옷 구분이 거의 안 된다.
2. **마우스 올림/키보드 포커스.** 그 카드 테두리·받침대가 조금 밝아진다. `UiHover`.
3. **고름.** 고른 카드의 실루엣이 **더 또렷해져** 얼굴 윤곽·머리·옷 경계가 청록 톤 안에서 구분된다(예: 원본 밝기를 청록에 섞기, 0.25초 정도). 안 고른 카드는 살짝 어두워진다. 다른 카드를 누르면 바꿔 고를 수 있다. 안내 글 `광부를 선택해 주세요`는 처음 고르는 순간 **짧게 글리치(지직거림·좌우 어긋남, 약 0.25초)를 내며 사라진다**. 바꿔 고를 때는 다시 나타나지 않는다. 모션 감소여도 이 작은 글자 글리치는 유지한다(화면 전체 연출이 아님). `탐사 시작`이 켜진다. `UiSlotSelect`.
4. **확정(탐사 시작).** 고른 카드에 **원래 색이 아래에서 위로(또는 스캔 줄을 따라) 차오른다**(약 0.5초). `UiConfirm`. 그 뒤 입력을 막고 5로.
5. **글리치 전환.** 화면 전체가 짧게(약 0.4~0.6초) 지직거리며 깨진 뒤 검게 닫히고 인트로 영상이 바로 시작된다. `BriefingGlitchShort`. **모션 감소면 글리치 없이** 짧은 암전(약 0.2초)으로만 넘어간다.
- 초안 상수(검사기에서 조절, 보고서에 적기): `SilhouetteSharpenSeconds 0.25`, `ColorFillSeconds 0.5`, `GlitchSeconds 0.5`, `HintGlitchOutSeconds 0.25`, `ReducedFadeSeconds 0.2`.

## 할 일
1. **흐름 바꾸기.** `새 게임` → (빈 슬롯은 바로, 기존 슬롯은 지금처럼 덮어쓰기 확인) → **광부 선택 화면**. `StartNewGame`은 **탐사 시작을 눌렀을 때만** 부른다. 선택 화면에서 돌아가면 슬롯·저장은 그대로다(덮어쓰기는 탐사 시작 때만 일어난다).
2. **조작.** 마우스 클릭, 키보드 ←/→(또는 A/D)로 카드 이동, Enter/Space로 고름→한 번 더 누르면 탐사 시작, Esc = 돌아가기. 기존 메뉴 입력 방식(Input System)을 따른다. 아무것도 안 고르고 탐사 시작을 누르면 `UiCancelFail`만, 진행 안 됨.
3. **돌아가기.** 선택 화면을 닫고 메인 메뉴로 돌아간다(메뉴 버튼이 다시 눌린다). 연타·전환 중 입력으로 두 번 실행되지 않게 한다.
4. **성별 넘기기.** 확정한 성별을 B-208 진입점으로 `StartNewGame`에 넘긴다. 시작한 게임의 플레이어·가이드 그림이 그 성별이어야 한다.
5. **인트로 위치 옮기기.** 인트로 영상은 이제 **글리치 전환 직후(새 게임 바로 뒤)** 재생한다. 기존 `NewGameIntroPlayer`(오버레이·건너뛰기·켜짐 연출)를 재사용하고 새로 만들지 않는다. 영상 → 새 게임 시작(씬 로드) → 켜짐 연출 순서로, 영상이 끝난 뒤 메인 메뉴가 다시 비치는 틈이 없게 한다(로드 동안 검은 화면 유지 등). **첫 광산 진입에서는 영상을 다시 틀지 않는다**(`IntegrationRuntimeBinder` 쪽 영상 재생 제거, 시작 브리핑은 지금처럼 첫 진입에서 그대로). 모션 감소면 B-205 규칙대로 영상을 생략하고 켜짐 연출만. 영상 파일이 없거나 실패하면 바로 게임으로 간다. 이어하기에서는 영상이 없다.
6. **화면 만들기.** 메인 메뉴 씬에 코드로 만든다(기존 `MainMenuView`·`ControlSchemePanel`처럼). 1920×1080 기준, 다른 비율에서도 카드·버튼이 잘리지 않게. 받침대·홀로그램 테두리는 코드로 그리거나 기존 청록 홀로그램 그림을 쓴다.
7. EditMode: 고르기 전 탐사 시작 비활성/거부, 고르면 활성, 바꿔 고르기, 확정 시 고른 성별로 진입점 호출, 돌아가기 시 `StartNewGame` 미호출·슬롯 미변경, 모션 감소면 글리치 0·암전만, 첫 광산 진입에서 영상 미재생·브리핑 유지. 기존 메뉴·저장·인트로 테스트를 깨지 말 것(B-205 정책 테스트는 바뀐 위치에 맞춰 고친다).

## 테스트 (플레이 가이드)
1. 메인 메뉴에서 빈 슬롯으로 `새 게임`을 누른다. 바로 시작하지 않고 광부 선택 화면이 뜨는지 본다. 두 광부 모두 청록 실루엣이고, `탐사 시작`이 회색으로 눌리지 않는지 본다.
2. 마우스를 각 카드에 올린다. 카드가 살짝 밝아지고 효과음이 나는지 본다.
3. `여자`를 누른다. 여자 카드의 얼굴 윤곽·색이 더 또렷해지고 남자 카드는 어두워지는지, `광부를 선택해 주세요` 글자가 지직거리며 사라지는지, `탐사 시작`이 켜지는지 본다.
4. `남자`를 눌러 바꾼다. 강조가 남자로 옮겨 가고 안내 글자가 다시 나타나지 않는지 본다. 다시 `여자`를 고른다.
5. `돌아가기`를 누른다. 메인 메뉴로 돌아오는지 본다. 다시 `새 게임`을 눌러 선택 화면이 처음 상태(둘 다 실루엣)로 뜨는지 본다.
6. 키보드 ←/→로 카드를 옮기고 Enter로 고른 뒤 Esc로 돌아가 본다. 마우스와 똑같이 되는지 본다.
7. `여자`를 고르고 `탐사 시작`을 누른다. 여자 카드에 원래 색이 차오르고, 화면이 짧게 지직거린 뒤 인트로 영상이 바로 나오는지 본다. 그 사이 메인 메뉴가 다시 비치지 않는지 본다.
8. 영상이 끝나면(또는 아무 키로 건너뛰면) 게임 화면이 켜지고, 캐릭터와 가이드 그림이 여자인지 본다.
9. 광산에 처음 들어간다. 영상이 다시 나오지 않고 생존자 브리핑은 그대로 뜨는지 본다.
10. 저장 후 메인 메뉴로 나가 이어하기한다. 선택 화면·영상 없이 여자로 이어지는지 본다.
11. 데이터가 있는 슬롯으로 `새 게임` → 덮어쓰기 확인 → 선택 화면에서 `돌아가기`. 그 슬롯을 이어하기해서 기존 저장이 그대로인지 본다.
12. 모션 감소를 켜고 `남자`로 7을 다시 한다. 화면 전체 지직거림 없이 짧게 어두워졌다 넘어가고(영상은 B-205 규칙대로 생략), 카드 색 차오름은 그대로 보이는지 본다.
13. 새 효과음이 없고 기존 UI 소리만 나는지, Unity Console에 새 빨간 오류가 없는지 본다.
