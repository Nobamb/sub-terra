---

## 0. 한 줄 결론

퀘스트를 숙제가 아니라 **다음 진행 비용을 실제로 깎아 주는 지급**으로 만든다.

골드만 주면 진행에 거의 안 쓰인다. 업글·건물은 광물 비용이고, 골드는 지금 긴급 탈출 100G / 새 광산 500G 두 군데뿐이다. 그래서 주축은 **다음 퀘스트 재료를 미리 쥐여 주는 것**이다.

판정 문장:

> “퀘스트를 끝냈더니 다음 건물/업글 재료가 바로 생겼다. 안 했으면 왕복을 한 번 더 했어야 한다.”

이 문장을 못 만들면 보상 수준이 약하다.

---

## 1. 문제

현재 데모 퀘스트 18개는 완료 보상이 없다. HUD는 할 일만 보여 주고, 끝나면 다음 숙제로 넘어간다.

그 결과:

| 플레이어가 겪는 것                 | 원인                                   |
| ---------------------------------- | -------------------------------------- |
| 퀘스트가 숙제로만 남는다           | 완료 시 인벤/골드가 안 변한다          |
| 강제 건설·업글이 세금처럼 느껴진다 | 코어·드릴 2·포탈 비용을 전부 직접 캔다 |
| 골드를 받아도 진행이 안 풀린다     | 골드 싱크가 탈출 100G / 새 광산 500G뿐 |

데모 퀘스트는 선형 필수라서, “스킵을 막는 뇌물”이 아니라 **숙제를 끝낸 대가가 다음 설치/업글로 바로 이어지게** 만들어야 한다.

---

## 2. 설계 원칙

바꿀 때 이 다섯 줄을 유지하는 것을 기본으로 한다. 깨려면 이유를 §6에 적는다.

1. 방금 쓴 비용을 100% 환급하지 않는다.
2. 대신 **다음 퀘스트 비용의 50~100%**를 광물로 준다.
3. 큰 한 방은 **코어(11) / 심층(14) / 데모 완료(18)** 세 곳만.
4. 선택 업글(전력·화물·가스·체력) 재료는 퀘스트가 대신 사 주지 않는다.
5. 리튬은 심층 해금(14) 이전에는 주지 않는다.

보상 종류 우선순위:

| 우선 | 종류                          | 쓰는 곳                   |
| ---: | ----------------------------- | ------------------------- |
|    1 | 구리 / 철 / 리튬              | 업글·건물. 실제 진행 화폐 |
|    2 | 골드                          | 탈출·새 광산. 보이는 숫자 |
| 금지 | 업글 무료 지급                | 3번·14번 퀘스트가 사라짐  |
| 금지 | 전력/체력 풀충전을 본보상으로 | 한 번 쓰면 끝나서 무시됨  |

## 3. 경제 기준 (현재 빌드)

보상 크기를 잡을 때 사용한 값. 비용 데이터가 바뀌면 이 절과 §4를 같이 고친다.

### 3-1. 기본 수치

| 항목             | 값                   |
| ---------------- | -------------------- |
| 시작 골드        | 0                    |
| 시작 전력        | 100 / 100            |
| 기본 화물        | 50                   |
| 구리 단가 / 중량 | 10G / 1.5            |
| 철 단가 / 중량   | 15G / 2.0            |
| 리튬 단가 / 중량 | 40G / 0.8            |
| 만재 구리        | 약 33개 = 330G       |
| 긴급 탈출        | 100G + 최대 전력 10% |
| 새 광산          | 500G                 |

### 3-2. 강제 퀘스트 경로 최소 소모

건물·업글을 퀘스트가 시키는 만큼만 산다고 가정. 가스 정화는 기존 코어 재사용.

| 자원 |  합 | 주요 내역                                                         |
| ---- | --: | ----------------------------------------------------------------- |
| 구리 |  34 | 드릴1 8, 버팀목 2, 사다리 3, 코어 5, 충전기 3, 보건소 3, 드릴2 10 |
| 철   |  18 | 사다리 1, 조명 1, 보관함 2, 코어 5, 드릴2 6, 포탈 3               |
| 리튬 |   4 | 정산 콘솔 1, 포탈 3                                               |
| 골드 | 100 | 포탈 사용                                                         |

화물 50 기준으로 약 왕복 2회분이다.

### 3-3. 참고 비용

| 대상                               | 비용           |
| ---------------------------------- | -------------- |
| 드릴 속도 1                        | 구리 8         |
| 드릴 속도 2 (심층 해금, 코드 기준) | 구리 10 + 철 6 |
| 버팀목                             | 구리 2         |
| 사다리                             | 구리 3 + 철 1  |
| 조명                               | 철 1           |
| 보관함                             | 철 2           |
| 전진기지 코어                      | 구리 5 + 철 5  |
| 충전기                             | 구리 3         |
| 보건소                             | 구리 3         |
| 정산 콘솔                          | 리튬 1         |
| 긴급 탈출 포탈                     | 철 3 + 리튬 3  |

퀘스트 문구(`DemoObjectiveCatalog`)는 심층 해금에 드릴 2 + 드론 스캔 2 + 가스 저항 1을 적지만, 코드(`DeepZoneUnlockRule.Mvp`)는 **드릴 속도 2만** 요구한다. 이 문서의 14번 보상은 코드 기준이다. 문구를 코드에 맞출지, 보상을 문구 기준으로 올릴지는 별도 결정.

## 5. 합계 vs 강제 소모

§4 기본선 기준.

|      | 퀘스트 지급 |  강제 소모 |                        비율 |
| ---- | ----------: | ---------: | --------------------------: |
| 구리 |          21 |         34 |                         62% |
| 철   |          13 |         18 |                         72% |
| 리튬 |           4 |          4 |                        100% |
| 골드 |         580 | 100 (탈출) | 탈출 5.8회 / 새 광산 1.16회 |

골드환산:

- 광물: 21×10 + 13×15 + 4×40 = **535G**
- 현금: **580G**
- 합: **약 1,115G** = 만재 구리 한 번(330G)의 약 3.4배

선택 업글은 이 합에 들어 있지 않다. 전력·화물·가스를 사려면 여전히 직접 캐야 한다.

데모 중에 광물을 팔면 골드가 더 쌓인다. 580G + 만재 1~2회 판매면 새 광산 500G가 사실상 열린다. 그게 싫으면 §6의 “너무 헤플 때”를 적용한다.

## 6. 조절 노브

표 전체를 다시 짜기 전에, 먼저 여기만 손대도 된다.

### 너무 헤플 때

| 변경               | 효과                                           |
| ------------------ | ---------------------------------------------- |
| 18번 골드 150 → 80 | 클리어 보너스가 새 광산의 16%로 내려감         |
| 13번 구리 4 → 0    | 심층 직전 구리를 직접 캐게 함                  |
| 결과               | 구리 17 / 골드 510. 강제 소모의 약 절반만 보조 |

### 더 세게 갈 때

| 변경                | 효과                                    |
| ------------------- | --------------------------------------- |
| 11번에 구리 3 추가  | 충전기까지 키트로 줌                    |
| 16번에 구리 3 추가  | 가스용 코어를 새로 박은 플레이어도 회수 |
| 18번 골드 150 → 250 | 데모 클리어 ≈ 새 광산 거의 1회          |

### 결정이 필요한 분기

- [ ] 클리어 보너스를 새 광산 1회(500G)까지 밀어올릴지. 기본선은 150G(30%).
- [ ] 16번이 코어를 새로 박는 경로를 보조할지. 기본선은 골드만.
- [ ] 심층 해금 보상을 퀘스트 문구(드론 스캔 2 + 가스 1) 기준으로 올릴지. 기본선은 코드(드릴 2만).

## 7. 구현 시 메모 (수치 확정 후)

이 절은 보상 수준이 아니라 넣을 때 걸리는 지점이다. 수치 합의와 별개로 남겨 둔다.

- `DemoObjectiveDefinition`에 보상 필드가 없다. 카탈로그에 구리/철/리튬/골드를 명시해야 HUD에 미리 보여줄 수 있다.
- 보상을 미리 안 보여 주면 숙제로 남는다. 지급과 미리보기는 같이 간다.
- 화물 50 제한에 큰 광물 더미가 들어갈 수 있다. 넘치면 지급 실패 / 용량 초과 허용 / 보관함으로 보내기 중 하나를 정해야 한다.
- 지급은 `InventoryService` + `GameState.AddGold` 한 경로만 쓴다. 퀘스트 UI가 인벤을 직접 바꾸지 않는다.
- 완료 팝업에 보상 목록을 넣는다. 18번 긴급 탈출은 완료 팝업을 안 띄우는 예외가 있으므로, 그 경로는 별도 표시가 필요하다.
