## 0. 한 줄 결론

기존 X 블록(`tile.locked.signal`, 그레이박스 대각선 X)의 얼굴을 배너 문양 석재로 교체한다.

- 기본: 회색 석재 에셋. 문양은 꺼져 있다.
- 드론이 감지하면: **문양 전용 에셋**으로 갈아끼우고, 스캔 불빛은 **청록**.
- 심층 해금 후 캐면 **엔진 연료**가 나온다.
- 연료는 광물과 같은 인벤에 들어가고, 지상에서 **희귀 품목으로만** 판다. 개당 **100G**.
- 우주선 구동, 행성 이동, 배양시설 연동은 **하지 않는다.**

플레이어가 말할 수 있어야 하는 문장:

> “드론이 청록 빛으로 찍으니까 회색 돌에 문양이 떠서 캤더니 엔진 연료가 나왔다. 지상에서 100G에 팔았다.”

이 문장을 못 만들면 아직 아니다.

---

## 1. 대상 칸

지금 인게임의 “X 블록”은 별 에셋이 아니다. `LockedSignal` 스프라이트가 대각선 두 줄로 X를 그리고, 타일 색이 보라다.

| 칸 | ID | 이번 작업 |
| --- | --- | --- |
| 38m 신호 1칸 | `tile.locked.signal` | 문양 에셋 교체 + 해금 후 채굴 + 엔진 연료 |
| 해금 전 36m 가로 봉인 | 심층 진입 차단 줄 | **그대로 채굴 불가.** 연료 소스가 아니다. 나중에 같은 문양 언어를 쓸 수는 있다. |

연료는 신호 칸에서만 나온다. 봉인 줄을 캐서 농사하지 않는다.

데모 월드 신호는 기본 1칸이다. 희귀 보상이므로 이번 범위에서 칸 수를 늘리지 않는다. 새 광산 리셋으로 월드를 다시 열면 다시 1칸이다.

---

## 2. 비주얼

배너 `docs/readme/banner.jpg`의 문양 블록을 1칸 타일로 옮긴다. 새 타일 종류를 만들지 않고 **기존 X 블록**(`tile.locked.signal`)을 쓴다.

드론이 감지했을 때 문양이 나타난다. 이 전환은 틴트만으로 하지 않고 **에셋을 따로** 둔다.

| 상태 | 언제 | 에셋 | 보임 |
| --- | --- | --- | --- |
| **돌** | 드론 스캔 밖 | 회색 석재 전용 | 문양 없음. 리튬처럼 결정이 자라 있지 않음. 기존 보라 X는 폐기. |
| **문양** | 드론이 이 칸을 스캔 반경에 넣었을 때 | **문양 전용 에셋** (돌 위에 청록 선을 구운 별도 스프라이트) | 배너와 같은 기하 문양. **결정이 아니라 새겨진 선.** |

스캔이 끝나면(반경 밖·펄스 수명 종료) 다시 돌 에셋으로 돌아간다.

### 2-1. 드론 스캔 불빛

칸 마커 색은 이미 종류별로 갈린다. 문양 블록은 광물 흰색을 쓰지 않는다.

| 대상 | 지금 색 | 이 칸 |
| --- | --- | --- |
| 일반 광물 (구리·철·리튬) | 흰색에 가까운 냉백 (`mineralColor`) | — |
| 가스 | 빨강 (`hazardColor`) | — |
| 골드 드롭 | 노랑 (`goldColor`) | — |
| **문양 블록 / 엔진 연료** | 없음 | **청록** |

`DroneScanTargetKind`에 신호 종류를 하나 추가하고 `DroneScanPulseView`에 청록 색을 둔다. 범위 링 색은 건드리지 않는다. 바뀌는 것은 **이 칸 위의 스캔 포인트 라이트**다.

리튬과의 구분:

| | 리튬 | 문양 블록 |
| --- | --- | --- |
| 색 | 청록 결정 | 청록 **선** |
| 형태 | 광맥 | 회색 석재에 인공 문양 |
| 드론 | 희귀 광물 | 신호가 있다 / 문양이 깨어났다 |
| 드랍 | `mineral.lithium` | 엔진 연료 (희귀) |

색만으로 구분하지 않는다. 타일은 결정 vs 문양, 스캔 빛은 흰빛 vs 청록.

에셋 규칙:

- 돌 스프라이트와 문양 스프라이트를 **따로** 만든다. 회색 돌에 런타임 틴트만 올리는 방식은 쓰지 않는다.
- 1칸에서도 문양이 읽혀야 한다. 배너는 2×2에 가깝지만, 생성기를 2×2로 키우지 않는다.
- 타일 ID는 `tile.locked.signal` 유지. 스캔 on/off는 같은 ID의 스프라이트 교체(또는 자식 오버레이 에셋)로 처리한다.
- 문양을 켜는 주체는 플레이어 램프가 아니라 **Digger-Bot 스캔**. `upgrade.drone.scan`이 반경을 늘린다. 새 스킬 없음.

## 3. 채굴

해금 전:

- 36m에서 막힌다. 신호 칸에 닿지 못한다.
- 치트·붕괴로 붙어 있어도 신호 채굴은 `DeepZoneLocked` (또는 동일 실패). 타일 유지.

해금 후:

- `tile.locked.signal` 채굴 **허용**. 지금의 “신호는 항상 채굴 불가”를 여기서 푼다.
- 드릴 게이트는 리튬과 같게 **레벨 2**. 전력·구조 규칙은 일반 채굴을 따른다.
- 성공 시 타일을 제거하고 엔진 연료를 인벤에 넣는다.
- 인벤이 가득이면 채굴 실패, 타일 유지. 광물과 같다.
- 캐면 칸은 비어 있다. 문양을 남겨 기념비로 두지 않는다. (이번 범위는 드랍이 목적)

해금 자체는 기존처럼 지상에서 확정된다. 신호 칸을 캐서 해금하지 않는다.

---

## 4. 엔진 연료

우주선은 아직 없다. 이번 보상은 **희귀 판매 아이템**이다.

| 항목 | 내용 |
| --- | --- |
| ID | `item.rare.engine_fuel` (광물 ID 네임스페이스에 넣지 않는다. 제작 레시피가 구리·철·리튬을 훑다 집어가지 않게) |
| 보관 | 광물과 **같은 인벤**. 미정산 화물. 지하에서 팔지 못함 |
| 표시 | 인벤·판매 UI에서 구리/철/리튬과 **별도 희귀 행**. 같은 목록에 섞여 보여도 희귀 라벨이 있어야 한다 |
| 판매 | Surface Base에서만. **개당 100G** (리튬 40G의 2.5배). 희귀 1칸 보상 기준값 |
| Sell All | **포함하지 않는다.** 희귀는 선택 판매만. 실수로 같이 팔리지 않게 |
| 제작·업그레이드 | 재료로 쓰지 않음 |
| 우주선 | 소비하지 않음. 아이템만 존재 |

무게는 인벤 규칙을 따른다. 칸이 1개라 수치보다 “귀환 전에 잃어버릴 수 있는 화물”인 것이 중요하다.

드론 분석은 “광물 추천”이 아니라 “희귀 신호 / 엔진 연료 후보” 분기다.

---

## 5. 이번에 하지 않는 것

- 우주선 오브젝트, 엔진 N개 게이지, 발사, 다른 행성
- 배양시설·인구 재생 연동
- 36m 봉인 줄을 캐서 연료 파밍
- 신호 칸을 2×2 문으로 확장 (생성기·스냅샷 별 설계)
- 문양의 스토리 본문. “누가 왜”는 비워 둔다
- 곡괭이·장비 상점
- 월드 시드·해금 조건·38m 좌표 변경

우주선은 연료 아이템이 팔리고 난 뒤, 행성 작업과 같이 연다. 지금 연료를 팔 수 있으면 루프는 닫힌다.

---

## 6. 구현 순서 (착수할 때)

1. 돌 에셋 / 문양 에셋을 따로 만들고, X 그레이박스를 돌 에셋으로 교체
2. 드론 스캔 반경에서 문양 에셋으로 전환 + 이 칸 스캔 불빛 청록 (`DroneScanTargetKind` 추가)
3. 해금 후 `tile.locked.signal` 채굴 허용, 엔진 연료 1스택
4. 인벤 표시 + Surface 희귀 판매 행, 개당 100G (Sell All 제외)
5. 해금 전 채굴 거절·인벤 가득 거절 회귀

1~2만 되어도 배너와 인게임이 같은 그림이 된다. 3~4가 이번 플레이 루프다.
