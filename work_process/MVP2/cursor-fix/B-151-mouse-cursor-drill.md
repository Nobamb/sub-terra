# B-151 마우스 커서 드릴·집게 커스텀 커서

## 목표

기본 OS 커서 대신, 드릴·집게 스프라이트로 따라다니는 커서를 만든다.
좌클릭으로 파거나 끌 때는 드릴이 점점 빨라지며 모션블러가 진해지고, 우클릭으로 시설을 옮길 때는 집게로 바뀐다.
잡을 수 있는 대상 위에 올리면 드릴 끝에 청록 빛과 파티클이 난다.

## 에셋 (이미 준비됨 — 새로 그리지 말 것)

- `cursor-fix/mouse-cursor.png` (또는 지정 경로): **2×4 = 8칸** 드릴 회전 시트
  - 1번: 완전 정지 / 2~8번: 점점 빨라지며 블러 증가 (8번=최고속)
- `cursor-fix/cursor-right-click.png`: **1×4 = 4칸** 집게 시트
  - 1번: 접힌 집게 / 2번: 벌어짐 / 3번: 활짝 / 4번: 잡기
- Import: Sprite Mode=Multiple, 투명 배경 유지. 칸 크기가 같으면 Grid By Cell Count로 자르고, 다르면 수동으로 자른 뒤 보고한다.
- 픽셀 피벗(핫스팟)은 **드릴·집게 끝(왼쪽 위쪽 끝)** 이 클릭 지점이 되게 맞춘다. 커서 표시 크기 약 32~48px.

## 먼저 읽을 코드

- 시설 옮기기·호버: `GameplayBuildingPlacementBridge` (`HandleWorldRightClick`, `FacilityMoveHoverHint`)
- 좌클릭 채굴/드래그가 어디서 시작되는지 입력 경로 확인 (기존 Input System 마우스)
- OS `Cursor` API 사용처가 있으면 목록을 먼저 보고한다. (현재는 기본 커서만 쓰는 상태로 예상)

## 1. 커서 표시 방식

- 플레이 중(탐사·지상 기지 등 게임 화면)에는 OS 커서를 숨기고, 화면 최상위 UI에 스프라이트 커서를 띄워 마우스를 따라가게 한다.
- 메인 메뉴·설정처럼 시스템 UI만 있을 때는 기존 OS 커서를 써도 된다. 어느 화면에 커스텀을 켜는지 정해서 보고한다. 기본 권장: **Bootstrap 이후 인게임 전부**.
- 커서가 입력·클릭을 가로채면 안 된다 (`raycastTarget=false`).
- 게임이 느려져도 커서가 한 프레임 이상 lagged 하게 느껴지면 원인을 보고하고, 가능하면 unscaled 위치 갱신으로 맞춘다.

## 2. 기본(드릴) 상태

- 손을 떼고 있으면 `mouse-cursor` **1번**만 보여 준다.
- **좌클릭을 누르고 있는 동안**(클릭·드래그 포함):
  - 시작 속도는 중간보다 조금 빠른 쪽(대략 3~4번대)에서 시작한다.
  - 오래 누를수록 5→8번으로 올라가고, 프레임 전환이 빨라진다.
  - 떼면 천천히 1번 쪽으로 내려온다.
  - 느려지는 중에 다시 누르면 **1번으로 리셋하지 말고**, 그때 프레임/속도에서 다시 올라간다.
- 누르고 있는 동안 **미세 떨림**: 조준이 어긋나지 않을 정도로만(약 ±1~2px). 핫스팟은 흔들리지 않게 두고 그림만 흔들거나, 흔들림이 클릭 좌표에 영향을 주지 않게 한다.
- 원뿔 분리(옛 시트 3줄)는 **쓰지 않는다.** 우클릭 전환은 집게 시트로 바로 간다.

## 3. 우클릭(시설 옮기기) — 집게

- 우클릭으로 시설 옮기기가 활성화된 동안 `cursor-right-click`을 쓴다.
- 전환 시 0.1초 전후로 살짝 커졌다 돌아오거나 청록 링이 한 번 반짝이게 해서 끊김을 가린다.
- 집게 프레임: 기본은 1~2번, 잡을 수 있는 시설 위에 올리면 3~4번 쪽으로 연다. 기존에 화살표→손모양으로 바뀌던 호버와 같은 조건에 맞춘다.
- 우클릭을 떼거나 옮기기가 끝나면 드릴 시트로 돌아오고, 돌아오는 속도는 그 순간 좌클릭 상태에 맞춘다.

## 4. 잡기 가능 호버(청록 팁)

- 기존에 손모양 커서로 바뀌던 상황(옮길 수 있는 시설 호버 등)에서:
  - 드릴 끝(또는 집게 끝)에 청록(`#3FE0D0` 근처) 빛이 난다.
  - 그 위치에 작은 청록 파티클이 약하게 나온다. 방해되지 않게 개수·크기를 작게.
- 빛·파티클은 스프라이트에 구워 넣지 말고 코드/UI Image·Particle로 만든다.

## 5. 구현 방향

- 커서 전용 작은 컨트롤러(예: `GameplayCursorController`) + 스프라이트 시트 설정 ScriptableObject 또는 Builder로 에셋 연결.
- 회전 단계·가속·감속·떨림 세기·커서 크기는 인스펙터에서 조절 가능하게.
- 기존 시설 옮기기·채굴 입력 로직은 바꾸지 않는다. 커서 연출만 얹는다.
- Builder가 필요하면 `PromptB151GameplayCursorBuilder` 패턴.

## 테스트

- EditMode 전체 실행, 전부 통과.
- 새 EditMode
  - 시트 슬라이스 개수(8 / 4)와 핫스팟이 끝쪽에 있는지
  - 좌클릭 유지 시 프레임이 올라가고, 떼면 내려오며, 감속 중 재클릭 시 리셋되지 않음
  - 우클릭 옮기기 ON이면 집게 시트, OFF면 드릴 시트
  - 호버 가능일 때만 청록 팁/파티클 활성
  - 커서 Image가 raycast를 막지 않음
- PlayMode는 이번 작업에서 추가·수정한 테스트만 실행.
