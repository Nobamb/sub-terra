# B-147 긴급 탈출 포탈 UI 개편 + 버그 2건 (#119)

## 목표
긴급 탈출 포탈 창을 웜홀 인트로 + 터미널 접속형 창으로 바꾸고, 아래 버그 2건을 같이 고친다.
1. 전진기지 코어가 이미 있는데도 목적지 드롭다운이 열리지 않는 문제
2. 근처 다른 시설과 상호작용할 때 긴급 탈출 포탈까지 같이 반응하는 문제

## 먼저 읽을 코드
- EmergencyEscapePortalRuntimeBridge (App/Integration 쪽), EmergencyEscapePortal 관련 Presenter/View
- Tests/EditMode/App/UI/PromptB46EmergencyEscapePortalTests.cs (기존 동작 기준)
- 광산 초기화 팝업, 게임 가이드 창의 웜홀 아이콘 인트로 연출 (재사용 대상)
- 전진기지 코어 팝업 (OutpostPanelPresenter 등): 시스템 접속 느낌의 터미널 톤 기준
- 시설 상호작용 선택 로직 (가장 가까운 시설 / 우선순위 결정 부분)
- 참고 패턴: ResourceSellTimeline (DOTween 없는 순수 계산 타임라인)

## 1. 열기 연출
1) 화면 중앙에 광산 초기화·게임 가이드와 같은 웜홀 아이콘이 나타난다.
2) 웜홀이 점점 빠르게 회전한다 (가속, 약 0.5초).
3) 웜홀 중심에서 팝업이 3D처럼 앞으로 튀어나오며 열린다 (작은 크기 + 살짝 기울어진 상태 → 정면 원래 크기, 약 0.25초).
4) 팝업 안은 전진기지 코어처럼 시스템 접속 연출을 한다. 웜홀 인트로가 있으니 접속 줄은 1~2줄로 짧게 (총 0.3초 이내), 길면 생략해도 된다.
- 닫을 때는 역순을 짧게 (팝업이 웜홀로 빨려 들어가듯 0.2초).
- 전체 열기 시간은 1.2초를 넘지 않는다. 연출 중 아무 키나 누르면 바로 끝 상태로 건너뛴다.

## 2. 터미널 창 내용
- 톤은 전진기지 코어 팝업과 맞춘다 (같은 프레임, 폰트, 색).
- 상단: CCTV 미리보기 (선택한 목적지 화면). 기존 CCTV 렌더 경로를 재사용하고, 없으면 자리만 두고 보고한다.
- 하단: 갈 수 있는 목적지 목록을 드롭다운이 아니라 항상 펼쳐진 리스트로 보여 준다.
  - 항목: 엘리베이터, 전진기지 코어 1, 2 ...
  - 위·아래 키 / 마우스로 선택하면 CCTV 미리보기가 바뀐다.
  - 이동할 수 없는 항목은 흐리게 하고 이유를 짧게 표시 (전력 부족, 골드 부족 등)
- 비용 줄: "비용: 100G + 전력 15" 형식 유지.
- 버튼: 이동 / 닫기. 키보드로도 조작 가능.

## 3. 버그 1: 드롭다운 미표시
- 원인을 먼저 찾아 보고한다 (목록 갱신 시점, 코어 등록 누락, 드롭다운 렌더 문제 중 무엇인지).
- 새 리스트 UI는 창을 열 때마다 현재 목적지 목록을 새로 받아 그린다.
- 전진기지 코어를 설치한 직후, 세이브를 불러온 직후 모두 목록에 나타나야 한다.

## 4. 버그 2: 상호작용 우선순위
규칙
- 캐릭터 판정 영역이 포탈 상호작용 영역 안에 완전히 들어가 있을 때만 포탈이 대상이 된다. 이때는 포탈이 우선이다.
- 캐릭터가 조금이라도 포탈 영역 밖으로 나와 있으면 포탈은 대상에서 빠지고 다른 시설이 우선이다.
- 근처에 다른 시설이 없어도 같은 규칙: 완전히 들어가야만 포탈 상호작용 가능.
구현
- 완전 포함 판정은 순수 함수로 분리한다 (예: 캐릭터 Bounds가 포탈 영역 Bounds 안에 완전히 들어가는지).
- 다른 시설의 기존 판정과 우선순위 규칙은 바꾸지 않는다.
- 상호작용 키 안내(이름표 등)도 같은 규칙을 따라 포탈이 대상이 아닐 때는 포탈 쪽 안내가 뜨지 않는다.

## 구현 방향
- 연출 계산(EscapePortalOpenTimeline 등)은 순수 계산 클래스, View는 값 적용만.
- 웜홀 아이콘과 회전 연출은 광산 초기화·가이드 것을 재사용하고 복붙하지 않는다.
- 이미지가 필요하면 다른 에이전트에게 생성을 맡겨도 된다.
- 씬·프리팹 연결은 기존 Builder 패턴(Editor/DataValidation)을 따른다.
- 협동 플레이: 이동과 비용 처리는 기존 네트워크 경로를 그대로 쓴다.

## 범위 밖

## 테스트
- EditMode 전체 실행, 전부 통과. 기존 PromptB46 테스트가 UI 변경으로 깨지면 의도에 맞게 고치고 보고한다.
- 새 EditMode 테스트
  - 열기 타임라인: 단계 순서, 총 시간 1.2초 이하, 건너뛰기 시 즉시 끝 상태
  - 목적지 목록: 코어 설치 후 / 세이브 로드 후 목록에 코어가 포함
  - 완전 포함 판정: 완전히 안 / 한 변 걸침 / 완전히 밖
  - 우선순위: 포탈 완전 포함 + 다른 시설 근처면 포탈, 걸치면 다른 시설
- PlayMode는 이번 작업에서 추가하거나 수정한 테스트만 실행한다.

## 수동 확인 체크리스트
