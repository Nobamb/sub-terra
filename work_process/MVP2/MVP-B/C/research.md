# Phase C — 수직 이동과 시작 엘리베이터

## 1. 개요

Player는 좌우 이동과 점프만 제공하므로 수직 굴착 뒤 복귀할 수 없다. 지상과 40m Mine을 연결하는 시작 엘리베이터와, 현장 수직 이동용 사다리 또는 버팀목 발판이 필요하다.

## 2. 작업 목표

- Surface Base와 Mine 시작 지점을 연결하는 엘리베이터를 만든다.
- 엘리베이터 호출/탑승/이동/도착 상태를 명확히 표시한다.
- 깊은 shaft에서 사용할 사다리 또는 설치형 발판을 제공한다.
- 이동 중 입력·충돌·세이브 전환이 꼬이지 않게 한다.

## 3. 구현 범위

- `ElevatorController`, 탑승 구역, 상/하단 정거장
- 호출·상호작용 Input Action과 안내 UI
- Ladder/Platform Runtime Prefab과 이동 상태
- 엘리베이터 이동 중 Player 제어 잠금과 안전 하차 위치
- 전력 소비 정책과 비상 복귀 정책

## 4. 권장 구현 방향

1. SurfaceBase↔Mine Scene 전환과 Mine 내부 승강 이동을 분리한다.
2. 엘리베이터는 명시적 상태 머신(`Idle/Calling/Moving/Arrived/Blocked`)으로 만든다.
3. 사다리는 PlayerMovement에 별도 수직 모드를 추가하고 중력/속도를 진입·이탈 시 복원한다.
4. 발판을 선택하면 Building 배치 검증과 저장 경로를 재사용한다.
5. 엘리베이터 호출 전력은 App State의 단일 Energy 소비 경계를 사용한다.

## 5. 보안 및 안정성 기준

- 이동 중 Scene 종료/비활성화 시 Player 제어와 Rigidbody 상태가 복원된다.
- 정거장 출구가 막혔을 때 플레이어를 타일 안에 배치하지 않는다.
- 입력 중복으로 두 번 이동하거나 전력을 두 번 차감하지 않는다.
- 체크포인트 복원 위치는 유효한 정거장/발판 좌표만 허용한다.

## 6. 완료 기준

- 새 게임에서 지상→Mine→지상 왕복이 가능하다.
- 5칸 이상 수직 굴착 후 사다리/발판으로 탈출할 수 있다.
- 엘리베이터 이동 중 플레이어가 플랫폼을 이탈하거나 벽을 통과하지 않는다.
- 전력 부족·출구 막힘·중복 입력에 안전하게 실패한다.
