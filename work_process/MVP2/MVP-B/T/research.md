# Phase T — 드론 스캔 절대 반경과 월드 광원 탐지

## 0. 작업 전

- `init/prompt-B.md` 83번과 `init/rule.md`를 기준으로 한다.
- 선행: Phase K(드론 대사/Context), Phase H(가스 Zone), Phase S(업그레이드 밸런스). S의 후속 P3 중 **스캔 월드 표시**만 이번 단계가 가져간다.
- 기존 `upgrade.drone.scan` ID, 구매·저장·심층 해금 파이프라인은 유지한다.
- 드론 분석 주기(`DroneSensor.scanInterval` 0.5초), 가스 노출 경고, 붕괴 흔들림(prompt-B 82), 귀환·화물 추천은 끄지 않는다.

## 1. 개요

현재 드론 스캔은 반경 안 광물 ID만 모아 대사로 “인근 광물이 있다”고 알린다. 좌표도 월드 표시도 없어서 레벨을 올려도 체감이 없다. 반경 계산도 기본 4칸에 효과를 더해 `Lv.0=4 / Lv.1=7 / Lv.2=11`이므로, 업그레이드를 안 사도 탐지가 이미 켜져 있다.

이번 단계는 스캔을 **구매하는 정찰 능력**으로 바꾼다. 반경은 절대값이고, 펄스마다 대상 타일에 광원을 올려 어둠 속에서도 위치를 보여 준다.

## 2. 작업 목표

- 스캔 반경을 절대값 `Lv.0=0 / Lv.1=3 / Lv.2=7`로 고정한다.
- Lv.0에서는 반경 스캔(광물 탐지·펄스·인근 광물 대사 입력)을 끈다.
- 30초마다 한 번 스캔하고, 감지된 타일을 10초 동안 광원으로 강조한다.
- 광물은 흰색, 미진입 가스는 붉은색이다.
- Context 갱신 0.5초와 시각 펄스 30초를 분리한다.

## 3. 확정 규칙

| 항목 | 값 |
| :-- | :-- |
| 반경 의미 | 플레이어 발밑 타일 기준 체비쇼프 거리(`max(dx, dy) <= r`) |
| Lv.0 | 반경 0. 펄스 없음. `NearbyMineralIds` 비움 |
| Lv.1 | 반경 3. 광물만 흰빛 |
| Lv.2 | 반경 7. 광물 흰빛 + 미진입 가스 붉은빛 |
| 펄스 주기 | 30초. 자동. 플레이어 입력으로 당기지 않음 |
| 광원 유지 | 10초 후 소멸. 다음 펄스까지 약 20초 공백 |
| 광물 대상 | 반경 안 전경 타일 중 `mineralId`가 있는 칸. 매립·벽 너머 포함 |
| 가스 대상 | 반경 안 `GasHazardSystem.ActiveZones`가 덮는 칸. 현재 밟고 있는 노출과 별개 |
| 붕괴 | 스캔 광원 대상이 아님. prompt-B 82 흔들림이 담당 |
| 기본 경고 | 현재 칸 가스·붕괴, 전력·귀환·화물은 Lv.0에서도 유지 |
| 전력 소모 | 이번 단계 비범위. PRD의 스캔 전력 소비는 후속 |

`GetDroneScanRadius(baseRadius)`는 `baseRadius`를 더하지 않고 현재 레벨 효과값을 그대로 반환한다. 레벨 0·잘못된 레벨은 0이다.

카탈로그 `effectValue`는 기존처럼 Lv.1=3, Lv.2=7을 유지한다. 의미가 “기본 4에 더하는 보너스”에서 “절대 반경”으로 바뀐다.

## 4. 구현 범위

- App: `UpgradeEffectProvider.GetDroneScanRadius`를 절대값으로 변경. 업그레이드 UI 문구가 `+3`이 아니라 `반경 3`을 보여 주면 함께 맞춘다.
- Data: `Upgrade_Drone_Scan.asset` / `MvpDataAssetBuilder`의 3/7은 유지하되, 설명·테스트 기대값을 절대 반경에 맞춘다.
- Gameplay: `DroneSensor` 반경 0 허용. 분석 주기와 분리된 펄스 타이머. 광물·가스 셀 수집.
- Gameplay View: 타일 중앙 Light2D 풀. 흰색/붉은색. 10초 수명. 펄스 시작 시 반경 링을 짧게 표시.
- Tests: 절대 반경, Lv.0 차단, 펄스 주기, 광물/가스 대상, 분석 주기 비변경.
- Scene/Prefab: 드론 Runtime 또는 Integration의 스캔 View 컴포넌트만. 다른 UI Prefab은 열지 않는다.

## 5. 구현 방향

1. `DroneSensor.scanInterval`(0.5초)은 Context 전용으로 둔다. 시각 펄스는 별도 `pulseInterval=30` / `pulseDuration=10`이다.
2. 반경이 0이면 `ScanNearbyMinerals`와 펄스를 건너뛴다. `Mathf.Max(1, radius)`로 0을 막지 않는다.
3. Provider가 없으면 반경 0으로 본다. 직렬화 기본값 4에 의존하지 않는다.
4. 광원은 타일마다 새로 만들지 않고 풀을 재사용한다. 펄스마다 이전 광원을 정리한 뒤 다시 켠다.
5. 가스 붉은빛은 Zone 중심만이 아니라 Zone이 덮는 셀에 올린다. 플레이어가 이미 들어간 가스도 반경 안이면 표시하되, 기본 노출 경고를 대체하지 않는다.
6. 반경 링은 펄스 시작 1~2초만 보여 레벨 3과 7 차이를 숫자 없이 보여 준다.
7. 인근 광물 대사는 펄스가 만든 사실이 아니라, 같은 절대 반경으로 모은 `NearbyMineralIds`를 기존 분석기가 읽게 한다. 새 추천 규칙을 만들지 않는다.
8. Shared 계약 시그니처 `GetDroneScanRadius(float baseRadius)`는 유지한다. 구현만 절대값이다.

## 6. 보안 및 안정성 기준

- 매 프레임 타일맵 전체 순회, 타일당 Light2D 생성, 분석 주기 30초 변경을 하지 않는다.
- Scene 전환·비활성화·세이브 복원 시 광원과 펄스 타이머를 정리한다. 복원 직후 즉시 한 번 펄스해도 되고, 30초를 기다려도 된다. 다만 한 프레임에 두 번 켜지지 않게 한다.
- 기존 세이브의 스캔 레벨은 그대로 두고 새 절대 반경만 적용한다. 마이그레이션 필드를 추가하지 않는다.
- `BuildingMenu`, Surface Base, 드론 대사 패널 레이아웃은 수정하지 않는다.
- 폰트 아틀라스·ProjectSettings 자동 변경은 원복한다.
- 한국어 주석을 추가하고, Gameplay가 App 구체 클래스를 참조하지 않게 한다.

## 7. 완료 기준

- Lv.0에서 광원·인근 광물 ID·스캔 링이 없다. 가스 밟음/붕괴/귀환 대사는 남는다.
- Lv.1은 반경 3 광물만 10초 흰빛, Lv.2는 반경 7 광물+가스를 흰/붉은 빛으로 구분한다.
- 30초 주기와 10초 유지가 실제 시간에 맞다. Context는 0.5초 주기로 계속 갱신된다.
- 카탈로그·Provider·Sensor 반경이 모두 `0 / 3 / 7`이다.
- 지정 Edit/Play Mode 테스트가 통과하고, 범위 밖 UI/Scene/Font 변경이 없다.
