## 2. 기능 테스트 항목

### T-F01: 레벨별 절대 반경

- **준비:** 스캔 Lv.0 / Lv.1 / Lv.2 Provider
- **실행:** `GetDroneScanRadius(4)`와 `GetDroneScanRadius(0)`를 각각 호출한다.
- **예상 결과:** 인자 4를 넘겨도 `0 / 3 / 7`. 예전 가산 결과 `4 / 7 / 11`이 나오면 실패

### T-F02: Lv.0 반경 스캔 차단

- **준비:** 플레이어 옆 3칸 안에 구리 타일, 스캔 레벨 0
- **실행:** `CaptureContext()`와 펄스 갱신
- **예상 결과:** `NearbyMineralIds` 비어 있음. 광원 0. 현재 칸 가스/구조 필드는 기존처럼 채워짐

### T-F03: Lv.1 광물만, 반경 3

- **준비:** 거리 3에 철, 거리 4에 리튬, 거리 2에 가스 Zone. 스캔 Lv.1
- **실행:** 펄스 1회
- **예상 결과:** 철만 흰빛. 리튬·가스는 점등하지 않음. Context 인근 광물에 철만 포함

### T-F04: Lv.2 광물+가스, 반경 7

- **준비:** 거리 7에 리튬, 거리 8에 구리, 거리 5에 미진입 가스 Zone. 스캔 Lv.2
- **실행:** 펄스 1회
- **예상 결과:** 리튬 흰빛, 가스 칸 붉은빛, 거리 8 구리는 없음. 붕괴 위험 칸에는 스캔 광원을 올리지 않음

### T-F05: 펄스 30초 / 유지 10초

- **준비:** 스캔 Lv.1, 고정 `timeScale` 또는 테스트 클록
- **실행:** t=0 펄스, t=10, t=29, t=30
- **예상 결과:** 0~10초 광원 활성, 10~30초 소등, 30초에 다음 펄스. Context 갱신은 0.5초 간격으로 계속됨

### T-F06: 기본 드론 경고 유지

- **준비:** 스캔 Lv.0, 플레이어가 가스 Zone 내부, 구조 위험 있음
- **실행:** Context 캡처와 분석
- **예상 결과:** 가스 이탈·버팀목·귀환 추천은 기존 규칙대로 동작. 스캔 광원만 없음

### T-F07: 세이브 레벨 호환

- **준비:** 기존 세이브에 스캔 Lv.2가 있음
- **실행:** 로드 후 Provider·Sensor 반경 조회
- **예상 결과:** 레벨 2 유지, 반경 7. 마이그레이션 필드 없음

## 3. 테스트 절차

1. Provider/카탈로그 Edit Mode부터 고친다. 가산 기댓값을 절대값으로 바꾼 뒤 App Edit Mode 회귀를 돌린다.
2. `DroneSensor` 반경 0과 펄스 타이머 Play Mode를 추가한다.
3. Integration 또는 드론 Test Scene에서 Lv.1/Lv.2 광원 색과 반경 링을 확인한다.
4. Context `scanInterval`이 0.5초인지, 가스 노출·붕괴 흔들림이 꺼지지 않았는지 회귀한다.
5. `git status`로 범위 밖 UI/Scene/Font dirty를 원복한다.

## 4. 검증 결과 요약

- **상태:** 자동 검증 통과, 수동 QA 미실행
- **Unity 컴파일:** 오류 0
- **Edit Mode 전체 회귀:** 648 통과 / 0 실패 / 0 건너뜀
- **Play Mode 전체 회귀:** Bootstrap/MainMenu 진입 뒤 결과 없이 정지해 약 3분 후 중단. 생성된 임시 Scene·QualitySettings 변경은 제거·원복함
- **확인 범위:** 절대 반경 `0/3/7`, Lv.0 차단, 체비쇼프 경계, Lv.2 광물·가스 구분, 30초 펄스·10초 유지, 0.5초 Context 주기, 업그레이드 UI 절대 반경 표기
- **범위 보호:** 테스트가 dirty 처리한 Integration Scene, TMP 폰트, EditorBuildSettings를 원복함

## 5. 수동 QA

1. 새 게임(Lv.0)에서 광물 옆을 지나도 흰빛이 없고, 가스에 들어가면 기존 경고만 나오는지 확인한다.
2. 스캔 Lv.1 구매 직후 30초 안에 반경 3 광물이 10초 흰빛인지 확인한다.
3. 스캔 Lv.2에서 더 먼 광물과 가스가 흰/붉은 빛으로 나뉘고, 붕괴 칸은 흔들림만 남는지 확인한다.
4. 업그레이드 창 수치가 `반경 3` / `반경 7`이지, `+3` / 기본 4 합산이 아닌지 확인한다.
5. 저장 후 이어하기에서 같은 레벨·같은 반경이 유지되는지 확인한다.
