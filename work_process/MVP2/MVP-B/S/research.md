# Phase S — 업그레이드 밸런스 개편

## 0. 기준과 범위

- `init/prompt-B.md` 72번, `init/rule.md`, `work_process/MVP2/upgrade-system-rework-proposal.md`를 기준으로 한다.
- 기존 업그레이드 9개 ID, 구매·저장·적용 파이프라인과 세이브 레벨은 유지한다.
- 이번 단계는 제안서 P1과 P2의 비용·효과·심층 필수 조건을 적용한다.
- 스캔 월드 표시, 구매 팝업, HUD 애니메이션과 탐사 결과 기여도는 별도 P3 작업으로 남긴다.

## 1. 적용한 밸런스

- Lv.1은 구리, Lv.2는 구리+철, 최종 레벨은 철+리튬을 요구한다.
- 드릴 속도는 기본 1초 타일 기준 0.80/0.60/0.45초가 되도록 배율을 조정한다.
- 최대 전력은 기본 100 기준 150/210/280, 최대 화물은 기본 50 기준 80/120/170이 된다.
- 가스 저항은 25/50/75%, 드론 스캔은 기본 반경 4 기준 7/11, 구조 보존은 35/70%가 된다.
- 최대 체력은 기본 100 기준 140/180/230, 재생은 초당 1/2/3이 된다.

## 2. 드릴 전력 효율

- 카탈로그에는 실제 절감률 20/35/50%를 저장한다.
- Provider는 기존 Gameplay 계약과 호환되는 비용 나눗셈 배율로 변환한다.
- 채굴마다 올림하지 않고 이전 성공 채굴의 소수점 잔여 비용을 이어받는다.
- 취소, 자원 가득 참, 전력 부족 등 실패한 채굴은 잔여 비용을 변경하지 않는다.
- 기본 비용 2인 타일 10개는 레벨별로 16/13/10 전력을 사용한다.

## 3. 심층 해금

- 기존 목표 12개 완료와 드릴 Lv.2만 필수 조건으로 유지한다.
- 드론 스캔 Lv.2와 가스 저항 Lv.1 강제를 제거해 전력·화물·가스·스캔 선택 빌드를 허용한다.
- 제안서의 별도 심층 개방 프로젝트 비용(구리 10+철 10)은 명시적인 구매 UI 없이 기존 자동 해금 경로에 넣으면 자원을 예고 없이 차감하므로 이번 단계에 포함하지 않는다.

## 4. 데이터 안정성

- `MvpDataAssetBuilder`와 실제 9개 Upgrade ScriptableObject를 같은 값으로 갱신한다.
- 기존 세이브의 업그레이드 레벨은 그대로 유지되고 새 효과를 읽는다.
- Shared DTO, Save DTO, Scene, Prefab과 공용 폰트는 변경하지 않는다.

## 5. 완료 기준

- 9개 업그레이드의 단계별 비용과 효과가 제안서 1차 값과 일치한다.
- 전력 효율 3개 레벨 모두 동일한 10회 채굴에서 실제 총소모를 줄인다.
- 심층 해금은 드릴 Lv.2 외 선택 업그레이드를 요구하지 않는다.
- App Edit Mode 전체 테스트가 통과하고 범위 밖 Unity 에셋 변경이 없다.
