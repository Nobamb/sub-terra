# Phase N Agent Test

## 1. 정적 검증 항목

| ID | 테스트 항목 | 검증 방법 | 예상 결과 |
| :-- | :-- | :-- | :-- |
| N-S01 | 업그레이드 적용점 | provider 사용 검색 | 필수 효과 모두 소비됨 |
| N-S02 | 데이터 원천 | 코드/카탈로그 검사 | 가격/효과 하드코딩 없음 |
| N-S03 | Surface 참조 | Scene/Prefab 검사 | 판매/제작/업그레이드 연결 |
| N-S04 | 잠금 State | Save DTO 검사 | 진행 상태 저장 |

## 2. 기능 테스트 항목

### N-F01: 판매와 제작 선택

- **준비:** 구리/철/리튬 화물
- **실행:** 일부 판매 후 남은 광물로 시설을 제작한다.
- **예상 결과:** 수량·골드·비용이 정확하고 원자적이다.

### N-F02: Gameplay 업그레이드

- **준비:** 각 업그레이드 전/후 상태
- **실행:** 채굴, 에너지, 화물, 가스, 구조 실패를 반복한다.
- **예상 결과:** 카탈로그 정의만큼 실제 결과가 변한다.

### N-F03: 최대 레벨/자원 부족

- **준비:** 최대 레벨 또는 부족한 비용
- **실행:** 구매를 반복한다.
- **예상 결과:** 실패 이유가 표시되고 State가 불변이다.

### N-F04: 심층 잠금

- **준비:** 신호 미확인/확인과 업그레이드 조건 전후
- **실행:** 심층 진입을 시도한다.
- **예상 결과:** 조건 전에는 차단되고 충족 후 해제된다.

### N-F05: 다음 탐사

- **준비:** 귀환 정산과 업그레이드 완료
- **실행:** 새 탐사를 시작한다.
- **예상 결과:** 저장된 월드/진행을 사용해 한 번만 Mine으로 이동한다.

## 3. 테스트 절차

1. Edit Mode에서 거래·업그레이드·잠금 조건을 검증한다.
2. Play Mode에서 Surface UI와 다음 Mine 진입을 검증한다.
3. M의 저장 왕복에 경제/진행 상태를 포함한다.

## 4. 검증 결과 요약

- **상태:** 미실행
- **모든 항목 통과 시:** Phase N 완료
- **실패 항목 존재 시:** 거래 ID, 비용/보유량, 레벨 전후를 기록한다.
