# Phase N — Surface Base 경제·업그레이드·심층 진행

## 1. 개요

판매·제작·업그레이드 Service와 Surface UI는 존재하지만 한 Run의 결과가 다음 탐사의 실제 Gameplay 수치와 심층 잠금 해제에 연결되는지 완주 검증이 필요하다.

## 2. 작업 목표

- 귀환 화물의 판매/보존/제작 선택을 명확히 제공한다.
- 드릴·에너지·화물·가스 저항·드론 업그레이드를 실제 Runtime에 반영한다.
- 심층 신호 확인과 업그레이드 조건으로 다음 구역 잠금을 관리한다.
- 탐사 결과와 다음 목표를 Surface Base에서 보여준다.

## 3. 구현 범위

- Run result summary와 판매/제작/업그레이드 UI
- `IUpgradeEffectProvider` Gameplay 적용점 전체 연결
- deep-zone unlock 조건과 잠금 UI
- 다음 탐사 시작 guard와 중복 방지
- 판매/구매/잠금 해제 후 autosave
- 계약은 필수 루프를 막지 않는 안내 수준으로 제한

## 4. 권장 구현 방향

1. 기존 Economy/Progression/SurfaceBase Service를 재사용한다.
2. 업그레이드 수치는 카탈로그가 단일 원천이며 Gameplay는 Shared provider로 조회한다.
3. 실제 성공 이벤트만 목표/잠금/저장을 진행시킨다.
4. 판매 전 제작에 필요한 보유량을 UI에서 비교 가능하게 한다.
5. 심층 예고는 MVP 종료 목표이며 후속 지역 전체를 구현하지 않는다.

## 5. 보안 및 안정성 기준

- 거래/업그레이드 실패 시 광물·골드·레벨이 부분 변경되지 않는다.
- 최대 레벨과 잠금 조건을 우회할 수 없다.
- 중복 클릭으로 구매/저장이 두 번 발생하지 않는다.
- 데이터 ID 변경은 Migration 없이 수행하지 않는다.

## 6. 완료 기준

- 한 Run의 화물을 판매하거나 제작에 남길 수 있다.
- 각 필수 업그레이드가 실제 채굴/이동/위험/드론 구조에 적용된다.
- 심층 신호와 잠금 상태가 조건에 따라 정확히 바뀐다.
- 저장/재실행 후 경제와 진행 상태가 유지된다.
