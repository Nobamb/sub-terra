# Phase E — 채굴·전력·드릴·화물 루프 완결

## 1. 개요

현재 클릭/Enter로 타일을 즉시 제거할 수 있지만 PRD의 채굴 시간, 취소, 드릴 레벨, 전력 소비와 화물 중량 감속이 실제 플레이에 연결되지 않았다.

## 2. 작업 목표

- 키보드/마우스 모두 같은 채굴 검증과 완료 경로를 사용한다.
- 타일별 채굴 시간과 드릴 업그레이드 효과를 적용한다.
- 시작/진행/완료 시 전력 정책을 명확히 하고 부족하면 채굴을 막는다.
- Inventory 중량이 Player 속도에 단계적으로 반영된다.
- 채굴 보상과 월드 오브젝트가 정확히 한 번만 생성된다.

## 3. 구현 범위

- Mining progress 상태와 HUD
- `IUpgradeEffectProvider`, Energy 소비 경계 연결
- 이동/입력 해제/거리 이탈 시 취소 정책
- 0~50/50~80/80~100% cargo speed curve
- 최대 적재 거부와 Inventory Full 알림 이벤트
- 일반 암석/광물/가스/잠금/기반 암석 처리 구분

## 4. 권장 구현 방향

1. 클릭과 방향 입력은 목표 셀만 다르게 계산하고 `TryStart/Tick/Complete`를 공유한다.
2. 채굴 수치는 `MiningTileData`와 Upgrade provider에서 조회한다.
3. 전력은 완료 시 일괄 차감 또는 시작 예약 중 하나를 선택하고 취소 정책을 테스트로 고정한다.
4. Inventory 스냅샷 변경 이벤트에서만 이동 배율을 갱신한다.
5. 광물 보상은 Inventory 지급과 월드 드롭 중 디자인상 하나의 소유권을 명확히 한다. 둘 다 유지하면 중복 수집을 막는다.

## 5. 보안 및 안정성 기준

- 같은 타일에 대한 중복 입력으로 이중 보상이 발생하지 않는다.
- 채굴 도중 타일이 외부에서 제거되면 비용/보상을 안전하게 정리한다.
- 최대 적재 거부 시 타일을 제거하거나 광물을 잃지 않는다.
- 경계/잠금 타일은 전력과 시간을 소비하지 않는다.

## 6. 완료 기준

- 타일별 시간·드릴 레벨·전력 요구가 실제 채굴에 반영된다.
- 클릭/Enter가 같은 결과와 실패 이유를 제공한다.
- 화물 비율에 따라 이동 속도가 세 단계로 변한다.
- 적재 초과, 전력 부족, 취소, 중복 입력 테스트가 통과한다.
