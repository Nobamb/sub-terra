# Phase E Agent Test

## 1. 정적 검증 항목

| ID | 테스트 항목 | 검증 방법 | 예상 결과 |
| :-- | :-- | :-- | :-- |
| E-S01 | 채굴 데이터 경로 | 코드/카탈로그 검사 | 시간·레벨·전력 하드코딩 없음 |
| E-S02 | 입력 단일 완료 경로 | 호출 그래프 검사 | 클릭/Enter가 Complete 공유 |
| E-S03 | 이동 감속 연결 | 이벤트 구독 검사 | Inventory 변경 시만 갱신 |
| E-S04 | 진행 UI | Prefab 참조 검사 | progress 표시 연결 |

## 2. 기능 테스트 항목

### E-F01: 타일별 채굴 시간

- **준비:** 암석/구리/철/리튬과 고정 드릴 레벨
- **실행:** 동일 입력으로 채굴한다.
- **예상 결과:** 데이터에 정의된 시간과 레벨 제한이 적용된다.

### E-F02: 전력 부족과 취소

- **준비:** 부족한 전력 또는 채굴 중 이동
- **실행:** 채굴을 시작/취소한다.
- **예상 결과:** 타일·보상·전력이 정책에 맞게 보존된다.

### E-F03: 중복 완료 방지

- **준비:** 한 광물 타일
- **실행:** 클릭과 Enter를 같은 프레임에 입력한다.
- **예상 결과:** 타일 제거와 보상이 각각 한 번만 발생한다.

### E-F04: 화물 감속

- **준비:** 적재율 49%, 50%, 80%, 100%
- **실행:** 일정 시간 수평 이동한다.
- **예상 결과:** PRD 단계에 맞는 이동 거리 차이가 난다.

### E-F05: 최대 적재

- **준비:** 남은 용량보다 무거운 광물
- **실행:** 채굴 완료를 시도한다.
- **예상 결과:** 광물이 유실되지 않고 명확한 가득 참 알림이 발생한다.

## 3. 테스트 절차

1. Edit Mode에서 시간/전력/감속 계산을 검증한다.
2. Play Mode에서 실제 Input System과 Tilemap을 사용한다.
3. HUD, Inventory, Player 속도, 타일 상태를 한 시나리오에서 비교한다.

## 4. 검증 결과 요약

- **상태:** 미실행
- **모든 항목 통과 시:** Phase E 완료
- **실패 항목 존재 시:** 타일 ID, 입력 경로, 전력 전후, 보상 횟수를 기록한다.
