# Phase A Agent Test

## 1. 정적 검증 항목

| ID | 테스트 항목 | 검증 방법 | 예상 결과 |
| :-- | :-- | :-- | :-- |
| A-S01 | PRD 추적성 | 필수 기능과 MVP2 단계 매핑 검사 | 누락 0 |
| A-S02 | Scene 필수 구조 | Integration Scene 객체/컴포넌트 검사 | 필수 Root와 참조 존재 |
| A-S03 | Missing Script | Scene/Prefab 순회 | 0개 |
| A-S04 | Placeholder 식별 | BuildingData Runtime Prefab 검사 | 실제/임시가 명시됨 |
| A-S05 | 테스트 격리 | Save/Test 코드 경로 검사 | 사용자 세이브 접근 없음 |

## 2. 기능 테스트 항목

### A-F01: 읽기 전용 기준선 생성

- **준비:** 깨끗한 테스트 프로젝트 상태
- **실행:** Readiness 검증기를 실행한다.
- **예상 결과:** 에셋을 변경하지 않고 상태 보고서만 반환한다.

### A-F02: 누락 참조 검출

- **준비:** 복제한 테스트 Prefab에서 필수 참조 하나를 제거한다.
- **실행:** 검증기를 실행한다.
- **예상 결과:** 정확한 에셋과 필드가 실패로 보고된다.

### A-F03: 대역/Runtime 결과 분리

- **준비:** 대역 테스트만 통과하고 Runtime 검증은 없는 항목
- **실행:** 완료 판정을 요청한다.
- **예상 결과:** `부분 구현` 또는 `미검증`으로 남는다.

### A-F04: Scene 스모크 진입

- **준비:** Bootstrap부터 정상 새 게임 경로
- **실행:** Integration Scene 활성화까지 진행한다.
- **예상 결과:** 중복 전역 Root 없이 HUD와 입력 게이트가 열린다.

## 3. 테스트 절차

1. Edit Mode 정적 감사를 실행한다.
2. 보고서 실행 전후 `git status`를 비교한다.
3. Bootstrap Play Mode 스모크를 실행한다.
4. 실패 항목을 B~P 단계에 연결한다.

## 4. 검증 결과 요약

- **상태:** 미실행
- **모든 항목 통과 시:** Phase A 완료, B~P 착수 가능
- **실패 항목 존재 시:** 누락된 증거와 차단 단계를 기록하고 완료 처리하지 않는다.
