## 2. 기능 테스트 항목

### O-F01: 실제 입력 전체 완주

- **준비:** 새 설치에 준하는 빈 세이브
- **실행:** README의 12단계 최종 시나리오를 수행한다.
- **예상 결과:** 강제 Debug 없이 심층 신호와 다음 탐사 예고까지 도달한다.

### O-F02: 순서 밖 행동

- **준비:** 각 목표 이전 상태
- **실행:** 후속 성공/실패 이벤트를 임의 순서로 발생시킨다.
- **예상 결과:** 현재 목표의 유효 성공만 진행시킨다.

### O-F03: 위험 UI 선점

- **준비:** 튜토리얼/건설 UI가 열린 상태
- **실행:** 가스 또는 붕괴 임박을 발생시킨다.
- **예상 결과:** 긴급 경고가 즉시 보이고 입력을 부당하게 막지 않는다.

### O-F04: 해상도/접근성

- **준비:** 16:9, 16:10, 4:3과 모션 감소 설정
- **실행:** 핵심 UI 상태를 캡처한다.
- **예상 결과:** 잘림/겹침이 없고 색상 외 정보가 유지된다.

### O-F05: 밸런스 세션

- **준비:** 고정 빌드와 테스트 양식
- **실행:** 내부 3회 이상 및 신규 사용자 플레이를 기록한다.
- **예상 결과:** 막힘, 평균 완주 시간, 귀환 선택, 경고 빈도와 조정 근거가 남는다.

## 3. 테스트 절차

1. 자동 Objective/레이아웃 회귀 테스트를 실행한다.
2. 실제 입력 전체 완주를 녹화 또는 체크리스트로 기록한다.
3. 플레이 테스트 수치는 데이터 변경 전후로 비교한다.

## 4. 검증 결과 요약

- **상태:** 미실행
- **모든 항목 통과 시:** Phase O 완료
- **실패 항목 존재 시:** 막힌 목표, 실제 이벤트, 화면 상태와 재현 순서를 기록한다.
