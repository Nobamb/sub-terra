## 2. 기능 검증

### U-F01: 연결된 보건소에서 회복

- 감소한 체력으로 연결된 보건소를 사용한다.
- 최대 체력으로 복구되고 `체력 회복이 완료되었습니다.`가 표시되어야 한다.

### U-F02: 최대 체력에서 사용

- 최대 체력으로 연결된 보건소를 사용한다.
- 자원 차감 없이 성공하고 `이미 체력이 최대입니다.`가 표시되어야 한다.

### U-F03: 전력망 미연결

- 엘리베이터와 전진기지 코어 반경 밖의 보건소를 사용한다.
- 체력 회복 명령은 호출되지 않고 지정된 미연결 안내 문구가 3초 표시되어야 한다.

### U-F04: 보건소 퀘스트

- 충전소 퀘스트를 완료하면 보건소 퀘스트가 시작되어야 한다.
- 코어 반경 10칸 밖의 보건소 사용은 완료되지 않아야 한다.
- 반경 안 보건소 설치 후 성공적으로 사용하면 심층 구역 해금 퀘스트로 이동하고 완료 수가 13이어야 한다.

### U-F05: 저장 마이그레이션

- 충전소 이전 저장은 변경하지 않는다.
- 충전소 완료/심층 해금 이후 저장은 완료 수를 1 증가시키고 현재 목표를 유지한다.
- 기존 17개 완료 저장은 18개 완료로 변환한다.
- v3 왕복 저장 후 재로드해도 증가가 재적용되지 않아야 한다.

## 3. 자동 검증 결과

- Unity 컴파일: 성공, 오류 0
- Unity 자산 검사: Catalog의 충전소/보건소 인덱스 `3/4`, 전력 수요 3, Menu 순서 충전소/보건소/저장고, Integration의 복원 정의 1개와 배치 바인딩 1개 확인
- Edit Mode 전체 테스트: 664 통과 / 1 실패 / 0 건너뜀
- 보건소 관련 테스트: 모두 통과
- 남은 실패: 기존 `PromptB85EmergencyRescueChipTests.PromptB85_ChipFollowTick_PlacesChipAbovePlayerHead`의 Y 좌표 기대값 2936, 실제값 2488. 보건소 변경과 무관해 수정하지 않음
- Play Mode 수동 경로: 자동 Edit Mode의 배치 거리·사용·퀘스트 연동으로 대체, 수동 QA 권장

## 4. 수동 QA

2. 보건소를 설치하고 흰색 사각형과 빨간 십자 외형을 확인한다.
3. 전력망 밖에서 `E` 사용 시 미연결 안내가 표시되는지 확인한다.
4. 피해를 받은 뒤 전력망에 연결된 보건소에서 `E`를 눌러 최대 체력 회복과 완료 문구를 확인한다.
