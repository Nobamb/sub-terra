# Phase B — 결정론적 40m 지층과 깊이별 자원 분포

## 1. 개요

현재 40줄 암석은 존재하지만 구리·철·리튬·가스·잠긴 신호가 소수 고정 좌표에만 있다. 같은 Seed에서 재현되는 깊이별 지층 생성과 플레이 가능한 광맥 분포가 필요하다.

## 2. 작업 목표

- 1~15m 상층, 15~35m 중층, 35~40m 심층 규칙을 구현한다.
- 전체 지층의 암석 85~90%, 자원/가스/신호 약 10%를 목표 범위로 둔다.
- 낱개 점이 아닌 2~5칸 광맥과 위험 포켓을 생성한다.
- 시작/엘리베이터/필수 튜토리얼 경로는 항상 통과 가능하게 보장한다.

## 3. 구현 범위

- Seed 기반 `MineLayerGenerator`와 분포 ScriptableObject
- 파괴 불가능한 좌우/하단 경계 암석
- 상층 구리, 중층 철·가스, 심층 리튬·잠긴 신호
- 필수 경로 보호 마스크와 생성 후 연결성 검증
- 생성 Seed/버전 및 기본 월드 재구성 경계

## 4. 권장 구현 방향

1. Unity 전역 Random 상태 대신 로컬 Seed PRNG를 사용한다.
2. 깊이 band별 가중치와 vein 크기를 데이터로 둔다.
3. 먼저 암석을 채운 뒤 후보 셀을 셔플하고 간격 제한을 적용한다.
4. 시작 지점, 엘리베이터 shaft, 안전 경로와 설치 tutorial 공간은 자원/가스 배치에서 제외한다.
5. 저장은 기본 지층 전체가 아니라 Seed·generatorVersion·변경점만 기록한다.

## 5. 보안 및 안정성 기준

- 생성기는 같은 Seed/버전에서 동일 결과를 내야 한다.
- 모든 깊이에서 필수 목표의 최소 수량을 보장하되 무한 재시도를 하지 않는다.
- 경계 타일은 채굴 불가 데이터로 구분한다.
- 대규모 Tilemap을 매 프레임 재생성하지 않는다.

## 6. 완료 기준

- 40줄과 경계가 실제 Integration Scene에서 생성된다.
- 100개 이상의 고정 Seed 표본이 분포 허용 범위를 만족한다.
- 상/중/심층 자원 규칙과 필수 목표가 보장된다.
- 같은 Seed 재생성 결과의 타일 ID 해시가 일치한다.
- 시작 지점부터 심층 신호까지 최소 한 경로가 존재한다.
