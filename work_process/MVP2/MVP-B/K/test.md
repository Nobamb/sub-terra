# Phase K Agent Test

## 1. 정적 검증 항목

| ID | 테스트 항목 | 검증 방법 | 예상 결과 |
| :-- | :-- | :-- | :-- |
| K-S01 | World ViewSocket | Drone/View Prefab 검사 | anchor와 view 참조 존재 |

| K-S03 | raycast 차단 | CanvasGroup/Graphic 검사 | 입력 차단 없음 |

## 2. 기능 테스트 항목

### K-F01: 상황별 팝업

- **준비:** 가스, 붕괴, 가득 참, 저전력, 희귀 광물 Context
- **실행:** 각 이벤트를 실제 Runtime에서 발생시킨다.
- **예상 결과:** 올바른 추천과 말풍선이 드론 위에 표시된다.

### K-F02: 긴급 우선순위

- **준비:** 일반 대사 표시 중 붕괴 임박
- **실행:** 긴급 이벤트를 발행한다.
- **예상 결과:** 긴급 경고가 즉시 선점한다.

### K-F03: 쿨다운

- **준비:** 같은 Context 반복
- **실행:** 분석을 여러 번 요청한다.
- **예상 결과:** 설정된 시간 안에는 같은 일반 대사가 반복되지 않는다.

### K-F04: 수치 일치

- **준비:** 고정 GameState/DroneContext
- **실행:** 팝업과 상세 패널을 표시한다.
- **예상 결과:** 전력·가스·구조·화물 근거가 실제 Context와 같다.

### K-F05: 오프라인 폴백

- **준비:** 실패/timeout transport
- **실행:** 대사를 요청한다.
- **예상 결과:** 제한 시간 안에 템플릿 대사가 표시되고 진행이 계속된다.

## 3. 테스트 절차

1. Edit Mode에서 추천/우선순위/쿨다운을 검증한다.
2. Play Mode에서 실제 드론 위치와 World Canvas를 검증한다.
3. 다양한 카메라 경계에서 팝업이 화면 안에 보이는지 캡처한다.

## 4. 검증 결과 요약

- **상태:** 미실행
- **모든 항목 통과 시:** Phase K 완료
- **실패 항목 존재 시:** Context, 선택 action, template ID, cooldown 상태를 기록한다.
