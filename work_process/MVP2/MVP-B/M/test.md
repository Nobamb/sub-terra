## 2. 기능 테스트 항목

### M-F01: 전체 왕복

- **준비:** 채굴, Support, 시설, 케이블, 가스, 붕괴, 체크포인트가 있는 Run
- **실행:** 저장 후 새 Runtime을 구성해 로드한다.
- **예상 결과:** State, Tilemap, 건물, 위험, UI가 저장 직전과 같다.

### M-F02: 같은 Seed+변경점

- **준비:** 생성된 기본 월드와 변경 목록
- **실행:** 기본 월드 재생성 후 변경점을 적용한다.
- **예상 결과:** 좌표별 타일 ID 해시가 저장 직전과 일치한다.

### M-F03: 손상 복구

- **준비:** 손상된 정식 파일과 정상 backup
- **실행:** 이어하기를 수행한다.
- **예상 결과:** backup으로 복구하고 오류를 안전하게 안내한다.

### M-F04: 저장 중 실패

- **준비:** tmp 기록/교체 단계 실패 대역
- **실행:** 저장을 요청한다.
- **예상 결과:** 기존 정상 파일이 유지된다.

### M-F05: Migration

- **준비:** 이전 Save Version과 누락된 신규 필드
- **실행:** 로드한다.
- **예상 결과:** 안전한 기본값과 명시된 변환으로 현재 버전에 도달한다.

### M-F06: 활성화 게이트

- **준비:** 지연되는 월드 복원
- **실행:** 로드 중 HUD/입력을 관찰한다.
- **예상 결과:** 파생 재계산 전에는 비활성, 이후 한 번 활성화된다.

## 3. 테스트 절차

1. Edit Mode에서 codec, validator, migration, 파일 실패를 검증한다.
2. Play Mode에서 실제 Integration Scene 전체 왕복을 실행한다.
3. 저장 전후 월드 해시와 Runtime instance ID 집합을 비교한다.

## 4. 검증 결과 요약

- **상태:** 미실행
- **모든 항목 통과 시:** Phase M 완료
- **실패 항목 존재 시:** Save Version과 실패 단계만 기록하고 JSON 원문은 남기지 않는다.
