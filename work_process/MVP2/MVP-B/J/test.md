# Phase J Agent Test

## 1. 정적 검증 항목

| ID | 테스트 항목 | 검증 방법 | 예상 결과 |
| :-- | :-- | :-- | :-- |
| J-S01 | Run 전이 | Service API 검사 | 명시적 상태 전이 |
| J-S02 | Scene 경로 | Build Settings/Loader 검사 | Surface/Mine 등록 |
| J-S03 | 체크포인트 DTO | 저장 타입 검사 | ID·좌표만 저장 |
| J-S04 | 자동 저장 이유 | enum/바인딩 검사 | 정상 귀환/정산 구분 |

## 2. 기능 테스트 항목

### J-F01: 정상 탐사 왕복

- **준비:** Surface Base 새 Run
- **실행:** Mine 진입, 채굴, 엘리베이터 귀환
- **예상 결과:** Run 결과와 화물이 Surface Base에 전달된다.

### J-F02: 전진기지 체크포인트

- **준비:** 활성 코어와 안전 spawn
- **실행:** 체크포인트를 등록하고 귀환/재진입한다.
- **예상 결과:** 올바른 위치와 상태로 복귀한다.

### J-F03: 비활성 기지

- **준비:** 전력 끊김 또는 거리 밖 전진기지
- **실행:** 귀환/정산을 요청한다.
- **예상 결과:** 실패 이유가 표시되고 State가 불변이다.

### J-F04: 중복 귀환

- **준비:** 귀환 가능 상태
- **실행:** 상호작용을 연속 입력한다.
- **예상 결과:** 결과/저장/Scene 로드가 한 번만 발생한다.

### J-F05: Scene 전환 실패

- **준비:** 실패하는 SceneLoader 대역
- **실행:** 귀환을 요청한다.
- **예상 결과:** Run과 화물이 유지되고 재시도 가능하다.

## 3. 테스트 절차

1. Edit Mode에서 전이와 멱등성을 검증한다.
2. Play Mode에서 실제 엘리베이터/코어 상호작용과 Scene 이동을 검증한다.
3. 저장 이벤트 횟수와 활성 Scene을 함께 확인한다.

## 4. 검증 결과 요약

- **상태:** 미실행
- **모든 항목 통과 시:** Phase J 완료
- **실패 항목 존재 시:** 전이 전/후 Run 상태와 SceneLoader 결과를 기록한다.
