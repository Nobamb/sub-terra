# Correction Delta 2 — Prompt-B 137-1 (Claude 리뷰 → Codex)

## 리뷰 판정
Delta 1 반영분(두 알파 분리, 비활성 정착, 파괴 안전, 패딩 보정, 시간 측정, 연속 캡처로 확인한 중앙→가장자리 등장/퇴장)은 **수용**한다. 코드·테스트 구조는 변경하지 않는다.
남은 문제는 **프레임 시각 품질 하나**다 (요구 §2 "각진 금속 모서리와 층이 구분되는 얇은 테두리", 기존 HUD/팝업과의 통일감).

증거: `b137-1/clock-1920x1080-normal.png`를 (800,0)-(1120,100)으로 4배 확대해 구 프레임(`clock-1920x1080-normal.png`, B-137)과 비교했다.
- 새 프레임은 회청색 림 + 안쪽 청록 이중선 + 번짐으로 층이 생겼다(개선).
- 그러나 **모서리 금속 플레이트가 14×10px로 너무 작고 어두워 거의 안 보인다**(구 프레임의 사각 브래킷보다 존재감이 오히려 약함). 외곽 모서리 잘림도 6px(32px 텍스처, border 8)라 실루엣이 거의 직사각형으로 읽힌다. 좌측 HUD(`HUD-frame.png`)의 비스듬히 잘린 모서리 + 회색 금속 코너 조각 + 리벳 문법이 전달되지 않는다.

## 수정 범위 (이것만)
파일: `Scripts/App/UI/HUD/MineResetClockFrameArt.cs`, `MineResetClockView.cs`의 `Build()` 중 `Bracket0~3`/프레임 층 크기·위치·색 상수만. 테스트는 값 의존 단언이 깨질 때만 갱신(의미 약화 금지).

1. **외곽 잘림 강화**: `PlateFill/Rim/Inner`의 모서리 잘림을 32px 텍스처 기준 **≥9px**(280×78에서 대각선이 뚜렷이 보이도록)으로 키우고 9-slice border를 그에 맞게 조정(border ≥ 잘림 크기). `Inner`(청록선)도 같은 비율로 따라가 모서리에서 꺾여 보이게(현재처럼 직각 코너 금지).
2. **코너 플레이트 확대·입체화**: `CornerPlate()`를 **약 20×14px**로 키우고 비스듬히 잘린 금속 조각 형태(바깥 변은 프레임 잘림선과 평행)로, 밝은 윗면 1px 하이라이트 + 어두운 아랫면 1px(베벨) + 리벳 점 1개를 알파/명도로 표현. 흰색 스프라이트 + `Image.color`(고정 회청색, 현재 `~(0.38,0.48,0.54)`보다 약간 밝게, 단 구간색 계열 금지)로 입힌다. 위치는 잘린 모서리에 맞춰 재배치(`Bracket0~3` 좌표/스케일 반전 유지).
3. **크기·가독성 불변**: `ClockRoot` 280×78, 숫자 영역(220×36, 24×36, 간격), 라벨 위치·크기, 앵커·위치 불변. 코너 플레이트가 라벨/숫자와 겹치거나 숫자 폭을 줄이면 안 된다. 외곽 번짐 최대 6px 유지.
4. **색 규칙 불변**: 철판·림·코너 플레이트 고정색, 구간색은 안쪽 청록선·번짐·세그먼트·콜론·DigitGlow만. 마지막 1분 맥동은 안쪽선·번짐에만.
5. 전원 연출은 건드리지 않는다. 단, 모서리 형태가 바뀌어도 `RectMask2D` 수축·`FrameFlash`가 어색하게 보이지 않는지 연속 캡처 1세트(청록 on/off)로 재확인.
