## 1차(110%·0.15초)가 사용자에게 안 보인 이유
1. **머티리얼 공유 버그.** 꺾쇠·조준선·칸 틴트가 `Sprites/Default` 머티리얼 하나를 공유해, 프리뷰 렌더에서 모두 첫 텍스처로 그려졌다(뭉툭한 청록 덩어리). 부품마다 머티리얼을 분리하고 `mainTexture`를 직접 넣어 해결했다.
2. **연출이 너무 약했다.** 1080p에서 칸이 약 108px인데 110%·0.15초는 약 5px 변화라 사실상 안 보였다. 명세 초안(110%, 0.15초, 알파 0.2)에서 **의도적으로 벗어나** 더 크게 키웠다(아래).
3. **그림이 거칠었다.** 8px 텍스처의 2px 두께 청록 L자가 청록 배경에 묻혔다.

## 새 디자인 (코드로 생성, 128px = 1칸, 쌍선형)
- **꺾쇠 4개:** 밝은 청백 심지 + 어두운 청록 외곽선 + 청록 광채. 바깥 모서리는 깎고(챔퍼) 팔 끝은 비스듬히 잘랐다. 안쪽에 작은 다이아 점. 두께 9px/128(≈0.07칸), 팔 길이 44px(≈0.34칸).
- **중앙 조준선:** 모서리만 남긴 다이아몬드 대시 링 + 바깥 눈금 4개 + 중심점(0.5칸). 드론 스캔의 X·링·스파크와 다르다.
- **칸 틴트:** 안쪽 가장자리가 은은히 밝은 청록 틴트 + 얇은 테두리(평상시 세기 `FillSettledAlpha` 0.5).
- 정렬: 틴트 23 → 꺾쇠 24 → 조준선 25 (균열 90~92·스캔 94~95 아래).
- 재질: 부품별 `Sprites/Default` 머티리얼 3개(코너/조준선/틴트), `mainTexture` 직접 지정.

## 연출 (최종 상수, `MiningReticleMotion`)
| 항목 | 값 |
|---|---|
| `AppearSeconds` | 0.34 |
| 꺾쇠 | 칸 중심에서 1.85배 벌어진 위치 → 1배로 조여듦(ease-out cubic), 알파 0 → 1 (첫 35%) |
| 조준선 | 15% 늦게 시작, 2.4배 → 1배, 60° 돌며 → 0°, 알파 0 → 1 |
| 틴트 | 0 → 1(40%) → 평상시 0.5로 가라앉음 |
| `RetargetSeconds` | 0.16 — 보이는 중 칸이 바뀔 때 꺾쇠 1.22배→1, 조준선 1.5배·45° 회전→0, 틴트 살짝 밝아짐 |

- **등장은 숨김 → 표시일 때만 재생.** 창을 닫거나 목표가 사라졌다 다시 뜨면 다시 재생.
- **칸 이동(명세 기본값과 다른 점):** 사라졌다 나타나지 않고 기존 0.1초 미끄러짐 위에 작은 재조준 맥동만 얹었다. 마우스 호버로 칸을 옮길 때도 락온 느낌이 보이게 하려는 것이다. 원치 않으면 `RetargetSeconds`를 0에 가깝게 하거나 `SetTarget`의 `retargetElapsed = 0f` 한 줄을 지우면 된다.
- 등장용 새 ReduceMotion 분기 없음(모션 감소에서도 등장은 재생). 모션 감소 중 칸 이동은 기존대로 정지 꺾쇠이고 재조준 맥동도 없다.
- 조임과 등장 분리: 조임(`Inset`)은 꺾쇠 위치에서 `(half - inset)`만, 등장·재조준은 그 위에 곱하는 배수·알파·회전만 담당한다.
