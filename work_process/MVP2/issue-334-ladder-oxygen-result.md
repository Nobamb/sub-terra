# #334 사다리·점프 산소 비교

2026-11-17 · 기준 main `7bca7db0` · Unity PlayMode

## 측정 조건

- 실제 플레이어 프리팹과 `PlayerSurvivalSettings` 에셋을 사용했다. 10m 회복 구간 밖인 약 20m 깊이에 가스 없는 1m 시험 코스를 구성했다.
- 같은 바닥에서 출발해 같은 높이의 단방향 발판에 안착할 때까지 게임 시간과 실제 산소 잔량 차이를 기록했다. 사다리는 발이 발판 위로 나오면 놓았다.
- 빈 짐(0%)·만적(100%)에 실제 화물 속도·점프 배율과 산소 적재율을 적용했다. 물리 간격은 프로젝트 설정인 0.02초다.

## 후속 확인

실제 광산의 연속 상승 경로에서 오르는 시간과 남은 산소로 버틸 수 있는 시간을 비교한다. 산소 업그레이드는 #336에서 적용된 뒤 같은 경로에서 전후 차이를 확인한다.
