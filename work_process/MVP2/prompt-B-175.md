## 3. 재생 (그림 번호 1부터)
1. 점프 키 → 물리는 지금처럼 즉시. 그림은 **processing 1→5 약 40fps**(0.125초)로 바로 시작. ready는 점프 전에 틀지 않는다.
2. 상승: **processing 6→24는 시간 대신 상승 진행도**로 고른다. 진행도 = 1 − (현재 위 속도 ÷ 점프 시작 위 속도), 0~1로 자르고 되돌아가지 않게(줄어들지 않게) 한다. 화물로 점프가 낮아져도 정점에서 24에 닿는다. 1~5가 아직 안 끝났으면 끝난 뒤 이어 간다.
3. 정점 이후(위 속도 ≤ 0): **fall 1→15 약 40fps 한 번**(0.375초), 이어서 **fall 18→24 12fps 반복**(24→18 이음새가 자연스러움).
4. 점프 없이 발판에서 떨어질 때(코요테 시간 포함)는 processing 없이 **fall 1부터**. 코요테 시간 안에 점프하면 1번 규칙으로 바꾼다.
5. 착지: 땅에 닿으면 **ready 8→1 약 30fps**(약 0.27초) 후 대기/걷기.
   - 착지 중 좌우 이동 입력 → 바로 걷기. 점프 입력 → 바로 1번(새 점프).
   - 착지 순간 점프 버퍼가 남아 있어 곧바로 다시 뛰면 착지 그림을 건너뛴다.
   - 착지 중 채굴·다침·쓰러짐·사다리는 지금 우선순위대로 바로 덮는다.
6. 사다리 위에서 내려오기 직전 "Jump" 표시(~295)는 지금 그림 대신 fall 루프 프레임을 쓴다. 사다리에서 점프로 떼어 낼 때는 1번 규칙.
7. 걷기 접지 유예(타일 경계 한 틱)는 그대로. 아주 짧은 공중(유예 이내)에는 fall로 바꾸지 않는다.
8. 출렁임 보정: 설정값 `fallBobCompensation`(기본 0, 끔). 켜면 fall 1~15의 장별 발 위치 차이만큼 그림을 반대로 옮긴다(장별 보정표는 정렬 스크립트가 만들어 둔다). 이번 기본은 끔.
9. 좌우 반전은 지금처럼 `PlayerFacing`이 처리(모든 점프 그림 반전 대상).

## 사용자 테스트 가이드 (보고서에 그대로 넣기)
디버그 터미널: 플레이 중 **Ctrl + `**(1 왼쪽 키).
1. 평지에서 점프 → 키를 누르는 순간 바로 뜬다(웅크렸다 늦게 뜨는 느낌 없음). 펴며 뛰고, 다리를 접고 오르고, 정점에서 떨어지는 자세로 바뀐다.
2. 착지 → 웅크렸다 일어서고 대기 자세로 자연스럽게 이어진다. 착지 소리는 전과 같은 때 난다.
3. 높은 데서 걸어서 떨어진다 → 처음부터 떨어지는 자세로 나오고, 오래 떨어지면 같은 자세가 끊김 없이 반복된다.
4. 발판 끝에서 떨어지자마자(아주 짧은 순간) 점프 → 정상 점프 동작이 나온다.
5. 착지 직전에 점프 키를 미리 눌러 둔다 → 착지 동작 없이 바로 다시 뛴다.
6. 착지 동작 중 좌우 키 → 바로 걷기. 점프 키 → 바로 다시 뛴다.
7. 좌우로 방향을 바꾸며 점프 → 모든 단계에서 몸이 진행 방향을 본다.
8. 화물을 많이 실어 점프가 낮아진 상태로 점프 → 정점에서 떨어지는 자세로 정확히 바뀐다(화물 명령이 있으면 사용).
9. 사다리를 타다 점프로 떼어 낸다 / 사다리 꼭대기에서 내려온다 → 그림이 튀거나 크기가 바뀌지 않는다.
10. 대기 ↔ 점프 ↔ 걷기를 오갈 때 캐릭터 크기·발 위치가 순간 커지거나 떠 보이지 않는다.
11. 공중에서 다치기(`hp` 명령 후 낙하 피해 등) → 다침 동작이 바로 덮는다. 사다리 채굴·바닥 채굴은 전과 같다.
12. 관제 터미널 점프 키 데모 그림이 새 그림이다.
13. Unity Console에 새 빨간 오류·노란 경고가 없다(기존 URP stereoTargetEye, obsolete, 라이선스 로그 제외).
