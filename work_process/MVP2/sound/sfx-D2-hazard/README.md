# Sub-Terra D-2 위험·생존 효과음 (정리본, 2026-10-26)

공통: 44.1kHz 16bit **모노** WAV. 20Hz 아래 저음·직류 성분 제거. 앞 무음 제거(소리 시작 전 약 2.5ms만 남김) + 2ms 페이드인, 뒤는 짧은 페이드아웃. 피크 -1dBFS. 음 높이·속도는 바꾸지 않음.
음량(dBFS)은 피크 / 전체 평균(RMS) / 가장 큰 0.1초 평균.
mp3는 들어보기용(192kbps). 게임에는 wav를 넣음.

## 참고
- player_hurt의 "지지직"은 Metal Crack 원본의 금속 "퉁"(앞 0.5초) 뒤에 나오는 전기 튀는 부분만 썼고, 600Hz 아래를 잘라 금속 울림이 섞이지 않게 함. 충격은 Big Hit 쪽만 씀.
- low_health_warning은 원본이 반복 경보지만 게임에서는 **한 번만** 재생(loop 끔). 음 높이가 약 196Hz로 일정한 버즈음이라 음이 "웽~" 오르내리는 광산 위험 경보(Factory Alarm)와는 다르게 들림. 다만 소리가 꽤 커서(RMS -9dB) 칸 값 음량을 0.5 안팎부터 들어보며 맞추기 추천.
- gas_pulse_loop도 RMS -10.5dB로 큰 편. 계속 반복되는 소리라 음량 0.4~0.5부터 시작 추천.
- 경보(Alert) 채널은 한 번에 1개라 다른 경보를 끊음. low_health_warning을 어느 채널에 둘지는 프롬프트에서 정하기.
