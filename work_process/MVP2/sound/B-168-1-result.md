## 원인 확인

변경 전에 Bootstrap → 메모리 저장소 새 게임 → 지상 탐사 버튼 실제 입력 → 광산 → 전력 0 → 구조 팝업 → 닫기 버튼 실제 입력을 실행했다. `UiPopupClose` 요청은 6.894초, `RescueHoloOpen` 요청은 7.194초로 약 0.30초 차이였다. 해당 시점에 클립이 할당된 AudioSource의 `isPlaying=true`, `StartedCount=7`, source volume `0.5`, listener volume `0.5`, startTime `0`을 확인했다. 재생 경로 누락은 발견하지 못했다.

홀로그램 클릭으로 다시 열 때는 `UiClick`과 `UiPopupOpen`만 요청되고 `RescueHoloOpen`은 0회였다. 첫 기준 실행은 이후 ESC 가상 입력 대기에서 끝까지 검증되지 않아 통과로 집계하지 않았다. 최종 검사는 문서가 허용한 닫기 버튼 경로를 사용한다. 연속 검사 첫 실행에서는 이전 검사 정리 후 `SfxPlayer`가 없어 새 검사 1건이 실패했고, 테스트 초기화를 보완한 뒤 전체 4건이 통과했다.

WAV 원본을 읽어 계산한 펼침 첫 0.32초 RMS는 기존 `0..0.32초 × 0.5`가 **-24.63 dBFS**, 변경 `.12..44초 × 0.7`가 **-16.32 dBFS**다. 초반 음량이 약 8.3 dB 커지므로, 앞부분이 작고 팝업 닫힘 소리와 겹친다는 추정에 맞춰 지정 값을 적용했다. 실제 마스킹 여부·청감은 직접 청취하지 못해 **미검증**이다. UiPopupClose 원본은 MP3여서 표준 WAV 분석에서는 제외했다.

| 소리 | 최대 0.1초 RMS, 기존 칸 적용 | 변경 칸 적용 |
|---|---:|---:|
| 작은 시설 | -18.70 dBFS | -15.87 dBFS |
| 큰 시설 | -15.09 dBFS | -10.66 dBFS |
| 가스 맥박 | -10.84 dBFS | -12.31 dBFS |

위 수치는 버스·마스터·효과음 배율을 1로 본 원본 PCM 기준이며 Unity 가져오기 압축 후 출력과는 차이가 있을 수 있다. 가스 음량은 약 15.6% 감소했다. 개별 WAV 피크는 약 -1 dBFS이고 칸 최대값은 1이지만, 다른 소리와 섞인 최종 출력의 왜곡까지 입증한 것은 아니다.

### 문서와 기존 게임 동작의 차이

전력을 회복하면 `ResetEpisode()`가 `initialPopupShown=false`로 초기화하므로 다음 전력 0에서도 팝업이 자동 표시된다. 기존 B-135 검사도 이 동작을 기대한다. 이번 범위는 게임 로직 변경을 금지하므로 유지했다. 실제 재고갈 후 팝업을 닫는 경로를 검사하며, 팝업 없는 `BeginDepletionEpisode` 분기는 같은 고갈 중 안내를 숨기고 전력 모델 갱신 이벤트를 보내 별도로 검사한다. 후자는 실제 재충전·재고갈 시나리오가 아니다.

지정 조정 후에도 닫힘 소리와 초반 약 0.6초가 겹치는 구조는 같다. 실제 청취에서 여전히 묻힌다면 **구조 팝업을 닫아 홀로그램을 표시하는 경우에만 닫힘 소리를 낮추는 방안**을 검토할 수 있다. 이 대안은 적용하지 않았다.

## 미검증 및 수동 확인 체크리스트

직접 스피커로 청취하는 항목과 실제 건설·시설 이동·가스 구역에서의 체감은 **미검증**이다. ESC 입력 및 실제 재충전 후 팝업 없이 펼침은 이번 검사로 입증하지 않았다. 아래 2번의 ‘팝업 없이’는 위 기존 게임 동작과 다르다.

1. 전력이 0이 되면 구조 팝업이 뜬다. 닫으면 머리 위 홀로그램이 펼쳐지는 바로 그 순간 "지직" 글리치가 분명히 들린다.
2. 전력을 다시 채웠다가 또 0이 되면(팝업 없이 홀로그램만 뜰 때)도 펼쳐지는 순간 "지직"이 난다.
3. 홀로그램을 눌러 창을 열면 클릭·팝업 열림 소리만 나고, 펼침 "지직"이 또 나지 않는다.
4. 사다리·버팀목·조명 설치 "철컥"이 전보다 또렷하다.
5. 충전기·보관함 같은 큰 시설 설치 "쿵-철컹"이 작은 시설보다 크게 들린다. 시설을 옮겨 놓을 때도 같다.
6. 가스 구역 맥박 "두-둥"이 전보다 조금 작아 덜 거슬린다. 박자·멈춤 동작은 그대로다.
7. 효과음 음량을 최대로 해도 소리가 찢어지거나 깨지지 않는다. Console에 경고·오류가 없다.
