# 시설 크기·저장 복원·UI 이미지 일치 작업

## 요청 및 작업 순서

1. 기존 저장의 조명·정산 콘솔도 새 1×2 규격으로 복원한다.
2. 주요 시설의 크기를 확인하고, 의도적으로 작은 시설과 잘못된 규격을 구분한다.
3. B 건설 목록·상세·월드 설치 미리보기·시설 관련 퀘스트가 같은 시설 원본을 사용하도록 한다.

작업 프로젝트는 Unity Hub 첫 번째 프로젝트인 `C:/Users/jeone/sub-terra/sub-terra`이다.

## 규격 확인

| 시설 | 설치 영역 | 처리 |
| --- | --- | --- |
| 조명 | 1×2 | 새 설치 및 빈 공간이 있는 구형 저장 복원에 동일 규격 적용 |
| 정산 콘솔 | 1×2 | 조명과 동일 |
| 충전기 | 2×2 | 기존 런타임 규격 유지; 메뉴 원본 참조 점검 |
| 보건소 | 2×2 | 현재 기준 시설; 크기 변경 없음 |
| 전진기지 코어 | 2×2 | 현재 넓은 원본 유지 |
| 보관함 | 1×1 | 이전 요청대로 확대하지 않음 |
| 사다리·버팀목 | 개별 배치 단위 유지 | 좁은 이동·지지 시설이므로 일괄 확대하지 않음 |
| 긴급 탈출 포탈 | 2×2 | 크기는 정상; 기존 임시 아이콘 사용은 별도 점검 항목 |

설치 영역과 실제 그림의 높이는 다르다. 조명·정산 콘솔은 원본 비율을 유지하며 1×2 안에 들어가므로, 정사각형에 가까운 콘솔은 조명보다 낮다. 보건소 크기에 맞춘 강제 늘리기나 그림 왜곡은 하지 않는다.

## 저장 복원

- 이전 1×1 조명·정산 콘솔은 확장될 윗칸이 비어 있으면 1×2로 복원한다.
- 모든 저장 시설의 원래 영역을 먼저 예약해, 나중에 복원할 시설을 먼저 복원하는 시설이 침범하지 않도록 한다.
- 지형·다른 시설·엘리베이터 공간·허용 구역을 검사한다.
- 복원 결과의 실제 점유 크기를 WorldSnapshotSystem에 기록하여 다음 정상 저장과 이어하기에서 유지한다.
- 인스턴스 ID, 위치, 레벨, 회전, 체력은 유지하며 자원은 차감하지 않는다. 원본 저장 파일을 직접 덮어쓰지 않는다.
- 확장 영역이 막힌 경우에는 원래 위치·크기를 보존하고 Console 경고를 남긴다. 자동 위치 변경 여부는 사용자에게 문의 중이다.
- 이번 저장 크기 변경은 직전 작업 대상인 조명·정산 콘솔이다. 구형 1×1 충전기와 구형 1×2 전진기지의 기존 호환 규칙은 별도로 유지한다.

## 이미지 연결

- B 건설 메뉴는 BuildingData.Icon, 월드 미리보기는 실제 프리팹 원본과 배치 규격을 사용한다.
- 조명·충전기·보관함·정산 콘솔·전진기지·보건소의 메뉴 아이콘을 현재 시설 원본으로 동기화한다.
- 시설 퀘스트 9개는 건설 메뉴와 동일한 BuildingData.Icon을 참조한다: 버팀목, 사다리, 조명, 보관함, 전진기지 설치, 충전, 치료, 코어 가스 정화, 정산.
- 그 밖의 채굴·업그레이드·이동 퀘스트 장면 그림은 유지한다.
- 퀘스트 UI 배치와 버튼 구조는 바꾸지 않고 이미지 참조만 전용 Editor 빌더로 갱신한다.

## 검증

- 전용 빌더 적용 완료: 프리팹 2개의 기존 접지 계층 위치를 갱신하고, Mine_Demo_Integration 씬의 시설 퀘스트 이미지 참조 9개만 교체했다. 씬의 UI 배치는 유지했다.
- EditMode **109개 / 109개 통과**, 실패 0개. 저장 복원·점유·겹침·JSON 재저장/이어하기·메뉴/미리보기/퀘스트 참조 일치를 검사했다.
- 결과: `work_process/facility-consistency-editmode-20261008.xml`.
- 현재 건설 메뉴의 변경 대상 6종은 원본 참조가 일치하며, 버팀목·사다리도 기존 메뉴와 실제 프리팹의 동일 스프라이트를 확인했다. 긴급 탈출 포탈의 임시 아이콘은 이번 변경 대상 6종 밖의 기존 항목으로 기록했다.
- diff 검사 통과. Unity 자동 변경 ProjectSettings.asset은 실행 전 바이트로 복원했다. Packages/Assets Settings 변경 없음.
- 기존 사용자 변경인 NotoSansKR-Regular_SDF.asset(296줄 추가/69줄 삭제)은 그대로 보존했다.
- 테스트 Editor 종료 확인. 작업 후 C 드라이브 여유 약 14.79GB.
- 실제 게임 화면의 시각 검수와 사용자의 실제 저장 슬롯 확인을 자동 단위 검증으로 대체했다고 주장하지 않는다.
