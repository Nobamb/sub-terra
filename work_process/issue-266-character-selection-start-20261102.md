# #266 캐릭터 선택 작업 착수 — 2026-11-02

- 이슈: https://github.com/Nobamb/sub-terra/issues/266
- 기준 main `385b4a98`, 전용 브랜치 `codex/issue-266-character-selection`.
- 사용자 요청으로 #265 가변 점프보다 먼저 진행한다. 이슈의 기존 '모션 확정 후' 순서보다 이번 우선 요청을 따른다. 팀원 #264의 모션/그림은 수정하지 않는다.

## 확인한 현재 구조

- 새 게임 확정은 MainMenuBinder.OnStartNewGame → SaveRuntimeController.StartNewGame으로 이어진다. 슬롯 덮어쓰기 확인을 통과한 뒤 실제 런타임 교체와 저장을 진행한다.
- PlayerState는 GameState.cs에 있으며 외형 선택 필드가 없다. PlayerSaveData와 SaveDataMapper에도 해당 필드가 없다.
- PlayerAnimationController는 동작별 프레임 배열을 사용한다. 캐릭터별 전체 모션 세트를 같은 프레임/접지 기준으로 교체해야 한다.
- Art 폴더의 female/woman/girl 파일명 검색에서는 여자 원화/모션을 찾지 못했다. 다른 이름이나 저장소 외부 파일의 존재는 미확인이다. 사용자에게 준비 여부와 위치를 질문했다.

## 구현 범위 및 순서

1. 여자 원화/모션 제작 담당과 파일 위치 확인. 미준비이면 남자 그림을 여자라고 표시하지 않는다. 새로운 원화를 임의로 대량 생성하지 않는다.
2. 기존 uGUI 화풍으로 새 게임의 캐릭터 선택 창을 연결한다. 기존 슬롯·덮어쓰기 확인 경로를 재사용하며 취소하면 기존 슬롯/저장에 영향이 없어야 한다.
3. 선택은 슬롯별 상태/저장 데이터로 보존한다. 전역 PlayerPrefs에 저장하지 않는다. 기존 저장의 누락 값은 현재 남자 외형으로 안전하게 복원한다.
4. 준비된 여자 모션 세트를 단위로 적용한다. 걷기·대기·사다리·채굴·사다리 채굴·점프·피격·쓰러짐의 프레임 수와 발 기준을 대조한다. 이미지 자르기/팔다리 왜곡으로 대체하지 않는다.
5. 가이드·터미널·초상화 등 플레이어가 보이는 경로도 같은 외형 소스를 쓰도록 연결한다. 프레임별 경로 복사에 의존하지 않는다.
6. 최소 확인: 선택 취소/확정, 기존 슬롯 덮어쓰기 확인, 선택 저장·복원, 구저장 기본값, 완성된 모션 세트 적용과 실제 화면. 광범위한 검사/Windows 빌드는 별도 필요가 없으면 반복하지 않는다.

## 현재 상태

- 사용자가 팀원의 기본 자세 원화 1장을 제공했다. 원본 `work_process/references/issue266/female-miner-original.webp`는 512×512 RGB 단일 이미지이며 투명 배경이 아니다. 사용자는 다른 동작 이미지는 없고 새 제작이 필요하다고 확인했다.
- 내장 image_gen으로 투명 기본 자세와 걷기 핵심 4자세 시안을 제작했다. 기본 자세 출력도 AI 편집이므로 원본 픽셀을 그대로 배경만 분리했다고 주장하지 않는다. 원본의 얼굴·장비와 미세한 차이가 있을 수 있어 사용자 비교가 필요하다.
- v1 시각 리뷰에서 높게 든 무릎·상체 방향 차이·아래쪽 신발 여백 부족을 발견해 v2에서 낮은 통과 자세와 동일한 상체 방향을 목표로 보정한다. 시안의 개수·알파 검사만으로 연속 동작의 완성을 판정하지 않는다.
- 출력은 `work_process/images/issue266/`, 재현용 프롬프트는 `work_process/issue266-image-prompts-20261102.txt`에 보존한다. 외부 API/CLI는 사용하지 않았다.
- v2는 1280×1229 RGBA이며 알파 0~255를 확인했다. 흰색/어두운 배경 비교(`female-walk-v2-inspection.jpg`)에서 전신·장갑·신발과 배경 투명성을 살폈다. 바닥 그림자·투사 광선은 보이지 않는다. 다만 상체 방향·장비 위치의 미세한 차이와 통과 자세의 발 경로는 추가 조율 대상이며, 일관성/걷기 루프 통과로 판정하지 않는다. 기본 자세 시안은 1254×1254 RGBA다.
- 걷기 4장은 검토용 핵심 자세이며 게임 적용용 완성 세트가 아니다. 외형·관절·접지 리뷰를 통과한 후 남자 걷기의 40프레임 재생과 대응하는 여자 세트를 제작한다. 원본 팔다리 자르기·늘리기, 잔상 겹침 보간은 사용하지 않는다.
- 아직 런타임 코드·저장 스키마·UI 에셋을 수정하지 않았다. 외형 확인 전 자동 적용·커밋·푸시·PR 게시하지 않는다. 실제 Unity 걷기·프레임 간 연결은 미검증이다.
- 기존 가스·조명 작업 보관본 `cd683e312e9d18b1551bcc91b7bf3ff561479991`는 유지한다.
