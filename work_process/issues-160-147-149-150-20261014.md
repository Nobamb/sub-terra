## 이슈별 실제 변경

### #160 블록 이미지·채굴 결과 불일치

코드에서 흔들림용 복제본이 처음 생성된 Sprite를 유지하고, 같은 칸의 실제 타일이 바뀌어도 재사용되는 경로를 확인했다. 원본 타일 제거 후 표시만 남을 수 있는 경로도 보완했다.

- 복제본에 원본 TileBase를 기록. 다른 타일로 교체되면 복제본을 회수하고 현재 Sprite·색·플래그로 다시 생성.
- 같은 타일의 Sprite 변화도 반영. 사라진 원본 셀은 균열·복제본을 정리.
- 색과 플래그 복원은 원본 TileBase가 여전히 같은 경우에만 수행. 새 타일에 이전 색을 덮지 않음.
- 새 시드 생성 전 구조 위험·복제본·숨김 색을 정리.
- 채굴 보상·광물 ID·가스 발생·타일 점유 규칙은 변경하지 않음.

균열 PNG는 투명 배경이다(알파 확인). 불투명 이미지 교체라는 가설로 에셋을 수정하지 않았다. 원래 제보의 36~40m 증상과 광물 지급 문제 전체를 실제 재현한 것은 아니다. 이번 수정은 확인된 시각 캐시 불일치 경로에 한정하며 실제 인게임 결과까지 해결됐다고 단정하지 않는다.

### #149 드론이 일반 지형까지 강조

- 대상별 점광원을 칸 안쪽의 얇은 SpriteRenderer 테두리로 교체. 표식을 풀링하며 주변 지형을 조명하지 않음.
- 광물 흰색 / 골드 금색 / 활성 가스 빨강 / 봉인 신호 청록 유지.
- 탐지 반경·주기·골드 우선·활성 가스 범위 판정은 유지. 활성 가스 구역의 위험 표시는 정상 대상이다.
