# #317 확률 붕괴 노트북 검사 계획

[#317 최신 본문](https://github.com/Nobamb/sub-terra/issues/317)을 기준으로 한다. #319와 #320이 모두 `main`에 들어가면 최신 `main`에서 시작한다.

| EditMode 검사 | 기대 결과 |
| --- | --- |
| 같은 줄과 바로 윗줄에서 받침 거리 1~2, 3, 4, 5칸 이상을 비교 | 3칸은 15%, 4칸은 30% 확률로 판정. 안전한 칸에는 확률 판정이 없고, 5칸 이상은 기존 붕괴 예고를 사용 |
| 채굴 1회에 가로 2·3·4칸 떨어진 균열을 비교하고 같은 월드 시드로 반복 | 2칸 이내에서만 칸마다 최대 한 번 판정. 3~4칸에는 30초 창만 열림. 같은 시드와 채굴 순서에서 같은 결과 |
| 채굴 없이 시간을 진행하고, 화면 밖 3칸 여유 경계 전후로 이동 | 시간 경과만으로는 확률 판정을 하지 않음. 화면 밖에서는 30초가 줄지 않고, 다시 보이면 이어서 감소. 근처를 다시 캐면 30초로 갱신 |
| 확률 붕괴로 천장 한 칸을 제거 | 1초 예고 후 한 칸만 낙하. 새로 드러나거나 더 위험해진 천장은 그 붕괴로 판정하거나 연쇄 낙하하지 않음. 새 채굴과 기존 고립 덩어리 판정은 정상 동작 |
| 연속 당첨, 버팀목 설치, 저장 복원 | 확률 예고는 최대 2개이며 1.5초 전역 쿨다운 적용. 버팀목으로 안전해지면 창·예고 종료. 저장을 불러오면 확률 붕괴 상태 초기화 |

첫 구현은 판정·시간·연쇄 방지부터 검증한다. 낙하 경로·홀로그램·타이머 아이콘과 실제 피해 체감은 후속 범위다.
