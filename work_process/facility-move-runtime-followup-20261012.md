# 시설 이동·종료 버퍼·채굴 지연 후속 작업

## 기준

- 첫 번째 Unity 프로젝트, 최신 main fe2c0fda 기준. PR #166은 별도 미병합 변경이며 직접 병합하지 않는다.
- 기존 폰트 변경은 preserve-local-font-before-main-sync-20261012 stash로 보존되어 있다.
- ProjectSettings, Packages 및 버전은 수정하지 않는다. 사용자 저장 슬롯과 기존 시설 오브젝트를 보존한다.

## 구현 순서와 계약

1. B 건설 메뉴의 시설 이동: 조명·정산 콘솔만 선택 → 최신 1×2 미리보기 → 클릭 확정. 취소 시 원래 시설 그대로 유지. 자신 점유만 제외하여 기존 설치 검사를 재사용한다. 확정 후 같은 인스턴스의 위치·점유·접지·전력망·저장 좌표를 갱신하고 비용과 건설 보상은 발생시키지 않는다.
2. 확대가 막힌 구형 시설에는 공간 부족 사유와 시설 이동 방법을 안내한다. 자동 위치 변경은 하지 않는다.
3. 2D Animation fallback ComputeBuffer는 패키지 내부 강제 해제·경고 숨김 없이 소유자의 정상 정리 경로를 검토한다. 안전하게 검증되지 않은 우회는 제품에 넣지 않는다.
4. 채굴 처리와 측정 도구의 위치 이동/물리 동기화 비용을 분리해 측정한다. 병목이 확정된 처리만 같은 조건 전후 비교 후 수정한다.

## 최소 검증

이동 성공/겹침 거부/취소/자기 영역/구형 확대/저장 보존의 좁은 검사와 필요한 컴파일만 수행한다. Windows 전체 빌드는 필요한 경우에만 한다. 완료 여부와 실제 측정 근거는 작업 후 아래에 기록한다.

## 현재 구현 및 검증

- 시설 이동은 건설 메뉴 상세 헤더의 `시설 이동` 버튼으로 시작한다. 직접 설치하거나 저장에서 복원한 조명·정산 콘솔을 클릭하고 새 위치를 선택한다. 우클릭, 같은 버튼 재클릭 또는 메뉴 닫기로 취소한다.
- 메뉴가 비활성 상태에서 먼저 연결되어도 첫 Awake가 기존 Presenter를 교체하지 않도록 수명주기를 보완했다.
- 기존 인스턴스를 보존하고 점유/접지 보호/전력망/미니맵/저장 좌표를 갱신한다. 비용 차감 및 새 건설 이벤트는 발생시키지 않는다. 레벨·체력·회전 DTO와 시설 컴포넌트의 상태를 유지한다.
- 이동·저장 EditMode 10개 모두 통과. 결과는 `facility-move-editmode-20261012.xml`이다. 구형 1×1→1×2 무료 이동, 자신의 영역, 다른 시설 및 지형 거부, 취소, JSON 저장·복원을 포함한다.
- UI 버튼 검사 1개도 통과했다. 결과는 `facility-move-ui-editmode-20261012.xml`이다. 최종 코드 컴파일 오류 없음, 검사 실행 종료 코드 0. 합계 11개이며 기존에 통과한 10개를 반복 실행하지 않았다. 실제 마우스 조작/화면 검수를 완료했다고 주장하지 않는다. 전체 테스트 또는 Windows 빌드는 추가 실행하지 않았다.
- 채굴 Tick/완료/거래/타일 제거/후속 이벤트에 ProfilerMarker를 추가했다. 실제 성공 거래와 측정용 위치 이동·물리 동기화 비용을 분리하는 진단 소스는 `tools/MiningSeparationProbe-20261012.cs`에 보관한다. 제품에 진단용 reflection이나 매 프레임 로그를 추가하지 않는다.
- 실제 씬 측정을 시도했으나 Editor private 메모리가 약 9,852MB에 이르고 디스크 여유가 0.96GB까지 줄었다. 측정용 Editor만 종료한 후 여유가 약 7.82GB로 회복했다. 유효한 성능 결과가 없어 특정 병목이나 개선률을 주장하지 않으며 추측 최적화는 적용하지 않았다.
- 2026-10-12 사용자 추가 요청에 따라 더 이상의 성능 측정·전체 빌드 없이 필수 검사와 컴파일 오류 확인만 진행한다.
- ComputeBuffer의 소유 코드 수정안은 `2d-animation-fallback-cleanup-15.1.0.patch`에 준비했고 원본에 대한 `git apply --check`가 통과했다. 패키지 파일은 아직 수정하지 않았다. 동일 버전 패키지를 프로젝트에 포함하는 데 필요한 등록 정보 변경은 승인 답변 대기 중이다. 종료 경고 해결 완료로 보고하지 않는다.
- 임시 측정 컴포넌트와 `.meta`는 Assets에서 제거했다. 테스트 Editor 종료 후 ProjectSettings/Packages/Assets Settings를 실행 전 바이트 기준으로 복원했고 별도 QA 저장 폴더만 정리했다. 사용자 저장 슬롯과 기존 폰트 stash는 건드리지 않았다.
- 아직 커밋·푸시·PR 게시하지 않았다. 직접 병합하지 않는다. PR #166과 동시에 진행되는 시설 저장 코드 변경의 통합은 별도 처리한다.
