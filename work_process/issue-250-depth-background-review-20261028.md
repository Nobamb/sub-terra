## 구현

- 원본 동굴 구도·화풍을 참고해 구리/철/리튬 배경 3장을 새로 제작했다. 원본 회색 배경과 GUID는 보존한다.
- 구리는 적갈색 광맥, 철은 회색 금속 광맥과 가스 균열, 리튬은 청록 결정과 엔진 연료를 연상시키는 각진 균열을 사용한다. 각 배경에 작은 금과 가스 흔적을 포함한다. 장식이므로 채굴·보상 대상이 아니다.

- 16/36 깊이부터 2칸 구간에 걸쳐 다음 배경으로 섞고, 이동/순간이동에도 0.8초 시정수의 지수 보간으로 연결한다. 전체 전환 완료 시간이 0.8초라는 뜻은 아니다.
- 기존 화면 비율·가장자리 여백·패럴랙스·원거리 정렬을 유지한다. 단일 메시·재질에서 3개 텍스처를 혼합한다. 리튬의 청록 성분만 약하게 맥동하며 별도 조명/전역 블룸을 만들지 않는다.
- 모션 감소 시 패럴랙스·맥동은 정지하고 실제 깊이의 배경은 즉시 반영한다.
- ProjectSettings, 패키지, 실제 광석 분포, 암전, 세이브, 보상 규칙은 수정하지 않는다. 최신 main에서 병합된 팀원 변경은 보존한다.
