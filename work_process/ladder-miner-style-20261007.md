## 검증 결과

실행 결과는 `work_process/ladder-facility-verification-20261007.txt`에 기록한다. `work_process/images/ladder-five-style-20261007.png`는 Unity의 격리 PreviewScene에서 렌더한 기본 광부와 새 5장 전체다. 이 파일은 이미지로 직접 확인했다. 먼저 생성한 3열 비교 캡처는 캐릭터가 표시되지 않아 증거에서 제외하고 삭제했다. 게임 씬은 저장하지 않는다.

최종 검증 완료:

- Unity 6000.5.4f1 일반 Editor + 명시적인 executeMethod로 12개 집중 검사 직접 호출 통과. Test Runner 전체 실행이나 결과 XML은 아님.
- 충전기 설치/네 칸 막힘 5개, 기존/신규 충전기 복원 2개, 승강로 겹침 1개, 실제 시설 JSON 왕복 3개, 5장 참조·임포트·단계 거리 1개.
- 최종 로그: `sub-terra/Logs/ladder-facility-focused-20261007-verified2.log`. 컴파일 성공, 새 C# 컴파일 오류 및 ShouldRunBehaviour 어설션 없음.
- 기존 충전기 복원 테스트의 지반 준비 누락을 수정했다. 실제 지반만 보호하는 현재 규칙에 맞춰 테스트용 바닥 두 칸을 넣었다. 게임 설치·저장 로직을 변경할 필요는 없었다.
- 새 JSON 왕복 검사는 EditMode에서 엔진 SendMessage를 사용하지 않고, 기존 테스트의 Reflection 패턴으로 OnEnable/OnDisable을 호출한다. 정상 이벤트 등록·해제를 확인하되 PlayMode 물리 실행으로 오인하지 않는다.
- Player 프리팹 의미 있는 변경은 사다리 Sprite 참조 5개뿐이다. Unity 저장의 빈 문자열 뒤 공백 직렬화 차이도 존재한다.
- 원본 5장 및 .meta 변경 없음. 씬·ProjectSettings·Packages의 의미 있는 변경 없음. 검사 전후 활성 씬 dirty=false, 저장 없음.
- 임시 검사 스크립트와 .meta는 삭제했다. 전체 테스트·Windows 빌드·실제 사용자 저장 슬롯 이어하기는 실행하지 않았다.
- 이후 사용자가 사다리 크기를 확인하고 커밋·푸시·PR 게시를 승인했다. 최종 게시 범위와 후속 작업은 `ladder-size-outpost-2x2-20261007.md`를 참고한다.
- 코드 diff 공백 검사 통과. 프리팹은 Unity가 빈 문자열 뒤에 추가한 공백만 제외하는 `core.whitespace=-blank-at-eol` 조건으로 diff 검사 통과. 수동 YAML 수정은 하지 않았다.
- 검사 Editor 종료 확인. 최종 디스크 여유 15.8GB. 별도 빌드, 새 Library 전체 생성·삭제는 하지 않았다.

## 이미지 제작 기록

모드: 기존 기본 광부 + 기존 사다리 자세를 참조한 편집. ImageGen으로 기본 자세를 제작한 뒤, 그 결과를 공통 모델로 사용해 네 자세를 추가했다. 투명 PNG 5장이며 원본 파일은 교체하지 않았다.

핵심 제작 지시: 기존 광부의 주황 헬멧·회색 밴드·오른쪽 램프, 짙은 작업복, 주황 보호대, 갈색 장화, 작은 청록 포인트 및 부드러운 입체 명암을 유지한다. 기존 중립 사다리 이미지의 손 높이·발 높이·전체 캔버스 중심을 유지하면서 약 10도 돌아선 뒷모습과 작은 배낭을 표현한다. 사다리, 배경, 지면, 그림자, 글자 없이 단일 투명 캐릭터 이미지만 제작한다.

네 이동 자세 제작 지시: 기본 자세의 헬멧·머리·몸통·배낭 위치와 크기는 유지하고, 각 원본 02~05의 팔·다리 자세만 반영한다. 02/03은 화면 오른쪽 손·발을 중간/최대로 올리고, 04/05는 화면 왼쪽을 중간/최대로 올린다. 낮은 손도 어깨 높이에서 사다리를 잡고 있어야 하며, 몸통 회전이나 전체 확대·축소는 하지 않는다.
