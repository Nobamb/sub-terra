# 여자 대기·진입·정지 무광 보정과 모션 크기/접점 검토

## 이번 결과

- 대기 1장·진입 2장·정지 2장의 헬멧/장비/신발 흰 광택을 기존 무광 걷기와 맞춤.
- 초기 보정본의 진입 자세는 걷기보다 키가 높아 전환 시 떨어져 보일 가능성이 있었다. 전신 원화에서 무릎 굽힘을 보완해 대기→진입01→진입02→걷기로 높이가 내려가도록 수정.
- 최종 소스는 `work_process/images/issue266/female-transition-matte-sheet-v3-alpha-20261104.png`. v1은 첫 표면 시안, v2-height는 배경 알파 검사에서 실패한 중간 시안이므로 적용하지 않음.
- 대기/진입/정지 5장 + 걷기 8장 + 사다리 5장 + 채굴 11장 = 29장 정렬 검토 PNG와 전환 GIF/APNG 제작.
- 출력 폴더: `work_process/images/issue266/female-matte-transition-contact-review-20261104/`.
- 재생성 도구: `work_process/tools/female-matte-transition-contact-20261104.ps1`. 원화 서비스 호출은 하지 않으며 확정된 생성 시트를 입력받아 전신 셀 추출/외곽 알파 정리/정렬/미리보기를 만든다. 기존 `LandingRecoveryReview-20261103.cs`, `SpriteMotionAlignment-20261103.cs`, 로컬 ffmpeg 사용.

## 정렬 방식과 접점 범위

- 1024 캔버스, 발 기준선 y=800. 사다리 외 지면 오차는 0~1px.
- 걷기/전환은 허리 장비 x와 지지 발의 바닥 높이를 기준으로 전신만 이동. 신체 부위 분리, 늘리기, 이미지 겹치기 없음.
- 모션별로 하나의 균일 확대율만 적용. 주황색 헬멧 영역은 이음선에 따라 갈라지므로 실제 머리 전체 크기와 동일한 측정값이 아니다. 전환은 대기 키 611px 기준, 앞·뒤 모습은 별도 교정값을 사용해 사다리가 과도하게 작아지는 것을 피함.
- 사다리는 중립 몸 축을 고정하고 들어 올린 손발은 유지. pose04/05의 신발 끝은 중립 기준선보다 8px 높으며 의도적으로 아래에 붙이지 않음.
- 채굴은 신발 범위로 위치를 맞추고 청록 드릴 화면을 허리 기준으로 사용하지 않음. 손과 드릴은 전신 원화의 그립을 보존했다. 실제 채굴 타일/사다리 가로대와의 접촉은 검증하지 않았다.

## 미리보기와 최소 검사

- `entry-walk-stop-near.gif`, `entry-walk-stop-far.gif`: 두 팔 위상의 전환 검토. 정지 직후 회복 중간 자세로 entry01 전신 셀을 재사용한 검토 순서이며 실제 상태 머신에 연결하지 않음.
- `ladder.gif`, `mining.gif` 및 각 `*-lossless.png`: 크기 보정 후 비교용. GIF 디더링 없음.
- 4개 GIF/4개 APNG의 생성·디코딩 통과. JSON에 원화 해시, 모션 순서, 확대율, 정렬 기준 기록. PNG 경계 잘림/바닥/허리 축 검사 통과.
- 흰/어두운 배경 접촉 시트와 `cross-motion-scale.png` 육안 비교. 헬멧·장비 표면의 흰 반점 제거 상태, 양손/양발, 치마 가림과 외곽을 확인.
- 최종 정렬에서 대기 키 약 612px, 진입01 약 599px, 진입02 약 588px, 걷기 약 575~578px. 높이 차이가 단계화됐지만 모든 전환이 자연스럽다고 확정하지 않았다.

## 게임 적용·선택·저장 연결: 리뷰 후 단계

사용자가 정한 순서인 “리뷰 확정 후”를 지켜 실제 에셋 교체·선택 UI·저장 형식 변경은 이번에 하지 않았다. Editor 시험 코드의 기존 로컬 변경도 건드리지 않았다.

1. 위 전환 GIF와 전신 크기 시트를 팀원이 리뷰: 얼굴/장비 일관성, 진입·정지의 팔 위치와 높이 차이, 사다리 크기 채택 여부 확정.
2. 채택된 PNG만 에셋으로 가져오고 남자 모션 세트와 공통 동작 ID로 매핑. 점프·피격·쓰러짐 등 아직 이번 무광 정렬에 포함하지 않은 동작은 별도로 확정하며, 조용히 다른 성별 그림으로 대체하지 않기.
3. 기존 VisualRoot 기준점과 Sprite pivot/PPU를 확인해 실제 발/손/드릴 접점을 짧게 점검. 이번 캔버스 좌표를 기존 런타임 pivot과 같다고 가정하지 않기.
4. 선택값은 안정된 외형 ID로 저장하고 기존 저장에 값이 없으면 기존 남자 외형을 기본으로 복원. App↔Gameplay 직접 참조를 만들지 않고 Shared 계약/Integration 경로 사용. 실제 저장 DTO와 버전 정책을 읽은 뒤 구현할 것.
5. Bootstrap→새 게임→탐사에서 성별 선택/저장/완전 종료/이어하기를 최소 검증.

미검증: 실제 게임의 손발/드릴 접점, 발 미끄러짐, 이동 속도에 따른 전환, 선택·저장·복원, Unity Console/빌드. 이번에는 Unity를 실행하지 않았다. 이후 사용자 요청으로 최종 v3 원화·29장 정렬 PNG·미리보기·도구·기록을 커밋·푸시한다. 실패한 중간 원화와 재생성 가능한 raw/clean/프레임 복제본, 기존 Editor 시험 코드 변경은 제외한다.
