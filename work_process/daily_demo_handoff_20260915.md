# 2026-09-15 데모 작업 인수인계

PR: #128, 브랜치: `codex/inventory-item-icons`, 기준: `origin/main` 034b896.

## 이번 PR의 변경

- 인벤토리 구리·철·리튬·엔진 연료를 개별 256×256 투명 PNG로 적용했다. 구리는 주황빛 금속 덩어리, 철은 은회색 주괴, 리튬은 기존 타일과 맞춘 시안·청록 결정, 연료는 청록 코어 캡슐이다. 연료의 기존 GUID를 유지하고 잘못된 Single Sprite 메타 매핑을 정리했다.
- 채굴 실패 HUD에서 심층 미해금 / 드릴 부족 / 화물 가득 참을 서로 다른 이유로 보여 준다. 드릴 부족과 화물 초과에는 다음 행동을 안내하고, 실패 안내 동안 패널을 최소 360×44로 확장한 뒤 원래 크기로 복원한다.
- 판매 화면에 “전체 판매에서 희귀 품목 제외 · 엔진 연료는 개별 선택 판매” 안내를 유지한다. 기존 UI 참조를 사용하므로 씬·프리팹 재생성이 필요 없다.
- 전진기지의 화물·보관함 일괄 정산에서도 희귀 품목을 제외하고, 전진기지 연료 개별 정산을 거부한다. 연료 판매는 지상 기지의 개별 판매로 제한한다.
- QA 문서의 전체 판매 규칙을 수정하고 102번 정상 입력 검수 경로를 추가했다. 판매·스캔·저장·실패 HUD 회귀 검증과 전용 CLI QA 실행기를 포함한다.

## 이미 main에 있는 구현과 오늘 로컬 동기화

구리·철·리튬의 채굴·획득·판매 시스템과 엔진 연료 B-102 시스템은 이미 main에 있다. 이번 작업은 광물 시스템 신규 구현이 아니다. 기본 판매가는 구리 10G, 철 15G, 리튬 40G, 연료 100G이며 보너스가 있으면 실제 판매 미리보기와 지급량을 비교한다.

문양 석재는 스캔 반경 안에서 상시 켜지는 방식이 아니라 스캔 펄스 활성 중 오버레이를 표시한다. 36m 심층 제한, 드릴 레벨 2 요구와 38m 연료 채굴은 기존 기능을 사용한다.

원래 작업 폴더는 사다리·폰트 등 26개 변경 파일을 SHA256 검증 후 백업하고 최신 main을 현재 브랜치에 병합했다(904352a). PR #123의 이동 거리 기반 상승·하강, 3포즈/4단계 재생과 접촉 순간 걷기 모션 보호가 포함돼 있다. 이번 PR은 사다리 코드나 아트를 다시 변경하지 않는다. 로컬 main 동기화 기록은 별도이며, 기존 개인 Idle 시안·Recovery 씬·자동 폰트 변경은 이번 PR에 포함하지 않는다.

## 검증과 제한

- 원래 프로젝트 사다리 정적 검증: 6/6 통과, 연료 메타 수정 후 재임포트 정상 종료.
- 인벤토리: 네 PNG 크기·RGBA·투명 모서리 확인, 실제 InventoryPanel 프리팹의 카탈로그→Image 연결 4/4 통과. 리튬 수정 후 임포트·연결 재검수 완료, Console Error 0건.
- 연료 UI/안전 변경은 이전 별도 작업 폴더에서 EditMode 46/46 및 최종 HUD PlayMode 2/2 통과했다. 이번 통합 시 해당 C# 9개가 검증 후 보존본과 SHA256으로 동일함을 확인했다. 이 결과를 새로 전체 테스트를 실행한 결과로 표현하지 않는다.
- 최종 통합 후 원래 Unity 프로젝트에서 컴파일 완료, 판매 안내 상수와 네 아이콘 카탈로그 연결을 확인했다. Console Error 재조회 0건이다.
- 기존 입력 PlayMode `E_F03_KeyboardAndMouse_UseTheSameTimedCompletionPath`는 main 원본에서도 같은 실패를 재현했다. 실패 원인과 실제 Enter 입력 정상 여부는 미해결이다.
- 정상 입력으로 40m 완주, 인게임 전체 UI 가독성, Windows 빌드·별도 PC·저장 후 재실행은 아직 확인하지 않았다. 이 PR은 데모 완료나 빌드 출시 검증을 의미하지 않는다.

## 팀원 최소 확인 순서

1. PR 적용 후 원래 Unity 프로젝트를 열고 Console 오류 확인. Bootstrap에서 실행한다.
2. 새 게임 → 구리·철 채굴 → 인벤토리 이미지·이름·수량 → 지상 판매·업그레이드 확인.
3. 사다리 접촉 → 상승 → 정지 → 하강 → 방향 전환 → 이탈·점프·재접촉 확인.
4. 심층 미해금 / 드릴 부족 / 화물 초과 안내를 각각 확인한다.
5. 심층 해금 → 38m 스캔 펄스 → 연료 채굴 → 수량 확인.
6. 연료 보유 상태로 전체 판매 및 전진기지 화물·보관함 정산 → 연료 유지 확인.
7. 지상에서 연료 개별 판매 → 기본 100G(보너스 적용 시 미리보기 기준) 확인.
8. 연료·건설한 사다리 보유 저장 → 종료·이어하기 → 수량/사다리 유지 및 채굴한 봉인 블록 미재생성 확인.
9. 마지막으로 Windows QA 빌드에서 새 게임·이어하기·종료 후 재실행 확인.
