## 가설과 조사
1. **실제 리튬 타일에 보상/가스가 빠짐**: Integration resolver의 `tile.lithium` 및 `.gold`는 mineral.lithium/수량 1/containsGas=true. MiningYieldCommit의 실제 기본 보상은 exact 지급 성공 후 완료되며 실패 시 타일이 삭제되지 않는다. MiningGasBridge는 완료 이벤트 DTO의 containsGas로 가스를 만든다.
2. **흔들림 복제본이 논리 타일을 바꾸거나 다른 그림을 사용함**: 기존 PR #192의 SourceTile/스프라이트 갱신·소유권 회수·정렬 수정은 유지했다. 새 검사에서 실제 생성 타일로 복제본을 만들고, 원본 객체/그림/채굴 DTO·인벤토리 증가·가스 수를 대조했다.
3. **월드 재생성/복원이 일반 타일로 바꿈**: 실제 WorldSnapshotSystem Capture→Restore 후 채굴 칸은 비어 있고 나머지 칸의 ID/자원 ID/수량/금 보상/드릴 조건/가스/스프라이트가 동일한지 비교했다. 월드 복원 자체의 보상 중복도 확인했다.
