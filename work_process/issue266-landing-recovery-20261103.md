# #266 착지 → 대기 회복 원화 검토

- 브랜치: `codex/issue-266-character-selection`, 기존 PR #270 후속 작업. 후속 요청에서 착지 회복 검토본의 커밋·푸시 승인을 받아 같은 브랜치에 게시한다.
- 범위: 기존 착지와 대기 참고 사이에 **새 전신 회복 원화 2장** 추가. 게임 Assets/설정/씬/프리팹/저장/캐릭터 선택 코드는 변경하지 않았다.
- 대기 참고는 기존 정렬본 `damage/pose-01.png`다. 별도 완성 Idle 세트라는 뜻은 아니다.

## 제작과 선택

- built-in imagegen으로 투명 배경의 전신 자세 2장씩 두 차례 제작했다. 프롬프트는 `images/issue266/female-landing-recovery-prompts-20261103.txt`에 보존했다.
- v1의 오른쪽 자세는 최종 대기보다 높아졌다가 내려와야 해서 제외했다. v2의 왼쪽 자세는 착지보다 더 낮은 압축 자세여서 이번 '몸 펴기' 구간에서는 제외했다.
- 선택: **회복 1=v2 오른쪽 전신, 회복 2=v1 왼쪽 전신**. 이번 회복 제작에서 나온 온전한 그림을 각각 선택했으며 신체 부위를 조합하거나 변형하지 않았다.
- 배경 정리는 이미 승인된 범위로만 처리했다. 각 셀의 가장 큰 연결 전신 영역을 보존하고 외부의 분리된 알파 픽셀을 제거했다. 유지 영역의 RGB/알파와 내부 하이라이트는 그대로다. 기존 사다리의 흰 잔점 해결을 의미하지 않는다.
- 두 그림에 동일한 전신 배율 0.92를 사용했다. 허리 청록 버클 기준 가로 정렬과 지면 y800 맞춤 외에 관절/다리 길이/머리 변형은 없다. 원본 시트는 보존한다.

## 최소 확인과 한계

- 원본 두 시트 해시 보존, 전신 잘림/셀 외곽 비불투명 픽셀 없음. 분리 알파 제거: 선택 회복 1에서319px, 회복 2에서566px.
- 접지 오차 허용2px, 실제 출력 바닥 y800. 전신 높이는531→577→609→618px로 단조 증가한다. 높이 수치만으로 해부학적 일관성이나 자연스러움을 보증하지 않는다.
- 흰색·검정 접촉표를 직접 확인했다. GIF/APNG 디코딩 통과. 코드 작업에 필요한 생성/검사 도구만 실행했으며 Unity/Windows 빌드는 실행하지 않았다.
- **미검증:** 실제 반복 재생 인상, 팔과 몸통 각도의 잔여 차이, 발의 가로 위치/미끄러짐, 원화별 장비·얼굴의 완전한 일관성. 비교 GIF에서 이 부분을 리뷰하고 필요한 자세만 추가 보정한다.
- **게임 미적용:** PPU/pivot/콜라이더/물리/게임 내 전환과 Console 상태는 확인하지 않았다. 회복 2장만으로 여자 모션 전체가 완성되었다고 판단하지 않는다.
