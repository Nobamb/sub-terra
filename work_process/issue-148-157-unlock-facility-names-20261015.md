## #148 변경

기존 실제 규칙은 목표 13개 완료 + 드릴 속도 Lv.2였다. 퀘스트 설명에 적힌 세 장비 조건과 달라 보건소 목표 이후 조기 해금됐다. 업그레이드 트리 빌더는 심층 안내 참조를 비워 두고 있었다.

- `Scripts/App/Progression/DeepZoneUnlock.cs`: 공통 규칙을 세 장비 조건으로 변경하고 조건 문구 생성 경로를 제공한다.
- `Scripts/App/UI/Progression/UpgradeTreeView.cs`: 트리 아래 별도 공간에 구역 해금 조건과 현재 잠금/해금 상태를 표시한다. 기존 프리팹도 실행 시 생성하며 트리 영역을 줄여 겹침을 피한다. 갱신할 때 중복 생성·반복 축소하지 않고, 안내가 클릭을 가로채지 않게 한다.
- `ProgressionPanelView.cs`: 구형 심층 탭에서도 불필요한 ‘목표 0개’ 조건을 표시하지 않는다.
- `Scripts/App/UI/Guide/GameGuideCatalog.cs`: 지상 기지 안내에 실제 공통 규칙으로 만든 해금 조건을 추가했다. 현재 퀘스트의 세 장비 설명은 이미 맞아 유지했다.
- 접근 게이트·구매 후 해금·팝업은 기존 ProgressionService의 같은 규칙을 사용한다. 이미 해금된 저장은 기존 영구 해금 ID를 우선하여 다시 잠그지 않는다.
- 요구 장비 레벨의 재료는 구리·철로 마련할 수 있어 심층 해금 전에 리튬을 요구하지 않는다. 업그레이드 가격이나 인접 해금 규칙은 수정하지 않았다.
