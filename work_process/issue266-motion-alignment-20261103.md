# #266 모션 크기·접점 정렬 검토본

## 이번 범위

- 기존 PR #270 브랜치 `codex/issue-266-character-selection`에서 진행. 이전 게시 커밋은 `50844758`.
- **걷기8 + 점프4 + 피격4 + 쓰러짐4 =20자세**를 대상으로 크기/발 기준을 맞췄다. 새 원화/팔다리 조립/관절 변형 없음. 기존 PNG는 변경하지 않고 별도 정렬 검토본을 생성했다.
- 채굴/사다리는 이번20자세에 포함하지 않았다. 채굴의 채택 여부와 사다리 잔점은 기존 기록대로 별도 추적한다.
- 게임 Assets·씬·프리팹·meta·패키지·저장 코드는 수정하지 않았다. 게임 적용·캐릭터 선택/저장 연결은 미진행이다. 후속 요청에서 이 정렬 검토본의 커밋·푸시 승인을 받았으며 기존 PR #270 브랜치에 게시한다.

## 기준과 처리

- 캔버스1024×1024, 검토 기준점은 위쪽 좌표계 `(512,800)`. 걷기·피격·점프 준비/착지·쓰러짐의 지면 접점을 y800에 맞췄다.
- 점프 공중2자세는 준비/착지의 가상 지면 기준을 공유한다. 발을 바닥에 억지로 붙이지 않으며, 검토본에 실제 게임 이동 궤적/물리를 추가하지 않았다.
- 머리 크기는 헬멧 상단의 동일한 주황색 영역을 측정해 참고한다. 걷기 첫 자세 폭161px을 기준으로 **모션당 하나의 고정 비율**을 쓴다: 걷기1.0 / 점프1.0 / 피격약1.06623 / 쓰러짐약0.96988. 자세마다 다른 비율을 넣어 몸이 커졌다 작아지게 하지 않는다.
- 이 색 영역은 비교를 위한 표식이지 머리 전체의 해부학적 크기를 증명하지 않는다. 고개 회전·명암에 따른 폭 차이와 원화 자체의 비율 차이는 시각 리뷰 대상으로 남긴다.
- 그림 전체를 동일 비율로 확대/축소·이동한다. 머리만 키우거나 팔다리를 따로 늘리지 않는다. crouch/쓰러짐의 낮아진 전신 높이를 강제로 서 있는 높이에 맞추지 않는다.
- 가로 기준은 청록색 허리 버클 중심. 허리가 가려진 쓰러짐3/4자세는 골반 축을 각각 source x330/x290으로 표기한 임시 수동 기준을 쓴다. 이2점은 게임 연결 전 시각/플레이 확인이 필요하다.
- 대기 참고는 피격 첫 자세(`damage/pose-01`)를 재사용했다. 새 전용 Idle 세트가 완성됐다는 뜻이 아니다.

## 기존 게임 표시 크기와 임포트 후보

- 실제 남자 Walk01은256×256, PPU256, 불투명 전신 높이224px, pivot(0.5,0.5)다. 새 여자 셀768×768과 동일 PPU를 그대로 쓰면 크기가 다르므로 캔버스 치수만 비교하지 않았다.
- 정렬된 여자 걷기 첫 자세의 전신584px을 남자 기준 높이0.875unit에 맞추는 후보 PPU는 **약667.42857**이다. 여자 원화의 승인된 머리/몸통 비율 자체를 남자와 같게 왜곡하지는 않았다.
- 검토용 발 원점의 비율은 `(0.5,0.21875)`지만 이를 기존 VisualRoot에 바로 대입하면 위치가 달라진다. 기존 남자의 발 상대 y(-0.4375unit)와 허리 상대 x(0.0625unit)를 유지하는 **별도 후보 pivot**은 약 `(0.45926339,0.50390625)`, Custom alignment9다.
- 두 pivot의 의미를 `alignment.json`에 구분했다. **PPU/pivot은 Unity에 적용하지 않았다.** 실제 VisualRoot 위치/스케일, 콜라이더/카메라/사다리 기준과 함께 확인해야 한다.
- `PlayerAnimationController.ApplyJumpBob()`는 Sprite의 PPU로 픽셀 이동을 환산한다. 나중에 PPU를 바꿀 때 선택한 캐릭터별 픽셀 보정값/실제 월드 이동도 함께 확인해야 하며 남자 설정을 일괄 변경하지 않는다.

## 최소 확인

- 원본20개 SHA-256 변경 없음. 모션 내부 고정 비율1개씩 유지.
- 실제 출력 PNG를 다시 측정: 접지18자세의 지면선 오차0px(허용2px), 공중2자세는 최소5px의 발/가상지면 간격 유지. 이미지 잘림0.
- 흰/검정 원본 비교 이력 및 이번 정렬 전후/전환 비교표를 검수했다. GIF2개/APNG2개는 파일 디코딩과 프레임 수 확인.
- Unity 실행·실제 게임 전환·Windows 빌드는 하지 않았다. 영상 파일 생성이나 발 기준 검사만으로 자연스러운 모션 완성 판정을 내리지 않는다.

## 다음 작업과 미검증

1. **착지→대기**의 낮은 자세에서 몸을 펴는 간격이 크다. 다음 연결 원화는 이 회복 구간을 우선 보완한다.
2. 대기 참고→걷기 진입도 팔 위치/무릎 굽힘의 연결을 본다. 지면 맞춤으로 남은 원화 원근/장비 모양 차이까지 해결됐다고 하지 않는다.
3. **미검증:** 실제 반복 재생 인상과 발 미끄러짐, 모션별 머리/장비 일관성, 수동 골반 축2점, 실제 PPU/pivot 적용, 물리/콜라이더/카메라/사다리 접점.
4. 리뷰에서 필요한 연결 원화만 추가한 뒤 전체 세트/채택 여부를 확정한다. 여자 세트를 남자 그림으로 섞어 완성처럼 적용하지 않는다.
5. 그다음 별도 여자 세트의 게임 적용·캐릭터 선택·슬롯별 저장/구저장 기본값 연결을 진행한다.
