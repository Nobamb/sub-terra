## 사다리 검사 개선

검사를 분리했다.

- 실제 Bootstrap → 새 게임 → 탐사 → 사다리 프리팹 진입을 유지한다.
- Rigidbody 시뮬레이션을 잠시 멈추고 실제 애니메이션 갱신 경로를 호출해 상승/하강의 거리별 순서 `0,1,2,1,0,3,4,3,0` 및 역순을 검사한다.

정상 Editor Play에서 해당 영구 PlayMode 코루틴을 직접 실행해 통과했다. 전체 Test Runner XML 실행은 아니다. 재실행 중 이탈 뒤 물리 상태는 종료됐지만 LateUpdate 전의 사다리 이미지를 읽은 실패가 한 번 있었다. 고정 0.15초 대기 대신 실제 일반 이미지 복귀를 최대 20초 안에 기다리도록 고쳤고, 최종 재실행이 통과했다. 잘못된 일반 이미지나 미복귀는 여전히 실패한다. Windows 실행에서도 실제 Trigger 진입·다섯 자세·VisualRoot 위치 유지·상단 정지·이탈 후 일반 이미지 복귀를 확인했다.

유효한 등반 높이에서 Transform/물리 좌표를 동기화한 최종 중립·오른손 상승·왼손 상승 캡처를 직접 확인했다. 발/손 이미지가 바뀔 때 전체 그림이 별도로 튀는 현상은 확인하지 못했다. 손·발이 모든 시점에 가로대에 완전히 고정되는 발 접점 애니메이션은 아니며, 중립 자세에서 접점의 작은 간격은 남는다. 새로운 위치 보정/그림 재제작은 적용하지 않았다.
