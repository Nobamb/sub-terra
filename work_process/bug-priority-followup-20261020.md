## #215 블록 이미지 덮임

- 통합 씬의 BackgroundTilemap과 ForegroundTilemap은 모두 sortingOrder=0, 같은 SortingLayer다.
- 기존 흔들림은 원본 지형을 투명하게 숨기고 복제본을 Foreground-1에 그린다. 실제 씬에서는 -1이 되어 배경 뒤로 들어가므로 광석 대신 배경 암석이 보이는 경로가 존재한다.
- 복제본을 Foreground+1로 변경한다. 이웃 타일을 침범하지 않도록 기존 KeepShakeOutsideOccupiedCells의 상하좌우·대각선 제약은 유지한다.
- 실제 원본 타일, 자원 ID, 채굴 보상, 저장, 모션 감소 설정은 변경하지 않는다.
- 기존 검사는 Foreground=14라는 가상의 정렬만 사용해 배경 가림을 놓쳤다. 실제 씬의 0/0 정렬을 재현하는 검사로 교체하고 이웃 침범 검사도 실행한다.
- Windows에서 제보된 모든 상황의 시각적 해결까지 단정하지 않는다.
