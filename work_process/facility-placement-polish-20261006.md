## 떠 보이는 충전기 후속 수정

- 사용자 인게임 사진에서 충전기와 추가 받침 사이에 검은 틈이 보였다. 앞선 컴파일 검증은 접지의 시각적 성공을 보장하지 않았다.
- 원본 RGBA PNG를 읽어 알파 64 이상인 픽셀의 경계를 측정했다. 충전기 1240×1269에서 하단 투명 여백은 79px, 보관함 1312×1199에서 96px이다. Sprite 메시 경계는 이 불투명 경계와 같다고 보장할 수 없으므로 실제 발끝 계산에는 원본의 불투명 경계를 사용한다.
- `FacilityGroundedVisual.GetVisibleBounds`에서 해당 원본 이름·크기가 일치할 때 측정한 경계를 사용한다. 다른 그림은 기존 메시 경계로 처리한다. 런타임에서 텍스처 Read/Write나 픽셀 순회를 요구하지 않으며 원본 이미지·메타는 수정하지 않는다. 원본 교체 시에는 이 경계 데이터와 회귀 테스트를 함께 갱신해야 한다.
- 받침은 0.07칸 두께로 낮추고 지면 아래로 0.03칸 겹친다. 최종 실제 불투명 경계는 지면 -0.04칸, 받침 상단은 +0.04칸으로 겹치도록 한다. 처음 +0.015칸 접점은 수치상 겹쳤지만 렌더에서 그림의 검은 외곽선 때문에 떠 보이는 부분이 있어 추가 보정했다. 받침 렌더링 순서는 본체 뒤로 변경했다.
- 원본 PNG 픽셀을 독립적으로 읽어 불투명 발끝의 높이를 검사하는 회귀 테스트를 추가했다. 신규 2×2/기존 1×1 충전기와 보관함을 포함한다. 관련 런타임·테스트 3개 어셈블리 컴파일 통과; 기존 CS0184 경고 1건. Test Runner와 인게임 재검수는 미실행이다. 임시 컴파일 파일은 삭제했다.
