# #266 최신 제작 기준: 리깅 중단, 기존 여자 전신 모션 유지

- 사용자 최신 요청: 리깅 결과를 거부하고 두 번째 GIF의 여자 사다리 모션으로 진행. 앞선 리깅 허용은 철회된 것으로 적용한다.
- 채택 기준은 `images/issue266/female-original-outfit-ladder-v1-review/`의5개 전신 자세 및 기존 `ladder-review.gif`. 머리·몸통·팔다리 조립, 새 부위 생성, 리깅 동작은 더 진행하지 않는다. 리깅 시안은 삭제하지 않되 사용하지 않는다.
- 기존 여자 원화/자세/색/재생 순서를 그대로 유지한다. 사다리 순서1→2→3→2→1→4→5→4. 원본 검토 GIF를 재생성하지 않고 새 준비 폴더에 그대로 복사했다.
- 게임용 크기 준비: `images/issue266/approved-ladder-whole-cels/ladder_01.png`~`ladder_05.png`(1254×1254). 실제 남자 사다리 중립 원화와 전체 높이를 맞추는 **전신 전체의 같은 가로세로 배율·같은 이동량**만5장에 적용했다. 개별 팔다리나 프레임마다 다른 체형 보정은 없다. 원본 출처/해시/변환량은 같은 폴더 `export.json`에 기록했다.
- 재현: `tools/female-approved-ladder-export-20261102.ps1`. 5장 출력의 주요 알파 영역이 캔버스 경계에 닿지 않는지 검사했다. `approved-motion-reference.gif`는 기존 GIF의 동일 파일 복사이며 새 리깅 결과가 아니다.
- 현재 Unity 에셋/프리팹/게임 코드에 적용하지 않았다. 기존 남자 모션은 보존했다. 실제 사다리 손·발 접점/진입·이탈/모션간 크기는 미검증. 사용자 승인으로 이 자료를 커밋·푸시하고 검토 PR로 게시한다.
- 다음 작업도 리깅 없이 여자 전신 프레임 방식으로 진행한다. 걷기/채굴의 미채택40장·리깅 프리뷰를 섞거나 완성 세트로 간주하지 않는다. 준비된 사다리5장과 아직 미완성인 걷기/채굴 전체 세트를 구분한다.
