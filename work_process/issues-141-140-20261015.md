## #141 설정창 닫힘 끊김 — 수정

SettingsMenuSkin.AnimateClose는 고정 Y=850까지 ease-out으로 올라간 뒤 설정창을 비활성화했다. 큰 viewport/카드 조합에서는 끝 위치에서도 카드의 하단이 화면 안에 남을 수 있다. 이 상태에서 감속과 비활성화가 이어져 멈췄다가 사라지는 것처럼 보일 수 있는 코드 경로다. 실제 화면에서 제보 증상을 재현한 판정은 아니다.

- 카드의 실제 World Corners를 부모 좌표로 변환해 최하단이 부모 화면 상단보다 위에 오도록 종료 위치 계산.
- 마지막까지 속도가 유지되는 상승 곡선(0.65t+0.35t²) 사용. 기존 0.38초/unscaled 시간/완료 후 닫기 콜백은 유지.
- 닫기 중 현재 X 위치 유지. 드래그한 창이 닫는 순간 가로 중앙으로 튀지 않음.
- 기존 재진입/콜백/드롭다운 정리 동작은 변경하지 않음.
- 1920×1080/1280×720/2560×1440 카드 완전 이탈의 기하 검사 소스 및 끝까지 상승하는 곡선 검사 추가.

## #140 드론 순간이동 — 수정

DroneFollower는 SmoothDamp 결과가 플레이어의 최소 거리 안에 들어가면 현재 위치와 관계없이 followOffset.normalized 방향으로 즉시 이동시켰다. 플레이어가 반대편에서 접근하거나 점프하며 교차하면 드론이 다른 쪽으로 건너뛸 수 있다.

- 최소 거리 회피를 현재 분리 방향의 목표 위치로 계산하고 동일한 SmoothDamp 한 번으로 추종.
- 최소 거리를 강제로 맞추는 순간 재배치 제거. 짧은 근접 상태는 허용하며 이동으로 부드럽게 벗어남. 물리 충돌체/플레이어 이동 규칙은 변경하지 않음.
- 새 타깃 바인딩 시 이전 타깃 추종 속도를 초기화.
- Tick(deltaTime)으로 입력 시간에 맞춰 진행하며 0 이하 시간에는 이동하지 않음. Z 위치와 기존 방향 전용 Sprite 유지.
- 가까운 상태에서 반대편 점프 방지, 왼쪽/위쪽 이동 중 프레임 변위, Z 유지와 0시간 정지 회귀 검사 소스 추가.
