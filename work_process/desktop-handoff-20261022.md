## 패치 전달·복원 주의

1. stash는 노트북 로컬에만 있다. 데스크탑에서 위 stash SHA를 바로 apply하려고 하지 않는다.
2. 먼저 #242 브랜치를 받아 이 문서와 `work_process/handoff-20261022/`를 읽는다. 다른 브랜치로 전환하면 이 폴더가 사라질 수 있으므로 복원용 폴더를 별도 임시 위치에 복사해 둔다.
3. 해당 이슈 브랜치에서 작업 트리가 깨끗한지 확인하고 패치 파일 내용을 검토한다. `git apply --check <패치의 실제 경로>`로 먼저 확인한다. 기준 코드가 달라 실패하면 최신 main의 구현과 비교해 `git apply --3way <패치의 실제 경로>` 또는 파일별 수동 통합을 사용한다. 자동 성공으로 가정하지 않는다.
4. 두 패치를 걷기 브랜치에 한꺼번에 적용하지 않는다. 이미 같은 수정이 병합됐으면 중복 적용하지 않는다. 기존 노트북 stash는 삭제하지 않았다.
5. 복원 패치는 문서 자료이며 Unity가 컴파일·실행하지 않는다. ProjectSettings·Packages·씬 변경이나 사용자 세이브는 포함하지 않는다.
