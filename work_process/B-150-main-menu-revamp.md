# B-150 메인화면 개편: 부팅 연출 + 자석 철제 프레임 + 지상 기지식 버튼 (#119)

## 목표

메인화면을 "지하 관제 단말기를 켜는 순간"처럼 보이게 바꾼다. 레이아웃은 사용자 시안(로고 → 부제 → 슬롯 카드 3장 → 큰 이어하기 → 새 게임·설정·종료)을 따른다.
선택한 세이브 슬롯에는 철제 프레임이 자석처럼 날아와 붙고, 아래 버튼은 지상 기지 버튼과 같은 스타일로 맞춘다.

## 1. 켜질 때 (전체 1초 안쪽)

1. 검은 화면에서 가운데 가로선이 번쩍 → 위아래로 펼쳐지며 배경이 보인다 (약 0.3초).
2. 맨 위 "SUB-TERRA OPS // 신호 연결 중..."이 타이핑되고, 끝나면 "신호 연결됨"으로 바뀐다.
3. 로고가 짧게 글리치하며 또렷해지고, 부제 "봉인 너머에서 신호가 온다."가 타이핑된다.
4. 슬롯 카드 3장이 위에서부터 0.08초 간격으로 올라오며 fade in.
5. 이어하기 → 새 게임·설정·종료 순으로 나타난다.

- 아무 키나 클릭으로 끝 상태로 건너뛸 수 있다. 연출 중에도 입력이 꼬이지 않아야 한다.

## 2. 슬롯 카드

- 내용: 썸네일, "탐사 기록 0N", 골드 / 최대 깊이 / 목표 N/M, 마지막 저장 시각.
  - Depth는 현재 깊이 대신 **최대 깊이**로 바꾼다. 목표는 완료 목표 수 / 전체 목표 수.
  - 두 값은 세이브 파일에 이미 있는 값만 읽어서 메타에 추가한다. **저장 형식(SaveVersion)은 바꾸지 않는다.** 옛 세이브에 값이 없으면 "-"로 표시.
- 빈 슬롯: 썸네일 자리에 "신호 없음" 노이즈가 흐르고, "비어 있는 기록 / 새 탐사를 시작하세요." 표시.
- 손상 슬롯: 기존 표시 유지(주황, 이어하기 불가).
- 썸네일은 카드가 등장할 때 노이즈에서 화면으로 짧게 바뀐다.
- 선택 표시는 철제 프레임 하나로 한다. 왼쪽 화살표와 "선택됨" 배지를 동시에 쓰지 않는다(필요하면 배지만).

## 3. 자석 철제 프레임 (핵심)

- 선택된 카드에만 철제 프레임이 붙는다. 프레임은 모서리 4조각 + 위·아래 바 조각으로 나눈다.
- 붙을 때(약 0.25초): 조각들이 카드 바깥 약 24~40px에서 fade in 하면서 안쪽으로 날아와, 끝에서 살짝 튕기듯(overshoot) 딸깍 맞물린다. 맞물리는 순간 이음새에 청록 빛이 한 번 번쩍인다.
- 떨어질 때(약 0.18초): 조각이 바깥으로 풀리며 fade out.
- 위/아래 키나 마우스 호버로 다른 슬롯을 고르면: 이전 카드 프레임이 떨어지는 동시에 새 카드에 프레임이 붙는다.
- 빠르게 연타해도 프레임이 두 카드에 남거나 꼬이면 안 된다. 진행 중 연출은 끊고 새 대상으로 넘어간다.
- 프레임 모양은 지상 기지 상단 바처럼 모서리 깎인 철제 느낌. 맞는 이미지가 없으면 조각 이미지를 새로 만들어도 된다(codex 등 다른 에이전트에게 생성을 맡겨도 됨). 기존 UI_CutCorner_Plate 등을 조합해도 된다.

## 4. 슬롯 삭제

- 각 카드 오른쪽 위에 휴지통 버튼. 평소엔 흐리게, 선택된 카드에서만 또렷하게.
- 빈 슬롯에는 표시하지 않는다.
- 누르면 덮어쓰기 확인 창과 같은 스타일의 확인 창을 띄운다("탐사 기록 0N을 삭제할까요? 되돌릴 수 없습니다."). 확인해야만 삭제.
- 삭제는 기존 세이브 서비스의 삭제 경로를 쓴다. 없으면 백업 파일까지 같이 지우는 방식으로 만들고 보고한다. 실제 사용자 세이브를 테스트에서 지우지 않는다.

## 5. 아래 버튼

- 이어하기: 지상 기지 "지하 탐사 시작"과 같은 특별 버튼(Exploration-button.png 계열)으로 크게. 왼쪽 아이콘은 신호/세이브 느낌. 선택 슬롯에 기록이 없거나 손상이면 흐리게, 누를 수 없음.
- 새 게임 · 설정: 지상 기지 일반 버튼(button-active-off/on) + 왼쪽 아이콘, SurfaceBaseButtonFeedback과 같은 호버 연출.
- 종료: 같은 형태지만 **빨간 계열**로 위험 버튼임을 보이게 한다. 호버 빛도 빨강.
- 아이콘이 없으면 기존 아이콘(icon-quit, icon-settings 등)을 쓰고, 맞는 게 없으면 새로 만들어도 된다.
- 키보드 이동(위/아래 슬롯, 좌/우 버튼, Enter/Space 실행)은 지금처럼 유지.

## 6. 배경 분위기

- 기획서 7장의 먼지 입자, 옅은 스캔라인, 몇 초에 한 번 짧은 지지직을 넣는다. 아주 약하게 해서 글자를 가리지 않게 한다.
- 메뉴 뒤쪽을 살짝 어둡게 깔아(비네트) 배경 빛보다 메뉴가 먼저 보이게 한다.

## 7. 이어하기 / 새 게임 누른 뒤

- 선택 카드가 번쩍 → 화면이 TV 꺼지듯 가로선으로 접히고 다음 화면으로 넘어간다 (약 0.4초).
- 씬 전환·로드 흐름(Bootstrap → 새 게임 → 탐사)은 바꾸지 않는다. 덮어쓰기 확인 창 흐름도 그대로.

## 구현 방향

- 연출 계산은 순수 클래스로 분리한다 (예: MainMenuBootTimeline, SlotFrameMagnetTimeline). View는 계산된 값만 적용한다.
- CCTV·런 실패 쪽 효과는 재사용하고, 공용으로 빼는 게 작으면 그렇게 한다. 다른 창 동작은 바뀌면 안 된다.
- Prefab·Scene 변경은 B103 Builder를 고치거나 새 Builder(PromptB150MainMenuBuilder)로 한다. 범위 밖 Prefab·Scene은 건드리지 않는다.
- 시간·색·거리 값은 인스펙터에서 조정 가능하게.

## 수동 확인 체크리스트

실행 경로: Bootstrap → 메인화면 → 새 게임/이어하기 → 탐사

- [ ] 켜질 때 가로선 → 부팅 문구 → 로고·부제 → 카드 → 버튼 순으로 나온다
- [ ] 위/아래 키와 호버로 슬롯을 옮기면 철제 프레임이 떨어졌다가 새 카드에 딸깍 붙는다
- [ ] 빠르게 연타해도 프레임이 꼬이지 않는다
- [ ] 최대 깊이와 목표 수가 맞게 나오고, 빈 슬롯엔 "신호 없음" 노이즈가 흐른다
- [ ] 휴지통은 선택 카드에서만 또렷하고, 확인 창 없이 삭제되지 않는다
- [ ] 이어하기가 지하 탐사 시작 같은 특별 버튼이고, 빈 슬롯 선택 시 흐리다
- [ ] 종료 버튼이 빨간 계열이다
- [ ] 먼지·스캔라인이 글자를 가리지 않는다
- [ ] 이어하기 후 TV 꺼짐 연출 뒤 정상으로 게임이 이어진다
- [ ] Console 오류가 없다
