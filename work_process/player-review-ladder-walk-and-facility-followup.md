# 팀원 리뷰 우선 작업 / 시설 후속 계획

기준 main: d6d16e3e. 작업 경로는 기존 sub-terra/sub-terra, 브랜치 codex/player-review-ladder-top-walk.

## 우선 리뷰

- 사다리 맨 위에서 손이 허공을 잡지 않도록 플레이어 콜라이더 윗면이 마지막 Trigger 끝에 도달하면 상승만 제한. 하강·횡이동·탈출 점프는 유지.
- 연결된 사다리 경계에서 정지하지 않아야 하며, 기존 점프·재탑승 테스트와 함께 검증한다.
- 걷기 원본 walk_01~10을 실제 확인: 비슷한 앞쪽 보폭이 반복돼 반대쪽 발 주도 동작이 불명확. 단순 프레임 재배열/속도 변경으로 해소됐다고 주장하지 않는다. 기존 스타일/머리·몸통 정렬을 유지한 반대 보폭 시안을 검토한 뒤 기존 PNG와 meta GUID를 유지해 교체하는 방향.

## 후속 작업 (이번에는 구현하지 않음)

1. 충전기·전진기지 코어의 떠 보임 원인을 Sprite 투명 여백/피벗/PPU/VisualRoot 위치/지면 기준으로 분리 조사.
2. 바닥 접점과 크기를 통일하고 필요한 경우 좁은 받침·접지 그림자를 검토. 일반 시설 로직·전력·저장 규칙은 시각 보정과 분리.
3. 전진기지와 엘리베이터 겹침은 렌더 순서로만 숨기지 않는다. 실제 시설 footprint와 승강로/문/객실 이동 영역을 조사해 설치 금지 영역을 정의.
4. 기존 BuildingPlacement 검증 경로에서 점유/승강로 충돌을 검사하고 프리뷰와 최종 설치에서 같은 판정을 사용. 실패 시 자원 미차감, 이유 표시. 기존 저장 복원 처리 정책은 팀원과 합의 후 별도 적용.
5. 검증: 코어/충전기 지면 접점, 엘리베이터 문 개폐·왕복 중 겹침 없음, 경계 설치, 거절 시 비용 미차감, 저장/복원 회귀.
