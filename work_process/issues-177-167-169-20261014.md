## #167 점프 입력 보완

- PlayerMovement에 coyoteTimeSeconds/jumpBufferSeconds를 추가했다. 기본 각각 0.1초, Inspector 범위 0~0.2초. 기존 Prefab을 다시 만들 필요 없이 필드 기본값으로 적용한다.
- JumpGraceWindow를 같은 소스 파일의 순수 관리형 규칙으로 두었다. 바닥에서 떠난 직후 짧은 유예를 주고, 착지 전 입력은 유효 시간 내 착지하면 한 번 소비한다. 입력을 반복해도 예약은 하나이며 소비 후 유예/예약을 지운다.
- 기존 jumpUsedUntilLand, jumpAirLockRemaining, 비상승 착지 판정, 사다리 탈출, 화물 점프 배율을 유지한다. 공중 연타로 두 번째 점프가 되지 않도록 기존 잠금 조건과 함께 판정한다.
- 이동 잠금/비활성화 때 예약과 바닥 유예를 지운다. 잠금 중 입력이 해제 직후 튀어나오는 것을 방지한다. 사다리 진입은 바닥 유예만 지우며 기존 사다리 탈출 점프 규칙을 유지한다.

## #169 체력바 잔상

- BasicHudView의 체력 갱신에서만 HudGaugeView의 잔상을 활성화한다. 실제 체력바는 받은 값으로 즉시 변경한다. 전력바의 기존 감소 보간은 유지한다.
- 기존 Fill 이미지를 1회 복제해 그 뒤, Frame 앞에 잔상 Image를 둔다. 같은 RectTransform/스프라이트/수평 fill을 사용하며 주황색 tint와 raycastTarget=false를 적용한다. 추가 Inspector 연결이나 손수 Prefab YAML 편집은 없다.
- 감소 구간은 0.35초 유지한 뒤 0.4초 동안 새 값으로 내려간다. 연속 피해는 현재 보이는 잔상 값에서 이어지고, 같은 값을 반복 갱신해도 대기를 다시 시작하지 않는다.
- 회복은 잔상을 새 값으로 즉시 맞춘다. 최대 체력 변경/초기 표시/비활성화에는 잔상을 초기화한다. 체력 값·피해·회복 판정은 변경하지 않는다.
- HealthDamageTrail의 시간 규칙은 같은 파일의 순수 관리형 모델로 검사한다. 매 프레임 오브젝트 생성/검색은 추가하지 않았다.
