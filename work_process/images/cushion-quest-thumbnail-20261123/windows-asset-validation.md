# 완충판 퀘스트 에셋 Windows QA

- 검증 기준 커밋은 `ed88a029`이며, Unity 6000.5.4f1 Windows x64 QA 빌드가 성공했습니다.
- Bootstrap에서 별도 QA 슬롯으로 지상 기지와 광산에 진입했습니다. 두 씬의 퀘스트 상세 카드가 저장된 참조를 통해 `place_support_in_danger` 스프라이트를 직접 로드했습니다.
- PNG 원본은 2172×724이며, Windows 플레이어에서 Unity가 가져온 스프라이트 영역은 두 씬 모두 2048×683이었습니다. 검증 프로세스 종료 코드는 0이었습니다.
- 기존 Windows 카드 화면 비교에서는 같은 PNG를 임시 표시해 양발과 상판이 잘리지 않는지 확인했습니다. 이번 실행은 실제 에셋 연결과 로딩을 확인했습니다.
- Demo 일반 입력 검증은 별도 QA 슬롯과 별도 실행으로 구분합니다.
