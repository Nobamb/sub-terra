# 선택된 전신 걷기 16장 · 기본 1초

- `walk-01.png`~`walk-16.png`: 256×256 RGBA, 전신 신규 작화, 16fps / 1초 주기.
- `walk-1s.gif`: 흰색/검은색 배경 비교. GIF 시간 단위 제한 때문에 60/60/60/70ms를 반복해 합계 1초다.
- `timing-comparison.mp4`: 동일 그림의 기존 0.8초/20fps와 선택한 1초/16fps 비교.
- `walk-slow-2s.gif`: 자세 확인용 느린 재생.
- `export.json`: 원본 전신 영역, 전체 공통 배율, 발 위치, 높이, 파일 해시와 GIF 검사.
- 게임·클립·가이드 모두 16장/16fps다. 그림 전체의 크기/위치만 정렬했고 신체 부위 합성·변형·겹치기 보간은 하지 않았다.
- 일부 발 간격/팔 타이밍/상체 변화는 리뷰 항목이다. 실제 게임 속도와 발 미끄러짐은 추가 확인해야 한다.
