### 팀원 PC에서 한 번 수집하는 방법

1. 이 진단 코드가 포함된 새 실행 파일을 사용한다. 이전 exe는 Git 브랜치만 변경해도 바뀌지 않는다.
2. 실행 파일의 바로가기 대상 끝에 공백 후 `-trace-upgrades`를 붙인다. 또는 터미널에서 `./SubTerra.exe -trace-upgrades`로 실행한다(파일 이름은 실제 배포명 사용).
3. 문제가 발생했던 진입 경로(새 게임 / 이어하기 / 광산 복귀)와 구매 항목을 적고 한 번만 구매한다. 창을 닫았다 다시 열었을 때의 레벨도 적는다. 구매를 반복해 비용을 쓰지 않는다.
