# #211 지상 업그레이드 재현 조사 — 2026-10-21

## 결론

- 실제 SurfaceBase 씬·카탈로그·구매 버튼 경로에서도 제보 증상은 미재현이다. 해결 완료로 처리하거나 이슈를 닫지 않는다.
- 드릴 2회 → 최대 전력 → 최대 체력 → 최대 화물 → 채굴 수확량 순서로 구매했다. 기존 트리의 선행 해금을 지켰다.
- 각 구매 직후 같은 프레임에서 서비스 레벨과 실제 트리 노드 라벨이 증가했다. 전력·화물 실제 최대치 및 체력·수확량 효과 제공값도 즉시 갱신됐다. 창 재오픈 후 바인딩 유지도 확인했다.
- 지상에는 광산 플레이어가 없으므로 체력은 효과 제공값을 확인했다. 실제 플레이어의 체력 변화나 실제 화면 렌더링을 확인한 결과가 아니다.
