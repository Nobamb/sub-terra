# #266 걷기 리듬 보완 — 시험 속도 조율

## 선택한 범위

- 기준: `codex/issue-266-character-selection`의87f9bbf4.
- 사용자는 **시험에서만 걷는 속도를 낮춰 리듬·접지를 맞추기**를 선택했다. 기존 정식 이동 속도와 여자 원화/팔다리/장비/의상은 변경하지 않았다.
- 고정된 보폭0.78local unit과 기존 실제 속도5.76456unit/s를 동시에 유지하면 한 주기가약0.13초다. 주기를 늦추기만 해서 발 미끄러짐도 없어진다고 설명하지 않는다.

## 변경

- `FemaleLocomotionReviewWindow.cs`: `시험에서만 이동 속도 낮춤`과 `목표 걷기 주기(초)` 추가. 기본 목표0.7초를 바탕으로 보폭×현재 가로배율/목표주기에서 시험 이동 속도를 계산한다. 기존 속도보다 높이지 않는다.
- 속도 변경은 Play 중의 비영구 PlayerMovement 인스턴스의 moveSpeed에만 적용한다. 원래 값은 시작 시 보관한다. 끄기/시험 종료/창 닫기 때 복원하며, 그사이 외부에서 다른 값으로 바뀐 경우 오래된 시험 값으로 덮어쓰지 않는다.
- 원래 프리팹·씬·이동/물리 코드·저장 데이터/스키마·ProjectSettings·Packages는 수정하지 않는다. 무거운 화물/위험 배율은 기존 이동 경로에 계속 반영된다.
- 기존 거리 기반 그림 진행과 지면 표시 보정은 유지한다. 시간을 늦추면서 그림을 길게 늘리거나 발을 잘라 붙이지 않는다.
- 메뉴 `SubTerra > Review > Female Idle Walk (Play Only)`로 창을 새로 열면 시험 속도 조율을 켠 상태로 준비한다. Play 후 광산 진입→시험 켜기로 적용한다. 이미 시험 중이면 메뉴 재실행만으로 속도를 강제 변경하지 않는다.
- `FemaleLocomotionReviewSmoke.cs`: `RunRhythmWithMine` 추가. 같은 실제 Player 프리팹의 기존 거리 재생/속도6과 조율한 속도를 비교하고, 별도 시험 슬롯으로 실제 광산에서 짧게 이동한다. 양 단계 종료 시 moveSpeed가 원래 값6으로 복원되는지 검사한다.
- `female-locomotion-result-20261104.ps1`: CSV에 존재하는 비교 모드를 읽고 통계·비교표·실제 캡처 시각 간격의 GIF를 생성하도록 확장했다.

## 실제 실행 결과

- Unity6000.5.4f1에서 컴파일 통과, 전후 평지 및 Bootstrap→SurfaceBase→실제 광산의 짧은 이동 검사 **PASS**.
- 평지 기존 거리 재생: 기록81개, 실제 최고 속도5.76456unit/s, 해당 속도의 계산 주기0.12854초.
- 평지 시험 속도 조율: 기록85개, 실제 최고 속도0.82313unit/s, 해당 속도의 계산 주기0.90022초. 시험 moveSpeed 설정은1.05857이며, 목표0.7초와 실제0.9초는 물리 접촉 등을 거친 결과가 다르다는 점을 구분한다. 주기를 정확히0.7초로 강제하기 위해 물리 설정을 변경하지 않았다.
- 정지 상태의 이동 자세는 양쪽0개. 여자 표시/접지 측정에서 지면 차이는 양쪽0이었다. 실제 광산 기록11개 중 접지 측정9개에서도 지면 차이0, 정지3개 모두 대기였다.
- Sprite/VisualRoot는 매 렌더 후 원래 값으로 복원됐다. 평지와 광산에서 시험 종료 후 원래 moveSpeed6 복원 검사도 통과했다.
- 조율한 평지에서 같은 걷기 그림의 연속 기록28쌍, 최대 가로 발 진단점 변위0.056unit. 기존 고속 거리 재생에서는 이런 연속 쌍이0개였으므로 가로 미끄러짐의 개선율을 계산하지 않는다. **발 완전 고정·미끄러짐 완전 제거로 판정하지 않는다.**
- 보정 묶음 PNG와 실제 렌더 프레임을 확인했다. GIF는 실제 캡처 간격으로 생성한 검토 자료다. 60fps 완성 영상이나 Windows 빌드 성능 측정이 아니다.
- 새 C# 오류/게임 코드 예외는 검출되지 않았다. 라이선스·서비스 연결 관련 기존 환경 로그는 존재한다.

## 현재 판정과 다음

- 선택한 **느린 시험 보행**의 리듬 조율과 속도 복원까지 구현·실행했다. 정식 게임 속도를 낮춘 작업이 아니다. 걷기8장과 대기·진입만 시험하며 다른 모션은 원래 그림으로 표시한다.
